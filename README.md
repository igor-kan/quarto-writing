# Quarto Writing

This is a personal writing repository powered by [Quarto](https://quarto.org/). It is structured to seamlessly host blogs, tutorials, chapters, and articles.

## Publishing
The site is automatically built and deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the `main` branch.

## Directory Structure
- `posts/`: Blog posts and articles.
- `chapters/`: Book chapters or long-form content.
- `tutorials/`: Educational guides and tutorials.

## Local Preview
If you have Quarto installed locally, you can preview the site:
```bash
quarto preview
```
