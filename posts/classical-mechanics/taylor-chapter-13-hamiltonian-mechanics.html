13.1 The Legendre Transformation

The Hamiltonian formalism replaces the generalized velocities \(\dot q_i\) by the generalized momenta \[p_i = \frac{\partial \mathcal L}{\partial \dot q_i},\] and the Lagrangian by the Legendre transform \[\mathcal H(q,p,t) = \sum_i p_i \dot q_i - \mathcal L(q,\dot q,t).\] For this to define \(\mathcal H\) as a function of \((q,p)\) we must be able to invert \(p_i = \partial \mathcal L/\partial \dot q_i\) to get \(\dot q_i = \dot q_i(q,p)\). This is guaranteed when \(\mathcal L\) is convex in the velocities (the Hessian \(\partial^2 \mathcal L/\partial \dot q_i \partial \dot q_j\) is positive definite), so that the Legendre transform is an involution: applying it twice returns the original function. When it is not convex (e.g. a relativistic or gauge system), one uses the Dirac constraint formalism instead.

For a natural, conservative system \(\mathcal L = T - U\) with \(T = \tfrac12 M_{ij}(q)\dot q_i\dot q_j\), \[p_i = M_{ij}\dot q_j,\qquad \mathcal H = \tfrac12 p^\top M^{-1} p + U = T + U = E.\]

13.2 Hamilton’s Canonical Equations

The Legendre transform converts the second-order Euler–Lagrange equations into a first-order system of \(2n\) equations: \[\boxed{\ \dot q_i = \frac{\partial \mathcal H}{\partial p_i}, \qquad \dot p_i = -\frac{\partial \mathcal H}{\partial q_i}\ }\] The \(2n\)-dimensional space coordinatized by \((q_1,\dots,q_n,p_1,\dots,p_n)\) is phase space; it is the cotangent bundle \(T^*Q\) of the configuration space. Trajectories are its flow lines.

13.3 Symplectic Structure and Liouville’s Theorem

Phase space carries the symplectic form \[\omega = \sum_i dq_i \wedge dp_i,\] and Hamilton’s equations are equivalently \[\iota_{X_H}\,\omega = -\,d\mathcal H,\] where \(X_H\) is the Hamiltonian vector field. The flow preserves \(\omega\) (and hence phase-space volume): this is Liouville’s theorem. In local form the phase-space density \(\rho(q,p,t)\) obeys the incompressibility statement \[\frac{\partial \rho}{\partial t} + \{\rho, \mathcal H\} = 0, \qquad\text{so in equilibrium}\quad \{\rho,\mathcal H\}=0.\] Liouville’s theorem is the geometric reason statistical mechanics has invariant measures and why ensembles preserve volume.

13.4 Poisson Brackets

For functions \(F,G\) on phase space define the Poisson bracket \[\{F,G\} = \sum_i \left(\frac{\partial F}{\partial q_i}\frac{\partial G}{\partial p_i} - \frac{\partial F}{\partial p_i}\frac{\partial G}{\partial q_i}\right).\] It is bilinear, antisymmetric, and satisfies the Jacobi identity \[\{F,\{G,H\}\} + \{G,\{H,F\}\} + \{H,\{F,G\}\} = 0,\] making phase-space functions a Lie algebra. Fundamental brackets: \(\{q_i,q_j\}=0\), \(\{p_i,p_j\}=0\), \(\{q_i,p_j\}=\delta_{ij}\). The equations of motion take the elegant form \[\dot F = \{F,\mathcal H\} + \frac{\partial F}{\partial t},\] so \(\{F,\mathcal H\}=0\) characterizes conserved quantities, and a canonical transformation is precisely a change of coordinates preserving the brackets.

13.5 Noether’s Theorem in Hamiltonian Form

A continuous symmetry with generator \(G\) (i.e. \(\{G,\mathcal H\}=0\)) has a conserved charge \(G\); the group action is generated by brackets with \(G\). This is the Hamiltonian face of Noether’s theorem from Chapter 7: time-translation \(\to\) \(\mathcal H\); spatial translation \(\to\) total momentum; rotation \(\to\) angular momentum.

13.6 Lean 4 Formalization of Hamiltonian Mechanics

The Hamiltonian structure is algebraic and therefore pleasant to formalize: phase space is a type with a symplectic form, and Hamilton’s equations are a predicate on curves.

import Mathlib

-- phase space (cotangent bundle) as a normed vector space M with a Hamiltonian
variable {M : Type*} [NormedAddCommGroup M] [NormedSpace ℝ M]
variable (H : M → ℝ) (hH : ContDiff ℝ 2 H)

-- a trajectory in phase space and Hamilton's equations (schematic):
--   qdot = ∂H/∂p, pdot = -∂H/∂q  become  z' = X_H(z)  for the Hamiltonian field
variable (z : ℝ → M)
def IsHamiltonianFlow : Prop :=
  ∀ t, deriv z t = fderiv ℝ H (z t) 1         -- schematic: X_H from the symplectic form

-- a Poisson bracket: bilinear, antisymmetric, satisfying Jacobi
variable (br : M → M → ℝ)
def IsPoisson : Prop :=
  (∀ x, br x x = 0) ∧                            -- antisymmetry
  (∀ x y, br x y = - br y x) ∧
  (∀ x y z, br x (br y z) + br y (br z x) + br z (br x y) = 0)  -- Jacobi

-- conserved quantity = vanishing bracket with the Hamiltonian
def IsConserved (F : M → ℝ) : Prop := ∀ x, br x (gradient H x) = 0

What the formalization makes precise:

  • Legendre transform as a type-level operation. p = ∂L/∂v must be invertible; in Lean this is the hypothesis that the velocity-Hessian is positive definite (PosDef), i.e. convexity in the velocities.
  • Hamilton’s equations are first-order. The state is a single term z : ℝ → M, not a curve with its derivative carried along.
  • Phase space is TangentBundle/CotangentBundle. Coordinates (q,p) are a chart on \(T^*Q\); the symplectic form is a 2-form ω : M → M → ℝ (antisymmetric, closed, nondegenerate).
  • Conservation is an algebraic identity. {F,H} = 0 is checkable by the bracket axioms — no analysis required once the bracket is set up.
  • Gaps. Mathlib contains manifolds, TangentSpace, and Lie theory, but symplectic geometry and the Legendre transform are only partially developed, so a full formalization of Hamiltonian mechanics currently requires building the symplectic and Poisson machinery.

## 13.1 The Legendre Transformation

The Hamiltonian formalism replaces the generalized **velocities** $\dot q_i$ by the generalized **momenta**
$$p_i = \frac{\partial \mathcal L}{\partial \dot q_i},$$
and the Lagrangian by the **Legendre transform**
$$\mathcal H(q,p,t) = \sum_i p_i \dot q_i - \mathcal L(q,\dot q,t).$$
For this to define $\mathcal H$ as a function of $(q,p)$ we must be able to invert $p_i = \partial \mathcal L/\partial \dot q_i$ to get $\dot q_i = \dot q_i(q,p)$. This is guaranteed when $\mathcal L$ is **convex** in the velocities (the Hessian $\partial^2 \mathcal L/\partial \dot q_i \partial \dot q_j$ is positive definite), so that the **Legendre transform is an involution**: applying it twice returns the original function. When it is not convex (e.g. a relativistic or gauge system), one uses the **Dirac constraint** formalism instead.

For a natural, conservative system $\mathcal L = T - U$ with $T = \tfrac12 M_{ij}(q)\dot q_i\dot q_j$,
$$p_i = M_{ij}\dot q_j,\qquad \mathcal H = \tfrac12 p^\top M^{-1} p + U = T + U = E.$$

## 13.2 Hamilton's Canonical Equations

The Legendre transform converts the **second-order** Euler–Lagrange equations into a **first-order** system of $2n$ equations:
$$\boxed{\ \dot q_i = \frac{\partial \mathcal H}{\partial p_i}, \qquad \dot p_i = -\frac{\partial \mathcal H}{\partial q_i}\ }$$
The $2n$-dimensional space coordinatized by $(q_1,\dots,q_n,p_1,\dots,p_n)$ is **phase space**; it is the **cotangent bundle** $T^*Q$ of the configuration space. Trajectories are its flow lines.

## 13.3 Symplectic Structure and Liouville's Theorem

Phase space carries the **symplectic form**
$$\omega = \sum_i dq_i \wedge dp_i,$$
and Hamilton's equations are equivalently
$$\iota_{X_H}\,\omega = -\,d\mathcal H,$$
where $X_H$ is the Hamiltonian vector field. The **flow preserves $\omega$** (and hence phase-space volume): this is **Liouville's theorem**. In local form the phase-space density $\rho(q,p,t)$ obeys the incompressibility statement
$$\frac{\partial \rho}{\partial t} + \{\rho, \mathcal H\} = 0, \qquad\text{so in equilibrium}\quad \{\rho,\mathcal H\}=0.$$
Liouville's theorem is the geometric reason statistical mechanics has invariant measures and why ensembles preserve volume.

## 13.4 Poisson Brackets

For functions $F,G$ on phase space define the **Poisson bracket**
$$\{F,G\} = \sum_i \left(\frac{\partial F}{\partial q_i}\frac{\partial G}{\partial p_i} - \frac{\partial F}{\partial p_i}\frac{\partial G}{\partial q_i}\right).$$
It is **bilinear**, **antisymmetric**, and satisfies the **Jacobi identity**
$$\{F,\{G,H\}\} + \{G,\{H,F\}\} + \{H,\{F,G\}\} = 0,$$
making phase-space functions a **Lie algebra**. Fundamental brackets: $\{q_i,q_j\}=0$, $\{p_i,p_j\}=0$, $\{q_i,p_j\}=\delta_{ij}$. The equations of motion take the elegant form
$$\dot F = \{F,\mathcal H\} + \frac{\partial F}{\partial t},$$
so $\{F,\mathcal H\}=0$ characterizes conserved quantities, and a **canonical transformation** is precisely a change of coordinates preserving the brackets.

## 13.5 Noether's Theorem in Hamiltonian Form

A continuous symmetry with generator $G$ (i.e. $\{G,\mathcal H\}=0$) has a conserved charge $G$; the group action is generated by brackets with $G$. This is the Hamiltonian face of Noether's theorem from [Chapter 7](taylor-chapter-7-lagrange-equations.qmd): time-translation $\to$ $\mathcal H$; spatial translation $\to$ total momentum; rotation $\to$ angular momentum.

## 13.6 Lean 4 Formalization of Hamiltonian Mechanics

The Hamiltonian structure is algebraic and therefore pleasant to formalize: phase space is a type with a symplectic form, and Hamilton's equations are a predicate on curves.

```lean
import Mathlib

-- phase space (cotangent bundle) as a normed vector space M with a Hamiltonian
variable {M : Type*} [NormedAddCommGroup M] [NormedSpace ℝ M]
variable (H : M → ℝ) (hH : ContDiff ℝ 2 H)

-- a trajectory in phase space and Hamilton's equations (schematic):
--   qdot = ∂H/∂p, pdot = -∂H/∂q  become  z' = X_H(z)  for the Hamiltonian field
variable (z : ℝ → M)
def IsHamiltonianFlow : Prop :=
  ∀ t, deriv z t = fderiv ℝ H (z t) 1         -- schematic: X_H from the symplectic form

-- a Poisson bracket: bilinear, antisymmetric, satisfying Jacobi
variable (br : M → M → ℝ)
def IsPoisson : Prop :=
  (∀ x, br x x = 0) ∧                            -- antisymmetry
  (∀ x y, br x y = - br y x) ∧
  (∀ x y z, br x (br y z) + br y (br z x) + br z (br x y) = 0)  -- Jacobi

-- conserved quantity = vanishing bracket with the Hamiltonian
def IsConserved (F : M → ℝ) : Prop := ∀ x, br x (gradient H x) = 0
```

What the formalization makes precise:

- **Legendre transform as a type-level operation.** `p = ∂L/∂v` must be *invertible*; in Lean this is the hypothesis that the velocity-Hessian is positive definite (`PosDef`), i.e. convexity in the velocities.
- **Hamilton's equations are first-order.** The state is a single term `z : ℝ → M`, not a curve with its derivative carried along.
- **Phase space is `TangentBundle`/`CotangentBundle`.** Coordinates `(q,p)` are a chart on $T^*Q$; the symplectic form is a 2-form `ω : M → M → ℝ` (antisymmetric, closed, nondegenerate).
- **Conservation is an algebraic identity.** `{F,H} = 0` is checkable by the bracket axioms — no analysis required once the bracket is set up.
- **Gaps.** Mathlib contains manifolds, `TangentSpace`, and Lie theory, but symplectic geometry and the Legendre transform are only partially developed, so a full formalization of Hamiltonian mechanics currently requires building the symplectic and Poisson machinery.
