Command Line Essentials: Navigating the Shell

Linux
CLI
Fundamentals
Master the foundational command-line operations for directory navigation, file manipulation, and input-output piping in Linux.
Published

June 27, 2026

The Command Line Interface (CLI) is one of the most powerful tools available to developers and system administrators. While Graphical User Interfaces (GUIs) are convenient, the CLI offers speed, scriptability, and access to powerful system commands that are otherwise unavailable.

This guide provides an overview of the essential commands and concepts needed to confidently navigate the command line.

1. Directory Navigation

In the command line, you are always positioned within a specific directory, known as your Current Working Directory (CWD).

  • pwd (Print Working Directory): Displays the absolute path of your current directory.
  • ls (List): Lists the contents of the current directory.
    • ls -l: Detailed list view (permissions, file size, modification date).
    • ls -a: Show all files (including hidden dotfiles).
  • cd (Change Directory): Move between folders.
    • cd /usr/bin: Navigate to an absolute path.
    • cd ..: Move up one level (parent directory).
    • cd ~: Jump directly to your home directory.

2. File and Folder Manipulation

  • touch filename: Create an empty file, or update the timestamp of an existing file.
  • mkdir foldername: Create a new folder.
    • mkdir -p path/to/folders: Create nested parent directories automatically.
  • cp source destination: Copy files or directories.
    • cp -r dir1 dir2: Copy a directory recursively (including all contents).
  • mv source destination: Move or rename a file or directory.
  • rm filename: Delete (remove) a file.
    • rm -rf foldername: Delete a folder and all its contents recursively and forcefully. Use with extreme caution.

3. Viewing and Inspecting Files

  • cat filename: Print the entire content of a file to the terminal screen.
  • less filename: Open a scrollable viewer for large files. Press q to close.
  • head -n 10 filename: Output the first 10 lines of a file.
  • tail -n 10 filename: Output the last 10 lines of a file (useful for monitoring log files).
    • tail -f /var/log/syslog: Continuously follow updates to a file in real-time.

4. Redirecting Output and Piping

Linux treats inputs and outputs as streams. You can redirect these streams to files or pipe them into other commands.

Output Redirection

  • > (Overwrite): Redirect output to a file, overwriting existing contents.

    echo "Hello World" > greetings.txt

  • >> (Append): Redirect output to a file, appending it to the end of the file.

    echo "Another line" >> greetings.txt

Piping (|)

The pipe operator takes the stdout (output) of the command on the left and passes it as stdin (input) to the command on the right.

# List all files and filter for those containing 'config' in their name
ls -la | grep "config"

# Print a log file, filter for errors, and show only the first 5 matches
cat system.log | grep "ERROR" | head -n 5

5. Essential Terminal Shortcuts

Save time and avoid typos using these shell keyboard shortcuts: * Tab (Auto-complete): Start typing a filename or command path, and press Tab once to autocomplete. Press twice to list all possibilities. * Ctrl + C: Terminate/kill the currently running process. * Ctrl + Z: Suspend/pause the currently running process (run fg to resume in foreground). * Ctrl + R: Search through your command history. Type characters to find a matching past command. * clear (or Ctrl + L): Clear the terminal screen.
