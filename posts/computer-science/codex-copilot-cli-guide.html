A developer’s guide to using OpenAI’s Codex models and GitHub Copilot CLI for terminal assistance, code generation, and shell command explanation.
Published

August 3, 2026

While OpenAI’s Codex models initially popularized AI-assisted programming in the IDE, GitHub Copilot CLI brings that same intelligence directly to your terminal shell.

Instead of switching context to a browser to search for complex ffmpeg syntax or obscure Git flags, you can invoke Copilot right where you are working.

1. Installation and Setup

GitHub Copilot CLI requires an active GitHub Copilot subscription and the GitHub CLI (gh).

First, install the GitHub CLI and authenticate:

# Install via standard package managers
sudo apt install gh   # Ubuntu/Debian
brew install gh       # macOS

# Authenticate with your GitHub account
gh auth login

Next, install the Copilot extension:

gh extension install github/gh-copilot

2. Using the gh copilot Commands

The extension exposes two primary commands: explain and suggest.

Explaining Obscure Commands

If you encounter a complex script or command online and want to understand it before running it, use explain:

gh copilot explain 'tar -czvf archive.tar.gz /var/log/'

Copilot will break down the command flag by flag, explaining what -c (create), -z (gzip), -v (verbose), and -f (file) do.

Suggesting Shell Commands

If you know what you want to do but forgot the exact syntax, use suggest:

gh copilot suggest "find all python files modified in the last 24 hours"

Copilot will offer a suggestion (e.g., find . -name "*.py" -mtime -1). You can then interactively choose to run the command, copy it to your clipboard, or revise the query.

3. Creating Shell Aliases (The ?? and git? shortcuts)

To make Copilot truly seamless, it’s highly recommended to set up aliases in your .bashrc or .zshrc.

To evaluate Copilot aliases for your shell, run:

gh copilot alias -- bash
# or
gh copilot alias -- zsh

Adding the output to your rc file gives you access to shortcuts like: * ?? [query]: Equivalent to gh copilot suggest -t shell * git? [query]: Equivalent to gh copilot suggest -t git * gh? [query]: Equivalent to gh copilot suggest -t gh

Example Workflow:

# Instead of googling how to undo a commit:
git? undo my last commit but keep the files staged

4. Why Use Codex/Copilot in the CLI?

  • Context Switching: Reduces the cognitive load of switching between a terminal and a web browser.
  • Safety: The explain command is an excellent security measure before blindly pasting commands from StackOverflow.
  • Continuous Learning: Over time, seeing the explanations helps solidify your own knowledge of bash syntax and Linux utilities.
