The Complete Tmux Guide: From Essentials to Reboot Persistence

Master terminal multiplexing: session management, multi-pane workflows, batch session killing, and surviving system reboots with tmux-resurrect and tmux-continuum.
Published

July 21, 2026

If you spend significant time in the Linux terminal, managing multiple SSH connections, background jobs, and split terminal windows can quickly become chaotic. Network drops during remote SSH sessions can terminate running scripts, wasting hours of work.

Tmux (Terminal Multiplexer) solves these issues by decoupling terminal sessions from your physical terminal emulator. It lets you run multiple terminal sessions inside a single window, split screens into custom panes, detach long-running tasks, and persist full dev environments across system reboots.

1. Core Architecture of Tmux

Tmux operates on a 4-tier hierarchy:

  1. Server: The background daemon managing all tmux activity. Runs as long as at least one session exists (or until explicitly killed).
  2. Sessions: Isolated workspace containers. Each session runs independently and remains active even if you disconnect from SSH or close your terminal.
  3. Windows: Visual tabs within a session, each occupying the full display area.
  4. Panes: Individual rectangular splits inside a window running independent shell instances.
+-------------------------------------------------------------+
| Tmux Server                                                 |
|  +-------------------------------------------------------+  |
|  | Session 1: "dev"                                      |  |
|  |  +---------------------+---------------------------+  |  |
|  |  | Window 0: "editor"  | Window 1: "server"        |  |  |
|  |  |  +-------+-------+  |  +---------------------+  |  |  |
|  |  |  | Pane 0| Pane 1|  |  | Pane 0              |  |  |  |
|  |  |  +-------+-------+  |  +---------------------+  |  |  |

2. Getting Started: Commands & The Prefix Key

The Prefix Key

Once inside a tmux session, standard keyboard shortcuts are intercepted by your active shell unless preceded by the Prefix key. By default:

\[\text{Prefix} = \text{Ctrl} + \text{b} \quad (\text{written as } \text{C-b})\]

To execute a command, press Ctrl + b, release both keys, then press the desired key command.

Essential Command Line Operations

Execute these commands from your standard system shell:

# Start a new un-named session
tmux

# Start a new named session (recommended)
tmux new -s dev

# List all active sessions
tmux ls

# Attach to the last active session
tmux a

# Attach to a specific named session
tmux attach -t dev

# Detach from inside an active tmux session
# Press: Ctrl+b, then d

3. Windows and Panes Management

Window (Tab) Controls

  • Prefix + c: Create a new window.
  • Prefix + ,: Rename current window.
  • Prefix + n: Switch to Next window.
  • Prefix + p: Switch to Previous window.
  • Prefix + 0..9: Switch to window by index.
  • Prefix + w: Display interactive tree menu of all windows & sessions.
  • Prefix + &: Kill current window.

Pane Split Controls

  • Prefix + %: Split pane vertically (Left / Right).
  • Prefix + ": Split pane horizontally (Top / Bottom).
  • Prefix + Arrow Keys: Move cursor between adjacent panes.
  • Prefix + o: Rotate to next pane.
  • Prefix + z: Toggle Zoom (maximize active pane; press again to restore).
  • Prefix + x: Kill active pane.
  • Prefix + { or }: Swap active pane left or right.

Copy & Scroll Mode

To scroll up or copy text using keyboard navigation: 1. Press Prefix + [ to enter copy mode. 2. Use arrow keys, PageUp/PageDown, or Vi motion keys (k, j, g, G) to navigate history. 3. Press Space to start selection, Enter to copy to tmux buffer, and q to exit copy mode. 4. Press Prefix + ] to paste the copied buffer.

4. How to Kill Multiple Sessions at Once (Batch Termination)

As your workflow expands, orphan or unused tmux sessions accumulate. Tmux provides several built-in commands and CLI tricks to kill multiple sessions at once.

[!IMPORTANT] Choose the method based on whether you want to wipe everything, target specific session names, keep your active session, or select sessions interactively.

Method 1: Kill ALL Sessions at Once (Server Wipe)

To instantly destroy all running tmux sessions and stop the tmux server process:

tmux kill-server

Method 2: Kill All Sessions EXCEPT the Active Session

If you are inside a tmux session and want to clear out all other background sessions without losing your current workspace:

# Run from INSIDE your active tmux session:
tmux kill-session -a

# Run from OUTSIDE tmux (specify the session name to keep):
tmux kill-session -a -t keep_this_session

Method 3: Batch Kill Sessions Matching a Name Pattern (CLI One-Liners)

If you have multiple sessions with matching names (e.g. test-1, test-2, dev-api), use shell pipelines to filter and kill them in bulk:

# Kill all sessions starting with "test"
tmux ls | awk -F: '/^test/ {print $1}' | xargs -n 1 tmux kill-session -t

# Kill all sessions containing "dev-"
tmux ls | grep 'dev-' | cut -d: -f1 | xargs -I {} tmux kill-session -t {}

# Batch kill using a Bash loop with wildcards
for session in $(tmux ls | cut -d: -f1); do
    if [[ $session == temp_* ]]; then
        tmux kill-session -t "$session"
    fi
done

Method 4: Interactive Multi-Select Session Killing (Choose-Tree & Tagging)

Tmux has a built-in interactive tree manager (choose-tree) that supports multi-selecting (tagging) sessions to kill them in batch:

Step-by-step Multi-Selection:

  1. Press Prefix + s (or Prefix + w) to open the session tree view.
  2. Use j / k or Up / Down Arrow keys to navigate and highlight sessions.
  3. Press t on each session you want to select. A * tag marker will appear next to every tagged session.
  4. Once you have tagged all sessions to be removed, press X (Shift + X).
  5. Confirm deletion if prompted. All tagged sessions will be killed simultaneously!

[!TIP] Tree View Multi-Selection Shortcuts: * t: Tag / Untag current highlighted session. * Ctrl-t: Tag ALL sessions in the list. * T: Clear/remove all tags. * x: Kill only the single highlighted session under cursor. * X: Kill ALL tagged sessions at once.

Method 5: Interactive Multi-Select Killing with FZF (fzf -m)

If you use FZF (Fuzzy Finder), you can interactively search, check/highlight multiple sessions using Tab, and kill them all at once:

# Multi-select sessions using FZF and kill selected sessions
tmux ls | fzf -m --prompt="Select sessions to kill: " | cut -d: -f1 | xargs -I {} tmux kill-session -t {}
  • Use Tab or Shift + Tab in FZF to check/select multiple sessions.
  • Press Enter to execute and kill all checked sessions in one go.

5. Batch Editing & Synchronizing Multiple Terminals

Tmux allows you to perform batch editing—executing the same keystrokes or commands across multiple terminal panes or sessions simultaneously.

Method 1: Pane Synchronization (Batch Editing Panes in Real-Time)

When pane synchronization is enabled, every keypress, command, or edit you type in one pane is broadcast to all panes in the current window at the same time. This is invaluable when configuring multiple servers via SSH or running identical commands across environments.

+---------------------------+---------------------------+
| Pane 1 (Server 1)         | Pane 2 (Server 2)         |
| $ sudo apt update         | $ sudo apt update         |
+---------------------------+---------------------------+
| Pane 3 (Server 3)         | Pane 4 (Server 4)         |
| $ sudo apt update         | $ sudo apt update         |
+---------------------------+---------------------------+
  ^ Keystrokes are broadcast to ALL 4 panes simultaneously!

How to Enable Pane Synchronization:

  1. Press Prefix + : to enter tmux command mode.
  2. Type setw synchronize-panes on and press Enter.
  3. Type your commands or perform edits—they will appear in all panes simultaneously.

How to Disable Pane Synchronization:

  1. Press Prefix + :.
  2. Type setw synchronize-panes off and press Enter.

Add a Toggle Shortcut to ~/.tmux.conf:

# Toggle pane synchronization with Prefix + y
bind y set-window-option synchronize-panes\; display-message "Synchronize panes: #{?synchronize-panes,on,off}"

Method 2: Batch Command Execution Across Sessions (tmux send-keys)

If you want to send a command or script to multiple running sessions in the background without manually attaching to each one:

# Send a command to a single target session in the background
tmux send-keys -t dev_session "git pull && npm run build" C-m

# Batch send a command to ALL active tmux sessions using a shell loop
for session in $(tmux ls | cut -d: -f1); do
    tmux send-keys -t "$session" "echo 'System update scheduled'" C-m
done

(Note: C-m simulates pressing the Enter key to execute the sent command).

6. Modern Configuration (~/.tmux.conf)

Enhance usability by editing ~/.tmux.conf:

# Enable full mouse support (click, resize, scroll)
set -g mouse on

# Set prefix to Ctrl+a (easier reach than Ctrl+b)
unbind C-b
set-option -g prefix C-a
bind-option C-a send-prefix

# Start window and pane indexing at 1 (instead of 0)
set -g base-index 1
setw -g pane-base-index 1

# Intuitive split keybindings
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"
unbind '"'
unbind %

# Reload config easily
bind r source-file ~/.tmux.conf \; display "Config Reloaded!"

# True color support & status bar styling
set -g default-terminal "screen-256color"
set -g status-bg "#1e1e2e"
set -g status-fg "#cdd6f4"

Reload configuration active sessions:

tmux source-file ~/.tmux.conf

6. Persisting Tmux Sessions Across Reboots

By default, tmux sessions live in system memory. Reboots or server restarts destroy all running sessions.

Using TPM (Tmux Plugin Manager) with tmux-resurrect and tmux-continuum, you can automatically save and restore full session layouts, pane paths, terminal history, and active processes across reboot cycles.

Step 1: Install Tmux Plugin Manager (TPM)

Clone TPM into your home directory:

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

Step 2: Configure ~/.tmux.conf for Persistence

Add the following plugin setup to the bottom of ~/.tmux.conf:

# List of plugins
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-sensible'
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

# Restore pane contents & shell commands
set -g @resurrect-capture-pane-contents 'on'
set -g @resurrect-processes 'vi vim nvim emacs man htop top ssh'

# Enable automatic session restore on tmux server boot
set -g @continuum-restore 'on'
set -g @continuum-save-interval '15' # Auto-save every 15 minutes

# Initialize TMUX plugin manager (keep this line at the very bottom of tmux.conf)
run '~/.tmux/plugins/tpm/tpm'

Step 3: Install Plugins inside Tmux

  1. Open a tmux session or reload configuration: tmux source-file ~/.tmux.conf
  2. Press Prefix + I (capital I).
  3. TPM will download and install tmux-resurrect and tmux-continuum.

Step 4: Manual vs. Automatic Persistence

  • Manual Save: Press Prefix + Ctrl-s (C-s) to manually freeze current session state.
  • Manual Restore: Press Prefix + Ctrl-r (C-r) to restore saved session state.
  • Automatic Save/Restore: tmux-continuum automatically writes session metadata every 15 minutes and restores them automatically whenever the tmux server launches after a system reboot.

Step 5: Auto-Starting Tmux on System Boot

To guarantee tmux starts automatically upon system reboot (without waiting for manual login):

Method A: Systemd User Service (Linux)

Create ~/.config/systemd/user/tmux.service:

[Unit]
Description=Tmux Server Session Persistence
After=network.target

[Service]
Type=forking
ExecStart=/usr/bin/tmux new-session -s default -d
ExecStop=/usr/bin/tmux kill-server
Restart=on-failure

[Install]
WantedBy=default.target

Enable and start the service:

systemctl --user enable tmux
systemctl --user start tmux

Conclusion

With tmux, terminal management shifts from a fragile process vulnerable to network drops into a resilient development environment. By incorporating tmux-resurrect and tmux-continuum, your terminal state survives server reboots seamlessly.
