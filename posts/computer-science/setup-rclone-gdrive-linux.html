How to Set Up Rclone with Google Drive on Linux: Complete Guide

Linux
DevOps
Cloud
Storage
Systems
A step-by-step guide to installing rclone, authenticating Google Drive, re-connecting expired tokens, and mounting Google Drive as a local Linux filesystem.
Published

July 20, 2026

Rclone is an open-source command-line tool often described as “rsync for cloud storage”. It allows you to manage, sync, backup, and mount over 70 cloud storage providers—including Google Drive, Google Photos, Dropbox, S3, and OneDrive—directly on your Linux system.

Whether you need to sync files to Google Drive, back up local directories, or seamlessly mount your Drive as a local folder, this guide covers everything from initial setup to re-authenticating disconnected remotes.

1. Installing Rclone on Linux

Option A: Official Install Script (Recommended for Latest Version)

The official automated install script ensures you have the latest stable release of rclone:

sudo bash -c "$(curl -fsSL https://rclone.org/install.sh)"

Option B: Package Manager

Alternatively, install rclone via your Linux distribution’s package manager:

  • Ubuntu / Debian:

    sudo apt update && sudo apt install rclone

  • Arch Linux / Manjaro:

    sudo pacman -S rclone

  • Fedora / RHEL:

    sudo dnf install rclone

Verify the installation:

rclone version

2. Configuring Google Drive (rclone config)

To link your Google Drive account with rclone, use the interactive configuration wizard:

rclone config

Interactive Walkthrough:

  1. New Remote: Press n to create a new remote.
  2. Name: Type a descriptive name, such as gdrive.
  3. Storage Type: Scroll or search for Google Drive (usually option drive or number 18 depending on the rclone version). Type drive.
  4. Client ID & Client Secret:
    • Default: Press Enter to leave blank and use rclone’s shared credentials.
    • Custom (Recommended for high volume): You can create your own OAuth Client ID in the Google Cloud Console to avoid rate limiting.
  5. Scope: Choose the access permission scope. Option 1 (drive - full access to all files) is standard:
    • 1 / Full access (drive)
    • 2 / Read-only access (drive.readonly)
    • 3 / Access to files created by rclone only (drive.file)
  6. Service Account File: Press Enter to leave blank (unless configuring a service account).
  7. Edit Advanced Config: Press n (No).
  8. Auto Config:
    • On a Desktop machine with a browser: Press y (Yes). A web browser window will automatically open. Log into Google and click Allow.
    • On a Remote / Headless Server (SSH): Press n (No). Rclone will output a command to run on a local machine with a browser (rclone authorize "drive" ...), or a URL to visit to paste the authorization code.
  9. Configure as Shared/Team Drive: Press n unless you are connecting to a shared drive.
  10. Confirm & Keep: Press y to save the configuration, then press q to quit the config wizard.

3. Testing Your Connection

Once configured, verify that rclone can connect and list your Google Drive contents:

# List top-level directories on Google Drive
rclone lsd gdrive:

# List files in a specific folder
rclone ls gdrive:documents

# Check storage quota usage
rclone about gdrive:

4. Re-connecting an Expired or Disconnected Remote

Google Drive OAuth tokens expire periodically or when security permissions change. If rclone fails with an authentication error (invalid_grant or token expired), you can quickly refresh or reconnect without deleting the config:

Quick Re-authentication Command

rclone config reconnect gdrive:

When prompted: 1. Already have a token - refresh? -> Type y. 2. Use web browser to automatically authenticate rclone with remote? -> Type y (or n if on headless SSH). 3. Complete the web browser authentication flow.

Alternative via rclone config Menu

rclone config
  • Type e (Edit existing remote).
  • Select gdrive.
  • Press Enter through existing parameters until reaching Already have a token - refresh?.
  • Type y and authenticate.

5. Mounting Google Drive as a Local Directory

One of rclone’s most powerful features is mounting cloud storage into your local Linux directory tree using FUSE (Filesystem in Userspace).

Step 1: Create a Mount Point

mkdir -p ~/gdrive

Step 2: Mount the Remote

rclone mount gdrive: ~/gdrive --vfs-cache-mode full &

Note on --vfs-cache-mode full: This flag caches read/write operations locally, allowing full random access (opening documents, media streaming, writing files) just like a physical storage drive.

Step 3: Unmounting

When done or if a mount becomes unresponsive, unmount using fusermount:

fusermount -u ~/gdrive

6. Automating Mount on Boot with Systemd

To automatically mount Google Drive whenever you log into Linux, create a systemd user service:

  1. Create the user service directory if it doesn’t exist:

    mkdir -p ~/.config/systemd/user

  2. Create ~/.config/systemd/user/rclone-gdrive.service:

    [Unit]
Description=Rclone Google Drive Mount
After=network-online.target
Wants=network-online.target

[Service]
Type=notify
ExecStart=/usr/bin/rclone mount gdrive: %h/gdrive \
  --config %h/.config/rclone/rclone.conf \
  --vfs-cache-mode full \
  --vfs-cache-max-size 10G \
  --umask 022
ExecStop=/bin/fusermount -u %h/gdrive
Restart=on-failure
RestartSec=10

[Install]
WantedBy=default.target

  3. Enable and start the service:

    systemctl --user daemon-reload
systemctl --user enable --now rclone-gdrive.service

  4. Check status:

    systemctl --user status rclone-gdrive.service

Summary of Essential Commands

Action Command
Interactive Config rclone config
Reconnect / Refresh Auth rclone config reconnect gdrive:
List Directories rclone lsd gdrive:
Copy File to Drive rclone copy ~/myfile.txt gdrive:backups/
Sync Directory rclone sync ~/photos gdrive:photos --progress
Mount Remote rclone mount gdrive: ~/gdrive --vfs-cache-mode full &
Unmount Remote fusermount -u ~/gdrive

With this workflow set up, your Google Drive seamlessly integrates with your Linux command-line environment and local file managers!
