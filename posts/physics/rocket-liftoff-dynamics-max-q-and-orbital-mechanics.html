1 1. Introduction: The Conservation of Momentum in Open Variable-Mass Systems

Classical Newtonian mechanics is routinely introduced under the assumption of constant mass: \(\mathbf{F} = m \mathbf{a}\). However, a launch vehicle is an open thermodynamic system that operates precisely by expelling propellant at hypersonic exhaust velocities. At liftoff, over \(90\%\) of a launch vehicle’s total gross mass consists of chemical propellants (liquid oxygen, RP-1, liquid hydrogen, or solid binders).

Applying \(\mathbf{F} = \frac{d\mathbf{P}}{dt} = m \frac{d\mathbf{v}}{dt} + \mathbf{v} \frac{dm}{dt}\) directly to a variable-mass body is a notorious classical error violating Galilean invariance. Instead, we must apply Newton’s second law to an isolated system of constant total mass consisting of the rocket mass \(m(t)\) and an infinitesimal packet of exhaust mass \(dm_e = -\dot{m} dt\) expelled during an infinitesimal time interval \(dt\).

1.1 1.1 First-Principles Derivation of the Equation of Motion

Consider the system momentum at time \(t\): \[\mathbf{P}(t) = m(t) \mathbf{v}(t)\]

At time \(t + dt\), the rocket mass becomes \(m + dm\) (where \(dm < 0\)), moving with velocity \(\mathbf{v} + d\mathbf{v}\). Concurrently, an exhaust mass \(dm_e = -dm > 0\) has been ejected with velocity \(\mathbf{v}_e^{\text{inertial}} = \mathbf{v} - \mathbf{v}_e\) relative to the inertial frame, where \(\mathbf{v}_e\) is the effective relative exhaust velocity directed opposite to the thrust vector: \[\mathbf{P}(t + dt) = (m + dm)(\mathbf{v} + d\mathbf{v}) + (-dm)(\mathbf{v} - \mathbf{v}_e)\]

Expanding the products and dropping the second-order differential \(dm\, d\mathbf{v}\): \[\mathbf{P}(t + dt) = m\mathbf{v} + m\,d\mathbf{v} + \mathbf{v}\,dm - \mathbf{v}\,dm + \mathbf{v}_e\,dm = m\mathbf{v} + m\,d\mathbf{v} + \mathbf{v}_e\,dm\]

The net change in linear momentum is therefore: \[d\mathbf{P} = \mathbf{P}(t + dt) - \mathbf{P}(t) = m\,d\mathbf{v} + \mathbf{v}_e\,dm\]

Equating the rate of change of momentum to the external forces \(\mathbf{F}_{\text{ext}}\) (gravity \(\mathbf{F}_g\) and aerodynamic forces \(\mathbf{F}_{\text{aero}}\)): \[\mathbf{F}_{\text{ext}} = \frac{d\mathbf{P}}{dt} = m \frac{d\mathbf{v}}{dt} + \mathbf{v}_e \frac{dm}{dt}\]

Rearranging gives the celebrated Meshtchersky equation of motion for a variable-mass vehicle: \[m(t) \frac{d\mathbf{v}}{dt} = -\mathbf{v}_e \frac{dm}{dt} + \mathbf{F}_{\text{ext}} = \mathbf{T}(t) + \mathbf{D}(v, h) + m(t)\mathbf{g}(h)\]

where: * \(\mathbf{T}(t) = -\mathbf{v}_e \frac{dm}{dt} = \dot{m} v_e \hat{\mathbf{u}}_T\) is the thrust force, with propellant mass flow rate \(\dot{m} = -\frac{dm}{dt} > 0\). * When considering nozzle exit pressure \(p_e\) against ambient atmospheric pressure \(p_a(h)\) across nozzle exit area \(A_e\), the effective exhaust velocity \(v_e\) encompasses the pressure thrust: \[T = \dot{m} v_e = \dot{m} v_{\text{exit}} + (p_e - p_a(h)) A_e\]

2 2. Atmospheric Modeling and the Aerodynamic Dynamic Pressure Peak (Max-\(Q\))

As a rocket climbs vertically from the launch pad, it encounters two conflicting physical gradients: 1. Kinematic Velocity Growth: Under continuous thrust, the vehicle accelerates rapidly, so velocity \(v(t)\) increases monotonically from \(v(0) = 0\) to several kilometers per second. 2. Exponential Atmospheric Decay: The density of the planetary atmosphere \(\rho(h)\) decays exponentially with altitude \(h\).

The structural aerodynamic stress exerted on the rocket skin, fairings, and interstages is governed by the dynamic pressure \(q(t)\).

2.1 2.1 Mathematical Formulation of Dynamic Pressure

The fluid dynamic pressure \(q\) represents the kinetic energy per unit volume of the fluid stream colliding with the vehicle: \[q(t) = \frac{1}{2} \rho(h(t)) v(t)^2\]

Assuming an isothermal barometric atmosphere with sea-level density \(\rho_0 \approx 1.225\text{ kg/m}^3\) and atmospheric scale height \(H \approx 8500\text{ m}\): \[\rho(h) = \rho_0 \exp\left(-\frac{h}{H}\right)\]

Substituting the atmospheric profile into the dynamic pressure equation: \[q(t) = \frac{1}{2} \rho_0 \exp\left(-\frac{h(t)}{H}\right) v(t)^2\]

2.2 2.2 Analytical Extremum Condition for Max-\(Q\)

Because \(q(0) = 0\) (since \(v(0) = 0\)) and \(\lim_{t \to \infty} q(t) = 0\) (as the rocket enters the vacuum of outer space where \(\rho \to 0\)), Rolle’s Theorem guarantees that \(q(t)\) must attain at least one local maximum at some critical flight time \(t^*\), known in aerospace engineering as Maximum Dynamic Pressure or Max-\(Q\).

To find the exact physical condition at Max-\(Q\), we differentiate \(q(t)\) with respect to time \(t\) and set the derivative to zero: \[\frac{dq}{dt} = \frac{1}{2} \left[ \frac{d\rho}{dt} v^2 + 2 \rho v \frac{dv}{dt} \right] = 0\]

Using the chain rule on the density gradient: \[\frac{d\rho}{dt} = \frac{d\rho}{dh} \frac{dh}{dt} = \left(-\frac{1}{H} \rho_0 e^{-h/H}\right) \dot{h} = -\frac{\rho(h)}{H} v_z(t)\]

For a near-vertical initial climb where vertical velocity \(v_z(t) \approx v(t)\): \[\frac{dq}{dt} = \frac{1}{2} \left[ -\frac{\rho(h) v}{H} v^2 + 2\rho(h) v a(t) \right] = \rho(h) v(t) \left[ a(t) - \frac{v(t)^2}{2H} \right] = 0\]

Since \(\rho(h) > 0\) and \(v(t^*) > 0\), the vanishing of the bracket yields the universal fundamental kinematic condition for Max-\(Q\): \[\boxed{a(t^*) = \frac{v(t^*)^2}{2H}}\]

At the moment of Max-\(Q\), the vehicle’s forward acceleration \(a(t^*)\) exactly equals half the square of its speed divided by the atmospheric scale height \(H\).

2.3 2.3 Throttle-Down Regimes and Structural Load Mitigation

Max-\(Q\) typically occurs between \(60\) and \(85\) seconds after liftoff, at altitudes between \(11\text{ km}\) and \(15\text{ km}\) (near the tropopause), when the rocket is traveling at transonic or low supersonic speeds (\(\text{Mach } 1.3 - 2.0\)).

Because aerodynamic drag \(D = q S C_D\) and bending moments scale linearly with \(q\), exceeding structural limits (\(q_{\text{max}} \sim 35 - 45\text{ kPa}\)) risks catastrophic vehicle breakup. Launch vehicles actively modulate their thrust profile: * Space Shuttle: The three Space Shuttle Main Engines (SSMEs) throttled down from \(104.5\%\) to \(72\%\) rated thrust at approximately \(T+30\text{ s}\), maintaining reduced thrust until passing through Max-\(Q\) at \(T+65\text{ s}\), then throttling back up to \(104.5\%\). * Falcon 9: The central nine Merlin 1D engines throttle down during the transonic transition to cap dynamic pressure below \(38\text{ kPa}\), avoiding excessive aerodynamic forces on the payload fairing.

3 3. Ascent Trajectory: The Roll Program, Pitchover, and Gravity Turns

A rocket cannot reach orbit simply by flying straight up. Vertical flight expends enormous energy fighting gravitational potential energy without establishing horizontal velocity. Orbital velocity at low Earth orbit (LEO, \(\approx 300\text{ km}\)) requires: \[v_{\text{orbit}} = \sqrt{\frac{G M_\oplus}{R_\oplus + h}} \approx 7.73\text{ km/s} \quad (\approx 27,800\text{ km/h})\]

Thus, over \(90\%\) of the energy expended during orbital ascent goes into gaining horizontal tangential velocity, not vertical altitude.

3.1 3.1 The Roll Program

Immediately after clearing the launch umbilical tower (typically \(T+8\text{ s}\) to \(T+12\text{ s}\)), the flight computer commands a simultaneous roll and pitch maneuver: 1. Roll Axis Realignment: The rocket rotates about its longitudinal axis to align its pitch plane with the target orbital inclination \(\beta_0\). For Cape Canaveral launches (\(28.5^\circ\text{ N}\)), launching due east yields \(\beta_0 = 28.5^\circ\), maximizing the Earth’s rotational assist (\(v_{\text{Earth}} = \omega_\oplus R_\oplus \cos(28.5^\circ) \approx 409\text{ m/s}\)). 2. Structural Orientation: Vehicles like the Space Shuttle rolled “heads down” (orbiter hanging beneath the external tank) to direct the aerodynamic lift vector toward the Earth, minimizing aerodynamic bending stress on the orbiter-tank attachment struts.

3.2 3.2 The Gravity Turn (Zero-Lift Trajectory)

At an altitude of \(1\text{ to }2\text{ km}\), once aerodynamic control surfaces or gimballing thrusters impart a small initial pitch angle \(\theta_0 \sim 1^\circ - 3^\circ\) away from the local vertical, the vehicle ceases active aerodynamic pitching and initiates a natural gravity turn.

Let \(\gamma(t)\) be the flight path angle relative to the horizontal (\(\gamma = 90^\circ\) is pure vertical flight; \(\gamma = 0^\circ\) is pure horizontal flight). By maintaining an angle of attack \(\alpha \equiv 0\) (thrust aligned identically with the velocity vector \(\mathbf{v}\)), the lift force vanishes (\(L = 0\)), eliminating structural cross-wind shears. Gravity exerts a perpendicular component \(g \cos\gamma\) that naturally curves the velocity vector toward the horizontal:

\[\frac{dv}{dt} = \frac{T(t) - D(v, h)}{m(t)} - g(h) \sin\gamma\] \[v \frac{d\gamma}{dt} = -g(h) \cos\gamma + \frac{T \sin\alpha}{m(t)} \xrightarrow{\alpha = 0} \frac{d\gamma}{dt} = -\frac{g(h) \cos\gamma}{v}\]

Integrating this system demonstrates how Earth’s gravitational acceleration smoothly rotates the velocity vector from vertical at liftoff to horizontal at orbital insertion.

4 4. Multi-Stage Staging Dynamics and Jettisoning

The single-stage-to-orbit (SSTO) concept is rendered virtually impossible on Earth due to the logarithmic nature of Tsiolkovsky’s equation: \[\Delta v = v_e \ln\left(\frac{m_0}{m_f}\right) = v_e \ln\left(\frac{m_{\text{payload}} + m_{\text{structure}} + m_{\text{propellant}}}{m_{\text{payload}} + m_{\text{structure}}}\right)\]

For typical hydrolox (\(I_{\text{sp}} \approx 450\text{ s}, v_e \approx 4410\text{ m/s}\)) or kerolox (\(I_{\text{sp}} \approx 310\text{ s}, v_e \approx 3040\text{ m/s}\)) engines, achieving the required \(\Delta v_{\text{LEO}} \approx 9.3\text{ km/s}\) (including gravity losses \(\approx 1.2\text{ km/s}\) and aerodynamic drag losses \(\approx 0.3\text{ km/s}\)) requires a mass ratio: \[\frac{m_0}{m_f} = \exp\left(\frac{9300}{3040}\right) \approx 21.3 \implies \frac{m_f}{m_0} \approx 0.047\]

Less than \(4.7\%\) of the initial pad mass can be empty tanks, engines, avionics, and payload combined.

4.1 4.1 Stage Jettisoning Physics

Staging circumvents this fundamental limit by physically discarding dry structural mass (empty fuel tanks, plumbing, and oversized sea-level first-stage engines) once their propellant is depleted:

The instantaneous acceleration jumps upward: \[a(t_{\text{sep}}^+) = \frac{T_2}{m(t_{\text{sep}}^+)} \gg \frac{T_1}{m(t_{\text{sep}}^-)}\]

5 5. Satellites and Orbital Insertion: The Perigee Kick Motor (PKM)

A critical concept frequently encountered in space missions—such as the historical deployment of Intelsat communication satellites, early GPS constellations, and planetary probes—is the Perigee Kick Motor (PKM) and its counterpart, the Apogee Kick Motor (AKM).

5.1 5.1 The Geostationary Orbit (GEO) Challenge

Geostationary satellites must orbit at an altitude where their orbital period matches Earth’s sidereal rotation period (\(T_{\text{sidereal}} \approx 86164.1\text{ s} \approx 23.934\text{ hours}\)): \[r_{\text{GEO}} = \left( \frac{G M_\oplus T^2}{4\pi^2} \right)^{1/3} \approx 42,164\text{ km} \implies h_{\text{GEO}} = r_{\text{GEO}} - R_\oplus \approx 35,786\text{ km}\]

Launch vehicles like the Space Shuttle, Ariane 4/5, Atlas V, or Falcon 9 typically cannot deliver massive payloads directly into a circular \(35,786\text{ km}\) equatorial orbit without enormous cost. Instead, missions use multi-burn orbital transfer mechanics.

5.2 5.2 What Exactly is a Perigee Kick Motor (PKM)?

  1. Deployment into Low Parking Orbit (LEO): The primary launch vehicle (or Space Shuttle orbiter) releases the satellite with its attached booster into a low circular parking orbit (\(h_p \approx 200 - 300\text{ km}\), speed \(v_{\text{LEO}} \approx 7.7\text{ km/s}\)).
  2. The Perigee Burn (The “Kick”): To transfer from LEO to GEO, the satellite needs an elliptical Hohmann Geostationary Transfer Orbit (GTO) whose perigee is in LEO (\(r_p \approx 6,678\text{ km}\)) and whose apogee reaches GEO altitude (\(r_a \approx 42,164\text{ km}\)). The speed required at perigee of this GTO is: \[v_{p,\text{GTO}} = \sqrt{2 \mu_\oplus \left( \frac{1}{r_p} - \frac{1}{r_p + r_a} \right)} = \sqrt{\frac{2(398600)}{6678}\left(1 - \frac{6678}{48842}\right)} \approx 10.15\text{ km/s}\] The velocity increment that must be supplied at perigee is: \[\Delta v_{\text{PKM}} = v_{p,\text{GTO}} - v_{\text{LEO}} \approx 10.15 - 7.73 \approx 2.42\text{ km/s}\] The dedicated rocket engine that provides this violent, impulsive \(2.42\text{ km/s}\) burn at perigee is precisely the Perigee Kick Motor (PKM)!
  3. The Intelsat Paradigm: In the Space Shuttle era, commercial communication satellites like the Intelsat VI and Hughes HS-376 / HS-393 series were deployed directly from the Shuttle cargo bay at \(300\text{ km}\) altitude. Because the Shuttle could not fly any higher, the satellite stack was equipped with a massive solid-propellant PKM (such as the McDonnell Douglas PAM-D / Star 48B, or the Orbus-21S). Once cleared from the Shuttle bay, the PKM fired at perigee to kick the satellite into GTO.
  4. Apogee Kick Motor (AKM): Once the satellite coasts up to apogee (\(r_a = 42,164\text{ km}\), where speed slows to \(v_{a,\text{GTO}} \approx 1.61\text{ km/s}\)), an Apogee Kick Motor (AKM) fires to supply the remaining \(\Delta v_{\text{AKM}} = v_{\text{GEO}} - v_{a,\text{GTO}} \approx 3.07 - 1.61 = 1.46\text{ km/s}\) (plus plane change inclination correction), circularizing the orbit into final GEO.

6 6. Complete Mathematical Trajectory Formulation for Numerical Simulation

To simulate the ascent of a heavy launch vehicle through liftoff, transonic climb, Max-\(Q\), throttle bucket, and stage separation, we formulate the non-linear coupled differential system in 2D polar flight dynamics:

\[\begin{aligned} \frac{dh}{dt} &= v(t) \sin\gamma(t) \\ \frac{dx}{dt} &= v(t) \cos\gamma(t) \\ \frac{dv}{dt} &= \frac{T(t) - D(v, h)}{m(t)} - g(h) \sin\gamma(t) \\ \frac{d\gamma}{dt} &= -\frac{g(h) \cos\gamma(t)}{v(t)} \quad (\text{for } t > t_{\text{pitch}}) \\ \frac{dm}{dt} &= -\dot{m}(t) \end{aligned}\]

where: * \(g(h) = g_0 \left(\frac{R_\oplus}{R_\oplus + h}\right)^2\) is the inverse-square gravitational acceleration. * \(D(v, h) = \frac{1}{2} \rho_0 e^{-h/H} v^2 S C_D(M)\) is the Mach-dependent aerodynamic drag. * Dynamic pressure is logged continuously as \(q(t) = \frac{1}{2} \rho(h(t)) v(t)^2\).

7 7. High-Performance Multi-Language RK4 Trajectory Engine

We now implement this complete trajectory simulation identically across Python 3, C++20, Rust, Julia, Modern Fortran, and MATLAB. Each program executes a 4th-order Runge-Kutta numerical integrator with: * Vehicle Liftoff Mass: \(m_0 = 549,054\text{ kg}\) * Stage 1 Thrust: \(T_0 = 7,607,000\text{ N}\) (Sea level) * Specific Impulse: \(I_{\text{sp}} = 282\text{ s} \implies \dot{m} = \frac{T}{g_0 I_{\text{sp}}} \approx 2,750\text{ kg/s}\) * Cross-sectional Area: \(S = 10.52\text{ m}^2\), \(C_D = 0.30\) * Scale Height: \(H = 8,500\text{ m}\), \(\rho_0 = 1.225\text{ kg/m}^3\) * Pitchover kick at \(t = 10\text{ s}\) to initiate gravity turn * Stage 1 burn duration: \(t_{\text{MECO}} = 162\text{ s}\) * Tracking and reporting the exact maximum dynamic pressure \(q_{\text{max}}\), time of Max-\(Q\), altitude, and velocity.

import numpy as np

def simulate_rocket():
    # Physical Constants
    g0 = 9.80665
    R_earth = 6371000.0
    rho0 = 1.225
    H = 8500.0
    
    # Rocket Architecture (Falcon 9 / Kerolox class)
    m0 = 549054.0        # Initial gross liftoff mass [kg]
    T_sl = 7607000.0     # Stage 1 thrust [N]
    Isp = 282.0          # Sea-level specific impulse [s]
    m_dot = T_sl / (g0 * Isp)  # Mass flow rate [kg/s]
    S = 10.52            # Aerodynamic reference area [m^2]
    Cd = 0.30            # Drag coefficient
    
    # Simulation Parameters
    dt = 0.05
    t_max = 160.0
    steps = int(t_max / dt)
    
    # State Vector: [h (alt), x (range), v (speed), gamma (flight path angle), m (mass)]
    h = 0.0
    x = 0.0
    v = 0.0
    gamma = np.radians(89.8)  # Near vertical
    m = m0
    t = 0.0
    
    max_q = 0.0
    t_max_q = 0.0
    h_max_q = 0.0
    v_max_q = 0.0
    
    def derivatives(t_curr, state):
        h_c, x_c, v_c, gam_c, m_c = state
        
        # Local gravity
        g_c = g0 * (R_earth / (R_earth + max(0.0, h_c)))**2
        
        # Atmospheric density
        rho_c = rho0 * np.exp(-max(0.0, h_c) / H) if h_c < 120000.0 else 0.0
        
        # Aerodynamic drag
        D_c = 0.5 * rho_c * v_c**2 * S * Cd
        
        # Thrust profile (with throttle bucket between 45s and 75s)
        if 45.0 <= t_curr <= 75.0:
            thrust = 0.72 * T_sl  # Throttle down for Max-Q
            flow = 0.72 * m_dot
        else:
            thrust = T_sl
            flow = m_dot
            
        dh = v_c * np.sin(gam_c)
        dx = v_c * np.cos(gam_c)
        
        # Acceleration
        dv = (thrust - D_c) / m_c - g_c * np.sin(gam_c)
        
        # Gravity turn pitch rate (active after 10 seconds)
        if t_curr > 10.0 and v_c > 1.0:
            dgamma = - (g_c * np.cos(gam_c)) / v_c
        else:
            dgamma = 0.0
            
        dm = -flow
        return np.array([dh, dx, dv, dgamma, dm])
    
    state = np.array([h, x, v, gamma, m])
    
    for step in range(steps):
        h_c, x_c, v_c, gam_c, m_c = state
        rho_c = rho0 * np.exp(-max(0.0, h_c) / H) if h_c < 120000.0 else 0.0
        q = 0.5 * rho_c * v_c**2
        
        if q > max_q:
            max_q = q
            t_max_q = t
            h_max_q = h_c
            v_max_q = v_c
            
        # RK4 Integration
        k1 = derivatives(t, state)
        k2 = derivatives(t + 0.5 * dt, state + 0.5 * dt * k1)
        k3 = derivatives(t + 0.5 * dt, state + 0.5 * dt * k2)
        k4 = derivatives(t + dt, state + dt * k3)
        
        state += (dt / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4)
        t += dt

    print(f"Python 3 Rocket Trajectory Simulation:")
    print(f"  Max-Q Dynamic Pressure: {max_q / 1000.0:.2f} kPa")
    print(f"  Time of Max-Q:          {t_max_q:.2f} s")
    print(f"  Altitude at Max-Q:      {h_max_q / 1000.0:.2f} km")
    print(f"  Velocity at Max-Q:      {v_max_q:.2f} m/s (Mach {v_max_q / 310.0:.2f})")
    print(f"  MECO Altitude (160s):   {state[0] / 1000.0:.2f} km")
    print(f"  MECO Velocity (160s):   {state[2]:.2f} m/s")

if __name__ == "__main__":
    simulate_rocket()

struct State {

    x: f64,
    v: f64,
    gamma: f64,
    m: f64,

impl State {
    fn add(&self, other: &State) -> State {
        State {
            h: self.h + other.h,
            x: self.x + other.x,
            v: self.v + other.v,
            gamma: self.gamma + other.gamma,
            m: self.m + other.m,
        }
    }

    fn scale(&self, s: f64) -> State {
        State {
            h: self.h * s,
            x: self.x * s,
            v: self.v * s,
            gamma: self.gamma * s,
            m: self.m * s,
        }
    }
}

fn derivatives(t_curr: f64, s: &State, g0: f64, r_earth: f64, rho0: f64, h_scale: f64, t_sl: f64, m_dot: f64, s_ref: f64, cd: f64) -> State {
    let g_c = g0 * (r_earth / (r_earth + s.h.max(0.0))).powi(2);
    let rho_c = if s.h < 120_000.0 {
        rho0 * (-s.h.max(0.0) / h_scale).exp()
    } else {
        0.0
    };
    let d_c = 0.5 * rho_c * s.v * s.v * s_ref * cd;

    let (thrust, flow) = if (45.0..=75.0).contains(&t_curr) {
        (0.72 * t_sl, 0.72 * m_dot)
    } else {
        (t_sl, m_dot)
    };

    let dh = s.v * s.gamma.sin();
    let dx = s.v * s.gamma.cos();
    let dv = (thrust - d_c) / s.m - g_c * s.gamma.sin();
    let dgamma = if t_curr > 10.0 && s.v > 1.0 {
        -(g_c * s.gamma.cos()) / s.v
    } else {
        0.0
    };
    let dm = -flow;

    State { h: dh, x: dx, v: dv, gamma: dgamma, m: dm }
}

## 1. Introduction: The Conservation of Momentum in Open Variable-Mass Systems

Classical Newtonian mechanics is routinely introduced under the assumption of constant mass: $\mathbf{F} = m \mathbf{a}$. However, a launch vehicle is an open thermodynamic system that operates precisely by expelling propellant at hypersonic exhaust velocities. At liftoff, over $90\%$ of a launch vehicle's total gross mass consists of chemical propellants (liquid oxygen, RP-1, liquid hydrogen, or solid binders). 

Applying $\mathbf{F} = \frac{d\mathbf{P}}{dt} = m \frac{d\mathbf{v}}{dt} + \mathbf{v} \frac{dm}{dt}$ directly to a variable-mass body is a notorious classical error violating Galilean invariance. Instead, we must apply Newton's second law to an isolated system of constant total mass consisting of the rocket mass $m(t)$ and an infinitesimal packet of exhaust mass $dm_e = -\dot{m} dt$ expelled during an infinitesimal time interval $dt$.

```
           Control Volume at time t:
           +-----------------------+
           | Rocket Mass: m(t)     | ---> Velocity: v(t)
           +-----------------------+
           
           Control Volume at time t + dt:
           +-----------------------+                    +-----------------+
    <---   | Exhaust: dm_e = -dm   |                    | Rocket: m + dm  | ---> v + dv
  v - v_e  +-----------------------+                    +-----------------+
```

### 1.1 First-Principles Derivation of the Equation of Motion

Consider the system momentum at time $t$:
$$\mathbf{P}(t) = m(t) \mathbf{v}(t)$$

At time $t + dt$, the rocket mass becomes $m + dm$ (where $dm < 0$), moving with velocity $\mathbf{v} + d\mathbf{v}$. Concurrently, an exhaust mass $dm_e = -dm > 0$ has been ejected with velocity $\mathbf{v}_e^{\text{inertial}} = \mathbf{v} - \mathbf{v}_e$ relative to the inertial frame, where $\mathbf{v}_e$ is the effective relative exhaust velocity directed opposite to the thrust vector:
$$\mathbf{P}(t + dt) = (m + dm)(\mathbf{v} + d\mathbf{v}) + (-dm)(\mathbf{v} - \mathbf{v}_e)$$

Expanding the products and dropping the second-order differential $dm\, d\mathbf{v}$:
$$\mathbf{P}(t + dt) = m\mathbf{v} + m\,d\mathbf{v} + \mathbf{v}\,dm - \mathbf{v}\,dm + \mathbf{v}_e\,dm = m\mathbf{v} + m\,d\mathbf{v} + \mathbf{v}_e\,dm$$

The net change in linear momentum is therefore:
$$d\mathbf{P} = \mathbf{P}(t + dt) - \mathbf{P}(t) = m\,d\mathbf{v} + \mathbf{v}_e\,dm$$

Equating the rate of change of momentum to the external forces $\mathbf{F}_{\text{ext}}$ (gravity $\mathbf{F}_g$ and aerodynamic forces $\mathbf{F}_{\text{aero}}$):
$$\mathbf{F}_{\text{ext}} = \frac{d\mathbf{P}}{dt} = m \frac{d\mathbf{v}}{dt} + \mathbf{v}_e \frac{dm}{dt}$$

Rearranging gives the celebrated **Meshtchersky equation of motion for a variable-mass vehicle**:
$$m(t) \frac{d\mathbf{v}}{dt} = -\mathbf{v}_e \frac{dm}{dt} + \mathbf{F}_{\text{ext}} = \mathbf{T}(t) + \mathbf{D}(v, h) + m(t)\mathbf{g}(h)$$

where:
* $\mathbf{T}(t) = -\mathbf{v}_e \frac{dm}{dt} = \dot{m} v_e \hat{\mathbf{u}}_T$ is the **thrust force**, with propellant mass flow rate $\dot{m} = -\frac{dm}{dt} > 0$.
* When considering nozzle exit pressure $p_e$ against ambient atmospheric pressure $p_a(h)$ across nozzle exit area $A_e$, the effective exhaust velocity $v_e$ encompasses the pressure thrust:
  $$T = \dot{m} v_e = \dot{m} v_{\text{exit}} + (p_e - p_a(h)) A_e$$

## 2. Atmospheric Modeling and the Aerodynamic Dynamic Pressure Peak (Max-$Q$)

As a rocket climbs vertically from the launch pad, it encounters two conflicting physical gradients:
1. **Kinematic Velocity Growth**: Under continuous thrust, the vehicle accelerates rapidly, so velocity $v(t)$ increases monotonically from $v(0) = 0$ to several kilometers per second.
2. **Exponential Atmospheric Decay**: The density of the planetary atmosphere $\rho(h)$ decays exponentially with altitude $h$.

The structural aerodynamic stress exerted on the rocket skin, fairings, and interstages is governed by the **dynamic pressure** $q(t)$.

### 2.1 Mathematical Formulation of Dynamic Pressure

The fluid dynamic pressure $q$ represents the kinetic energy per unit volume of the fluid stream colliding with the vehicle:
$$q(t) = \frac{1}{2} \rho(h(t)) v(t)^2$$

Assuming an isothermal barometric atmosphere with sea-level density $\rho_0 \approx 1.225\text{ kg/m}^3$ and atmospheric scale height $H \approx 8500\text{ m}$:
$$\rho(h) = \rho_0 \exp\left(-\frac{h}{H}\right)$$

Substituting the atmospheric profile into the dynamic pressure equation:
$$q(t) = \frac{1}{2} \rho_0 \exp\left(-\frac{h(t)}{H}\right) v(t)^2$$

### 2.2 Analytical Extremum Condition for Max-$Q$

Because $q(0) = 0$ (since $v(0) = 0$) and $\lim_{t \to \infty} q(t) = 0$ (as the rocket enters the vacuum of outer space where $\rho \to 0$), Rolle's Theorem guarantees that $q(t)$ must attain at least one local maximum at some critical flight time $t^*$, known in aerospace engineering as **Maximum Dynamic Pressure** or **Max-$Q$**.

To find the exact physical condition at Max-$Q$, we differentiate $q(t)$ with respect to time $t$ and set the derivative to zero:
$$\frac{dq}{dt} = \frac{1}{2} \left[ \frac{d\rho}{dt} v^2 + 2 \rho v \frac{dv}{dt} \right] = 0$$

Using the chain rule on the density gradient:
$$\frac{d\rho}{dt} = \frac{d\rho}{dh} \frac{dh}{dt} = \left(-\frac{1}{H} \rho_0 e^{-h/H}\right) \dot{h} = -\frac{\rho(h)}{H} v_z(t)$$

For a near-vertical initial climb where vertical velocity $v_z(t) \approx v(t)$:
$$\frac{dq}{dt} = \frac{1}{2} \left[ -\frac{\rho(h) v}{H} v^2 + 2\rho(h) v a(t) \right] = \rho(h) v(t) \left[ a(t) - \frac{v(t)^2}{2H} \right] = 0$$

Since $\rho(h) > 0$ and $v(t^*) > 0$, the vanishing of the bracket yields the **universal fundamental kinematic condition for Max-$Q$**:
$$\boxed{a(t^*) = \frac{v(t^*)^2}{2H}}$$

At the moment of Max-$Q$, the vehicle's forward acceleration $a(t^*)$ exactly equals half the square of its speed divided by the atmospheric scale height $H$.

```
   q(t) Dynamic Pressure [kPa]
     ^
  40 |                * Max-Q Peak (~35-40 kPa)
     |               / \
  30 |              /   \
     |             /     \   <-- Rapid drop in vacuum
  20 |            /       \
     |           /         \
  10 |          /           \
     |         /             \
   0 +--------+-------+-------+------------->
     0       30      60      90     120    t [seconds]
     Liftoff         Throttle Down
```

### 2.3 Throttle-Down Regimes and Structural Load Mitigation

Max-$Q$ typically occurs between $60$ and $85$ seconds after liftoff, at altitudes between $11\text{ km}$ and $15\text{ km}$ (near the tropopause), when the rocket is traveling at transonic or low supersonic speeds ($\text{Mach } 1.3 - 2.0$). 

Because aerodynamic drag $D = q S C_D$ and bending moments scale linearly with $q$, exceeding structural limits ($q_{\text{max}} \sim 35 - 45\text{ kPa}$) risks catastrophic vehicle breakup. Launch vehicles actively modulate their thrust profile:
* **Space Shuttle**: The three Space Shuttle Main Engines (SSMEs) throttled down from $104.5\%$ to $72\%$ rated thrust at approximately $T+30\text{ s}$, maintaining reduced thrust until passing through Max-$Q$ at $T+65\text{ s}$, then throttling back up to $104.5\%$.
* **Falcon 9**: The central nine Merlin 1D engines throttle down during the transonic transition to cap dynamic pressure below $38\text{ kPa}$, avoiding excessive aerodynamic forces on the payload fairing.

## 3. Ascent Trajectory: The Roll Program, Pitchover, and Gravity Turns

A rocket cannot reach orbit simply by flying straight up. Vertical flight expends enormous energy fighting gravitational potential energy without establishing horizontal velocity. Orbital velocity at low Earth orbit (LEO, $\approx 300\text{ km}$) requires:
$$v_{\text{orbit}} = \sqrt{\frac{G M_\oplus}{R_\oplus + h}} \approx 7.73\text{ km/s} \quad (\approx 27,800\text{ km/h})$$

Thus, over $90\%$ of the energy expended during orbital ascent goes into gaining **horizontal tangential velocity**, not vertical altitude.

```
                  Orbital Ascent Trajectory (Gravity Turn)
                  
   Altitude (h)
       ^                                      Orbital Insertion (LEO)
       |                                          v_horiz ~ 7.8 km/s
 300km |-------------------------------------------------> [Orbit]
       |                                               .-'
 150km |                                           _.-'
       |                                       _.-' (Stage 2 burn)
  70km |                                  _.-' [Stage 1 Sep / MECO]
       |                             _.-'
  15km |                        _.-' (Max-Q, Transonic)
   2km |                   _.-' (Gravity Turn Arc: alpha = 0)
       |               _.-' (Pitchover Kick: 1-2 degrees)
   0km +--------------+---------------------------------------> Ground Range (x)
             Liftoff / Roll Program
```

### 3.1 The Roll Program

Immediately after clearing the launch umbilical tower (typically $T+8\text{ s}$ to $T+12\text{ s}$), the flight computer commands a simultaneous **roll and pitch maneuver**:
1. **Roll Axis Realignment**: The rocket rotates about its longitudinal axis to align its pitch plane with the target orbital inclination $\beta_0$. For Cape Canaveral launches ($28.5^\circ\text{ N}$), launching due east yields $\beta_0 = 28.5^\circ$, maximizing the Earth's rotational assist ($v_{\text{Earth}} = \omega_\oplus R_\oplus \cos(28.5^\circ) \approx 409\text{ m/s}$).
2. **Structural Orientation**: Vehicles like the Space Shuttle rolled "heads down" (orbiter hanging beneath the external tank) to direct the aerodynamic lift vector toward the Earth, minimizing aerodynamic bending stress on the orbiter-tank attachment struts.

### 3.2 The Gravity Turn (Zero-Lift Trajectory)

At an altitude of $1\text{ to }2\text{ km}$, once aerodynamic control surfaces or gimballing thrusters impart a small initial pitch angle $\theta_0 \sim 1^\circ - 3^\circ$ away from the local vertical, the vehicle ceases active aerodynamic pitching and initiates a **natural gravity turn**.

Let $\gamma(t)$ be the flight path angle relative to the horizontal ($\gamma = 90^\circ$ is pure vertical flight; $\gamma = 0^\circ$ is pure horizontal flight). By maintaining an angle of attack $\alpha \equiv 0$ (thrust aligned identically with the velocity vector $\mathbf{v}$), the lift force vanishes ($L = 0$), eliminating structural cross-wind shears. Gravity exerts a perpendicular component $g \cos\gamma$ that naturally curves the velocity vector toward the horizontal:

$$\frac{dv}{dt} = \frac{T(t) - D(v, h)}{m(t)} - g(h) \sin\gamma$$
$$v \frac{d\gamma}{dt} = -g(h) \cos\gamma + \frac{T \sin\alpha}{m(t)} \xrightarrow{\alpha = 0} \frac{d\gamma}{dt} = -\frac{g(h) \cos\gamma}{v}$$

Integrating this system demonstrates how Earth's gravitational acceleration smoothly rotates the velocity vector from vertical at liftoff to horizontal at orbital insertion.

## 4. Multi-Stage Staging Dynamics and Jettisoning

The single-stage-to-orbit (SSTO) concept is rendered virtually impossible on Earth due to the logarithmic nature of Tsiolkovsky's equation:
$$\Delta v = v_e \ln\left(\frac{m_0}{m_f}\right) = v_e \ln\left(\frac{m_{\text{payload}} + m_{\text{structure}} + m_{\text{propellant}}}{m_{\text{payload}} + m_{\text{structure}}}\right)$$

For typical hydrolox ($I_{\text{sp}} \approx 450\text{ s}, v_e \approx 4410\text{ m/s}$) or kerolox ($I_{\text{sp}} \approx 310\text{ s}, v_e \approx 3040\text{ m/s}$) engines, achieving the required $\Delta v_{\text{LEO}} \approx 9.3\text{ km/s}$ (including gravity losses $\approx 1.2\text{ km/s}$ and aerodynamic drag losses $\approx 0.3\text{ km/s}$) requires a mass ratio:
$$\frac{m_0}{m_f} = \exp\left(\frac{9300}{3040}\right) \approx 21.3 \implies \frac{m_f}{m_0} \approx 0.047$$

Less than $4.7\%$ of the initial pad mass can be empty tanks, engines, avionics, and payload combined. 

### 4.1 Stage Jettisoning Physics

Staging circumvents this fundamental limit by physically discarding dry structural mass (empty fuel tanks, plumbing, and oversized sea-level first-stage engines) once their propellant is depleted:

```
Total Mass m(t)
    ^
m_0 |--------\
    |         \ (Stage 1 Burn: dm/dt = -m_dot_1)
    |          \
m_1 |           \
    |            | <-- Discontinuous drop: Dry Mass of Stage 1 Jettisoned (Delta m_sep)
m_2 |            +--------\
    |                      \ (Stage 2 Burn: dm/dt = -m_dot_2)
    |                       \
m_f |                        \--------> Payload in Orbit
    +------------+------------+---------------------> Time t
     0          MECO        Stage 2 Start
```

At the staging boundary $t_{\text{sep}}$, the total mass undergoes a discrete jump:
$$m(t_{\text{sep}}^+) = m(t_{\text{sep}}^-) - m_{\text{stage1, dry}}$$

The instantaneous acceleration jumps upward:
$$a(t_{\text{sep}}^+) = \frac{T_2}{m(t_{\text{sep}}^+)} \gg \frac{T_1}{m(t_{\text{sep}}^-)}$$

## 5. Satellites and Orbital Insertion: The Perigee Kick Motor (PKM)

A critical concept frequently encountered in space missions—such as the historical deployment of **Intelsat communication satellites**, early GPS constellations, and planetary probes—is the **Perigee Kick Motor (PKM)** and its counterpart, the **Apogee Kick Motor (AKM)**.

### 5.1 The Geostationary Orbit (GEO) Challenge

Geostationary satellites must orbit at an altitude where their orbital period matches Earth's sidereal rotation period ($T_{\text{sidereal}} \approx 86164.1\text{ s} \approx 23.934\text{ hours}$):
$$r_{\text{GEO}} = \left( \frac{G M_\oplus T^2}{4\pi^2} \right)^{1/3} \approx 42,164\text{ km} \implies h_{\text{GEO}} = r_{\text{GEO}} - R_\oplus \approx 35,786\text{ km}$$

Launch vehicles like the Space Shuttle, Ariane 4/5, Atlas V, or Falcon 9 typically cannot deliver massive payloads directly into a circular $35,786\text{ km}$ equatorial orbit without enormous cost. Instead, missions use multi-burn orbital transfer mechanics.

```
                          Geostationary Transfer Geometry
                          
                                    Geostationary Orbit (GEO)
                                    Radius r_GEO = 42,164 km
                                  .-'                       '-.
                               .-'                             '-.
                             .'                                   '.
                           .'                                       '.
                          /                                           \
                         /                                             \
                        ;                                               ;
                        |          Earth                                |
                        |        (O)   r_p                              |
       ==================> [LEO] ===> (Perigee)                         |
       (PKM / Upper Stage   \       . ' \                               /
        Burn at Perigee)     \    .'     \                             /
                              '. ' GTO    '.                         .'
                                '._         '.                     .'  <-- (Apogee Kick Motor
                                   '-.        '-.               .-'         Burn: AKM Circularizes
                                      '-.        '-------------'            to GEO at r_a = 42,164 km)
                                         '--..__
                                           Apogee (r_a)
```

### 5.2 What Exactly is a Perigee Kick Motor (PKM)?

1. **Deployment into Low Parking Orbit (LEO)**: The primary launch vehicle (or Space Shuttle orbiter) releases the satellite with its attached booster into a low circular parking orbit ($h_p \approx 200 - 300\text{ km}$, speed $v_{\text{LEO}} \approx 7.7\text{ km/s}$).
2. **The Perigee Burn (The "Kick")**: To transfer from LEO to GEO, the satellite needs an elliptical **Hohmann Geostationary Transfer Orbit (GTO)** whose perigee is in LEO ($r_p \approx 6,678\text{ km}$) and whose apogee reaches GEO altitude ($r_a \approx 42,164\text{ km}$).
   The speed required at perigee of this GTO is:
   $$v_{p,\text{GTO}} = \sqrt{2 \mu_\oplus \left( \frac{1}{r_p} - \frac{1}{r_p + r_a} \right)} = \sqrt{\frac{2(398600)}{6678}\left(1 - \frac{6678}{48842}\right)} \approx 10.15\text{ km/s}$$
   The velocity increment that must be supplied at perigee is:
   $$\Delta v_{\text{PKM}} = v_{p,\text{GTO}} - v_{\text{LEO}} \approx 10.15 - 7.73 \approx 2.42\text{ km/s}$$
   The dedicated rocket engine that provides this violent, impulsive $2.42\text{ km/s}$ burn at perigee is precisely the **Perigee Kick Motor (PKM)**!
3. **The Intelsat Paradigm**: In the Space Shuttle era, commercial communication satellites like the **Intelsat VI** and **Hughes HS-376 / HS-393** series were deployed directly from the Shuttle cargo bay at $300\text{ km}$ altitude. Because the Shuttle could not fly any higher, the satellite stack was equipped with a massive solid-propellant PKM (such as the McDonnell Douglas PAM-D / Star 48B, or the Orbus-21S). Once cleared from the Shuttle bay, the PKM fired at perigee to kick the satellite into GTO.
4. **Apogee Kick Motor (AKM)**: Once the satellite coasts up to apogee ($r_a = 42,164\text{ km}$, where speed slows to $v_{a,\text{GTO}} \approx 1.61\text{ km/s}$), an **Apogee Kick Motor (AKM)** fires to supply the remaining $\Delta v_{\text{AKM}} = v_{\text{GEO}} - v_{a,\text{GTO}} \approx 3.07 - 1.61 = 1.46\text{ km/s}$ (plus plane change inclination correction), circularizing the orbit into final GEO.

## 6. Complete Mathematical Trajectory Formulation for Numerical Simulation

To simulate the ascent of a heavy launch vehicle through liftoff, transonic climb, Max-$Q$, throttle bucket, and stage separation, we formulate the non-linear coupled differential system in 2D polar flight dynamics:

$$\begin{aligned}
\frac{dh}{dt} &= v(t) \sin\gamma(t) \\
\frac{dx}{dt} &= v(t) \cos\gamma(t) \\
\frac{dv}{dt} &= \frac{T(t) - D(v, h)}{m(t)} - g(h) \sin\gamma(t) \\
\frac{d\gamma}{dt} &= -\frac{g(h) \cos\gamma(t)}{v(t)} \quad (\text{for } t > t_{\text{pitch}}) \\
\frac{dm}{dt} &= -\dot{m}(t)
\end{aligned}$$

where:
* $g(h) = g_0 \left(\frac{R_\oplus}{R_\oplus + h}\right)^2$ is the inverse-square gravitational acceleration.
* $D(v, h) = \frac{1}{2} \rho_0 e^{-h/H} v^2 S C_D(M)$ is the Mach-dependent aerodynamic drag.
* Dynamic pressure is logged continuously as $q(t) = \frac{1}{2} \rho(h(t)) v(t)^2$.

```python
import numpy as np

def simulate_rocket():
    # Physical Constants
    g0 = 9.80665
    R_earth = 6371000.0
    rho0 = 1.225
    H = 8500.0
    
    # Rocket Architecture (Falcon 9 / Kerolox class)
    m0 = 549054.0        # Initial gross liftoff mass [kg]
    T_sl = 7607000.0     # Stage 1 thrust [N]
    Isp = 282.0          # Sea-level specific impulse [s]
    m_dot = T_sl / (g0 * Isp)  # Mass flow rate [kg/s]
    S = 10.52            # Aerodynamic reference area [m^2]
    Cd = 0.30            # Drag coefficient
    
    # Simulation Parameters
    dt = 0.05
    t_max = 160.0
    steps = int(t_max / dt)
    
    # State Vector: [h (alt), x (range), v (speed), gamma (flight path angle), m (mass)]
    h = 0.0
    x = 0.0
    v = 0.0
    gamma = np.radians(89.8)  # Near vertical
    m = m0
    t = 0.0
    
    max_q = 0.0
    t_max_q = 0.0
    h_max_q = 0.0
    v_max_q = 0.0
    
    def derivatives(t_curr, state):
        h_c, x_c, v_c, gam_c, m_c = state
        
        # Local gravity
        g_c = g0 * (R_earth / (R_earth + max(0.0, h_c)))**2
        
        # Atmospheric density
        rho_c = rho0 * np.exp(-max(0.0, h_c) / H) if h_c < 120000.0 else 0.0
        
        # Aerodynamic drag
        D_c = 0.5 * rho_c * v_c**2 * S * Cd
        
        # Thrust profile (with throttle bucket between 45s and 75s)
        if 45.0 <= t_curr <= 75.0:
            thrust = 0.72 * T_sl  # Throttle down for Max-Q
            flow = 0.72 * m_dot
        else:
            thrust = T_sl
            flow = m_dot
            
        dh = v_c * np.sin(gam_c)
        dx = v_c * np.cos(gam_c)
        
        # Acceleration
        dv = (thrust - D_c) / m_c - g_c * np.sin(gam_c)
        
        # Gravity turn pitch rate (active after 10 seconds)
        if t_curr > 10.0 and v_c > 1.0:
            dgamma = - (g_c * np.cos(gam_c)) / v_c
        else:
            dgamma = 0.0
            
        dm = -flow
        return np.array([dh, dx, dv, dgamma, dm])
    
    state = np.array([h, x, v, gamma, m])
    
    for step in range(steps):
        h_c, x_c, v_c, gam_c, m_c = state
        rho_c = rho0 * np.exp(-max(0.0, h_c) / H) if h_c < 120000.0 else 0.0
        q = 0.5 * rho_c * v_c**2
        
        if q > max_q:
            max_q = q
            t_max_q = t
            h_max_q = h_c
            v_max_q = v_c
            
        # RK4 Integration
        k1 = derivatives(t, state)
        k2 = derivatives(t + 0.5 * dt, state + 0.5 * dt * k1)
        k3 = derivatives(t + 0.5 * dt, state + 0.5 * dt * k2)
        k4 = derivatives(t + dt, state + dt * k3)
        
        state += (dt / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4)
        t += dt

    print(f"Python 3 Rocket Trajectory Simulation:")
    print(f"  Max-Q Dynamic Pressure: {max_q / 1000.0:.2f} kPa")
    print(f"  Time of Max-Q:          {t_max_q:.2f} s")
    print(f"  Altitude at Max-Q:      {h_max_q / 1000.0:.2f} km")
    print(f"  Velocity at Max-Q:      {v_max_q:.2f} m/s (Mach {v_max_q / 310.0:.2f})")
    print(f"  MECO Altitude (160s):   {state[0] / 1000.0:.2f} km")
    print(f"  MECO Velocity (160s):   {state[2]:.2f} m/s")

if __name__ == "__main__":
    simulate_rocket()
```

```rust
use std::f64::consts::PI;

#[derive(Clone, Copy)]
struct State {
    h: f64,
    x: f64,
    v: f64,
    gamma: f64,
    m: f64,
}

impl State {
    fn add(&self, other: &State) -> State {
        State {
            h: self.h + other.h,
            x: self.x + other.x,
            v: self.v + other.v,
            gamma: self.gamma + other.gamma,
            m: self.m + other.m,
        }
    }

    fn scale(&self, s: f64) -> State {
        State {
            h: self.h * s,
            x: self.x * s,
            v: self.v * s,
            gamma: self.gamma * s,
            m: self.m * s,
        }
    }
}

fn derivatives(t_curr: f64, s: &State, g0: f64, r_earth: f64, rho0: f64, h_scale: f64, t_sl: f64, m_dot: f64, s_ref: f64, cd: f64) -> State {
    let g_c = g0 * (r_earth / (r_earth + s.h.max(0.0))).powi(2);
    let rho_c = if s.h < 120_000.0 {
        rho0 * (-s.h.max(0.0) / h_scale).exp()
    } else {
        0.0
    };
    let d_c = 0.5 * rho_c * s.v * s.v * s_ref * cd;

    let (thrust, flow) = if (45.0..=75.0).contains(&t_curr) {
        (0.72 * t_sl, 0.72 * m_dot)
    } else {
        (t_sl, m_dot)
    };

    let dh = s.v * s.gamma.sin();
    let dx = s.v * s.gamma.cos();
    let dv = (thrust - d_c) / s.m - g_c * s.gamma.sin();
    let dgamma = if t_curr > 10.0 && s.v > 1.0 {
        -(g_c * s.gamma.cos()) / s.v
    } else {
        0.0
    };
    let dm = -flow;

    State { h: dh, x: dx, v: dv, gamma: dgamma, m: dm }
}
```
