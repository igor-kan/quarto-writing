1 1. Introduction: The Crisis of Standard Numerical Integration

Phase Space Distortion: RK4 violates Liouville’s Theorem. It contracts or expands the differential volume of phase space, destroying the statistical mechanics of the system. 3. Broken First Integrals: Angular momentum, Laplace-Runge-Lenz vectors, and adiabatic invariants are steadily destroyed by secular numerical accumulation.

2 2. Symplectic Geometry and Hamiltonian Phase Space

2.1 2.1 The Symplectic 2-Form and Phase Space Manifold

Let \(\mathcal{Q}\) be an \(n\)-dimensional configuration manifold with generalized coordinates \(\vec{q} = (q_1, \dots, q_n)\). The state space of Hamiltonian mechanics is the cotangent bundle: \[\mathcal{M} = T^* \mathcal{Q}\] known as phase space, parameterized by canonical coordinates \(\vec{z} = (\vec{q}, \vec{p}) = (q_1, \dots, q_n, p_1, \dots, p_n) \in \mathbb{R}^{2n}\).

Phase space is endowed with a canonical, closed, non-degenerate differential 2-form, the symplectic form: \[\omega = \sum_{i=1}^n dq_i \wedge dp_i\]

In matrix notation, for any two tangent vectors \(\vec{\xi}, \vec{\eta} \in T_z \mathcal{M}\): \[\omega(\vec{\xi}, \vec{\eta}) = \vec{\xi}^T \Omega \vec{\eta}, \quad \text{where } \Omega = \begin{pmatrix} \mathbf{0}_n & \mathbf{I}_n \\ -\mathbf{I}_n & \mathbf{0}_n \end{pmatrix}\] The fundamental symplectic matrix \(\Omega\) satisfies: \[\Omega^T = -\Omega, \quad \Omega^2 = -\mathbf{I}_{2n}, \quad \Omega^{-1} = -\Omega\]

2.2 2.2 Symplectic Maps and Liouville’s Theorem

Definition 1 (Definition 2.1 (Symplectic Transformation)) A smooth transformation \(\psi: \mathcal{M} \to \mathcal{M}\) with Jacobian matrix \(J = \frac{\partial \psi}{\partial \vec{z}}\) is called symplectic (or canonical) if it preserves the symplectic form: \[\psi^* \omega = \omega \iff J^T \Omega J = \Omega\]

Taking the determinant of both sides: \[\det(J^T \Omega J) = \det(\Omega) \implies (\det J)^2 \det(\Omega) = \det(\Omega) \implies (\det J)^2 = 1\] In fact, every connected symplectic transformation has: \[\det(J) = +1\]

2.2.1 Liouville’s Theorem as an Exterior Derivative Consequence:

The \(2n\)-dimensional phase space volume element is given by the top exterior power of \(\omega\): \[d\mathcal{V} = \frac{(-1)^{n(n-1)/2}}{n!} \underbrace{\omega \wedge \omega \wedge \dots \wedge \omega}_{n \text{ times}} = dq_1 \wedge \dots \wedge dq_n \wedge dp_1 \wedge \dots \wedge dp_n\] Because \(\psi^* \omega = \omega\), it follows immediately that: \[\psi^* d\mathcal{V} = d\mathcal{V}\] Liouville’s Theorem: The volume of any arbitrary region in phase space is strictly conserved under the continuous time-evolution flow of a Hamiltonian system.

2.3 2.3 Hamilton’s Equations and Poisson Brackets

Given a smooth Hamiltonian function \(H(\vec{q}, \vec{p}, t)\), Hamilton’s equations of motion are: \[\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}\] In compact symplectic notation: \[\dot{\vec{z}} = \Omega \nabla_{\vec{z}} H(\vec{z})\]

The Poisson Bracket of two observables \(F, G: \mathcal{M} \to \mathbb{R}\) is defined as: \[\{F, G\} = \sum_{i=1}^n \left(\frac{\partial F}{\partial q_i}\frac{\partial G}{\partial p_i} - \frac{\partial F}{\partial p_i}\frac{\partial G}{\partial q_i}\right) = (\nabla F)^T \Omega (\nabla G)\] The time evolution of any observable \(F\) is given by: \[\frac{dF}{dt} = \{F, H\} + \frac{\partial F}{\partial t}\] An observable \(F\) is a conserved first integral if and only if \(\{F, H\} = 0\).

3 3. Symplectic Integrators from First Principles

3.1 3.1 Operator Splitting and the Lie-Poisson Formalism

Consider a separable Hamiltonian describing kinetic energy \(T(\vec{p})\) and potential energy \(V(\vec{q})\): \[H(\vec{q}, \vec{p}) = T(\vec{p}) + V(\vec{q}) = \frac{1}{2} \vec{p}^T M^{-1} \vec{p} + V(\vec{q})\]

The Hamiltonian vector field generates time evolution via the formal exponential Lie operator: \[\vec{z}(t) = \exp\left(t \hat{D}_H\right) \vec{z}(0), \quad \text{where } \hat{D}_H f = \{f, H\}\] Since \(H = T + V\), the generator splits into: \[\hat{D}_H = \hat{D}_T + \hat{D}_V\] where: * \(\hat{D}_T \vec{z} = \{ \vec{z}, T \} = (M^{-1} \vec{p}, \mathbf{0})\) (Pure drift step in configuration space). * \(\hat{D}_V \vec{z} = \{ \vec{z}, V \} = (\mathbf{0}, -\nabla V(\vec{q}))\) (Pure kick step in momentum space).

Crucially, each sub-Hamiltonian \(T\) and \(V\) can be integrated EXACTLY and analytically: * The Drift Map \(\Phi_T^\tau\): \[q(t+\tau) = q(t) + \tau M^{-1} p(t), \quad p(t+\tau) = p(t)\] * The Kick Map \(\Phi_V^\tau\): \[q(t+\tau) = q(t), \quad p(t+\tau) = p(t) - \tau \nabla V(q(t))\]

Both \(\Phi_T^\tau\) and \(\Phi_V^\tau\) are exact shears in phase space, having unit Jacobian determinants: \[J_T = \begin{pmatrix} I & \tau M^{-1} \\ 0 & I \end{pmatrix} \implies \det J_T = 1, \quad J_V = \begin{pmatrix} I & 0 \\ -\tau \nabla^2 V & I \end{pmatrix} \implies \det J_V = 1\] Because the product of two symplectic matrices is symplectic, any composition of exact drift and kick maps is unconditionally, exactly symplectic!

3.2 3.2 The Verlet and Velocity-Verlet Algorithms

The 2nd-order symmetric composition (Strang splitting) gives the celebrated Velocity-Verlet integrator: \[\Psi_2^\tau = \Phi_V^{\tau/2} \circ \Phi_T^\tau \circ \Phi_V^{\tau/2}\]

3.2.1 Algorithmic Execution Steps:

  1. Half-Step Kick: \[\vec{p}_{n + 1/2} = \vec{p}_n - \frac{\tau}{2} \nabla V(\vec{q}_n)\]
  2. Full-Step Drift: \[\vec{q}_{n+1} = \vec{q}_n + \tau M^{-1} \vec{p}_{n + 1/2}\]
  3. Half-Step Kick: \[\vec{p}_{n+1} = \vec{p}_{n + 1/2} - \frac{\tau}{2} \nabla V(\vec{q}_{n+1})\]

3.2.2 Key Geometric Properties:

  • Symplectic: Exactly satisfies \(J^T \Omega J = \Omega\).
  • Time-Reversible: Inverting \(\tau \to -\tau\) and reversing velocities traces the exact identical trajectory backwards in time.
  • Global Order: \(\mathcal{O}(\tau^2)\) local error, \(\mathcal{O}(\tau^2)\) global trajectory error.

3.3 3.3 High-Order Symplectic Splitting: The Yoshida 4th-Order Integrator

Can we construct an unconditionally symplectic integrator of order 4?
In 1990, Haruo Yoshida proved that any 2nd-order symmetric integrator \(\Psi_2^\tau\) can be combined into a 4th-order symmetric symplectic integrator \(\Psi_4^\tau\) via fractal composition: \[\Psi_4^\tau = \Psi_2^{w_1 \tau} \circ \Psi_2^{w_0 \tau} \circ \Psi_2^{w_1 \tau}\]

3.3.1 Derivation of the Yoshida Coefficients:

By the Baker-Campbell-Hausdorff (BCH) formula: \[\Psi_2^\tau = \exp\left(\tau \hat{D}_H + \tau^3 \hat{D}_3 + \tau^5 \hat{D}_5 + \dots\right)\] The composition of three symmetric steps of lengths \(w_1 \tau, w_0 \tau, w_1 \tau\) yields: \[\Psi_4^\tau = \exp\left( (2w_1 + w_0) \tau \hat{D}_H + (2w_1^3 + w_0^3) \tau^3 \hat{D}_3 + \mathcal{O}(\tau^5) \right)\] To eliminate the \(\tau^3\) error term while preserving consistency ($ au^1$ coefficient equals 1): \[2w_1 + w_0 = 1\] \[2w_1^3 + w_0^3 = 0\]

Solving this non-linear algebraic system: \[w_0^3 = -2w_1^3 \implies w_0 = -2^{1/3} w_1\] Substituting into the first equation: \[2w_1 - 2^{1/3} w_1 = 1 \implies w_1 \left(2 - 2^{1/3}\right) = 1\] \[w_1 = \frac{1}{2 - 2^{1/3}} \approx 1.351207191959657\] \[w_0 = -\frac{2^{1/3}}{2 - 2^{1/3}} = 1 - 2w_1 \approx -1.702414383919315\]

(Remarkable Fact: To achieve 4th-order accuracy, the intermediate step \(w_0\) must step backwards in time!)

3.4 3.4 Backward Error Analysis and the “Shadow Hamiltonian”

Why do symplectic integrators conserve energy so extraordinarily well without secular drift?
The answer is revealed by Backward Error Analysis (Moser, Benettin, Hairer).

When you run a symplectic integrator \(\Psi^\tau\) on a Hamiltonian \(H\), the numerical points do NOT follow the exact trajectory of \(H\). Instead, they follow the EXACT trajectory of a modified “Shadow Hamiltonian” \(\tilde{H}\): \[\tilde{H}(\vec{q}, \vec{p}) = H(\vec{q}, \vec{p}) + \tau^2 H_2(\vec{q}, \vec{p}) + \tau^4 H_4(\vec{q}, \vec{p}) + \dots\]

Because \(\Psi^\tau\) is the exact flow of \(\tilde{H}\), the modified energy \(\tilde{H}(\vec{q}_n, \vec{p}_n)\) is strictly, exactly conserved! \[\tilde{H}(\vec{q}_n, \vec{p}_n) = \text{const}\] Therefore, the true physical energy \(H\) fluctuates within an extremely narrow bounded band: \[|H(\vec{q}_n, \vec{p}_n) - H(\vec{q}_0, \vec{p}_0)| = \mathcal{O}(\tau^p)\] There is zero secular drift over exponentially long times \(\sim e^{c/\tau}\)!
In contrast, standard RK4 does not possess a shadow Hamiltonian; its energy drifts linearly or quadratically with time: \(\Delta E_{\text{RK4}}(t) \sim t \tau^4\).

4.2 4.2 Chebyshev Differentiation Matrices

For non-periodic boundary value problems on \([-1, 1]\), equispaced grids cause catastrophic divergence near boundaries (Runge’s Phenomenon).
The cure is the Chebyshev-Gauss-Lobatto (CGL) grid: \[x_j = \cos\left(\frac{\pi j}{N}\right), \quad j = 0, 1, \dots, N\] These nodes are the horizontal projections of equally spaced points on the unit semicircle, clustering densely near the boundaries \(x = \pm 1\) with density \(\propto 1/\sqrt{1 - x^2}\).

The spectral derivative of an arbitrary vector of function values \(\vec{u} = (u(x_0), \dots, u(x_N))^T\) is computed via a single dense matrix-vector product: \[\vec{u}' = D_N \vec{u}\] where \(D_N\) is the Chebyshev Differentiation Matrix: \[(D_N)_{jk} = \begin{cases} \frac{c_j}{c_k} \frac{(-1)^{j+k}}{x_j - x_k} & j \neq k \\ -\frac{x_j}{2(1 - x_j^2)} & 1 \le j = k \le N - 1 \\ \frac{2N^2 + 1}{6} & j = k = 0 \\ -\frac{2N^2 + 1}{6} & j = k = N \end{cases}\] where \(c_0 = c_N = 2\) and \(c_j = 1\) otherwise.

Higher derivatives are obtained by matrix exponentiation: \(\vec{u}'' = D_N^2 \vec{u}\).

4.3 4.3 Solving the Time-Independent Schrödinger Equation (TISE)

The 1D TISE is: \[\hat{H}\psi(x) = \left(-\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + V(x)\right)\psi(x) = E\psi(x)\] Discretizing on a Chebyshev grid with \(N\) interior nodes, the differential operator becomes a finite \(N \times N\) matrix: \[H_{\text{spec}} = -\frac{\hbar^2}{2m} D_N^2 + \operatorname{diag}(V(x_0), \dots, V(x_N))\] Solving for energy eigenvalues and quantum eigenstates reduces to a standard matrix eigenvalue problem: \[H_{\text{spec}} \vec{\psi}_k = E_k \vec{\psi}_k\] This yields machine-precision quantum ground and excited states with as few as \(N = 64\) grid points!

5 5. Quantum Dynamics: Split-Operator FFT for the TDSE

The Time-Dependent Schrödinger Equation (TDSE) describes non-relativistic wavepacket dynamics: \[i\hbar \frac{\partial \psi(x, t)}{\partial t} = \left(-\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2} + V(x)\right)\psi(x, t) = (\hat{T} + \hat{V})\psi(x, t)\]

The formal solution is given by the unitary time evolution operator: \[\psi(x, t + \Delta t) = \exp\left(-\frac{i}{\hbar}(\hat{T} + \hat{V})\Delta t\right)\psi(x, t)\]

6 6. Statistical Mechanics and Markov Chain Monte Carlo (MCMC)

6.1 6.1 The Canonical Ensemble and the Combinatorial Explosion

In equilibrium statistical mechanics, the probability of finding a system in a microstate \(\sigma\) with energy \(E(\sigma)\) at temperature \(T\) is given by the Boltzmann distribution: \[P(\sigma) = \frac{1}{Z} e^{-\beta E(\sigma)}, \quad \beta = \frac{1}{k_B T}\] where the normalizer is the canonical partition function: \[Z = \sum_{\sigma \in \Omega} e^{-\beta E(\sigma)}\]

For a modest \(20 \times 20\) lattice of magnetic spins \(\sigma_i \in \{-1, +1\}\), the configuration space contains: \[|\Omega| = 2^{400} \approx 2.58 \times 10^{120} \text{ states}\] Evaluating \(Z\) by exhaustive summation would require longer than the lifetime of the universe.

6.2 6.2 The Metropolis-Hastings Algorithm

Instead of evaluating the denominator \(Z\), Markov Chain Monte Carlo (MCMC) constructs a random walk in configuration space whose stationary distribution is precisely the Boltzmann distribution.

To guarantee that the Markov chain converges to \(P(\sigma)\), the transition probabilities \(W(\sigma \to \sigma')\) must satisfy the Detailed Balance Condition: \[P(\sigma) W(\sigma \to \sigma') = P(\sigma') W(\sigma' \to \sigma)\] Rearranging: \[\frac{W(\sigma \to \sigma')}{W(\sigma' \to \sigma)} = \frac{P(\sigma')}{P(\sigma)} = \frac{e^{-\beta E(\sigma')}}{e^{-\beta E(\sigma)}} = e^{-\beta \Delta E}\] where \(\Delta E = E(\sigma') - E(\sigma)\). Notice that the intractable partition function \(Z\) cancels completely!

6.2.1 The Metropolis Acceptance Criterion:

Propose a trial move \(\sigma \to \sigma'\) by selecting a single random spin \(\sigma_i\) and flipping it (\(\sigma_i \to -\sigma_i\)).
Accept the flip with probability: \[\alpha(\sigma \to \sigma') = \min\left(1, e^{-\beta \Delta E}\right)\] * If \(\Delta E \le 0\) (the flip lowers or maintains energy), accept unconditionally (probability 1). * If \(\Delta E > 0\) (the flip raises energy), generate a uniform random number \(r \sim U(0, 1)\) and accept if: \[r < e^{-\beta \Delta E}\]

6.3 6.3 The 2D Ising Model and Onsager’s Phase Transition

The 2D ferromagnetic Ising model on a square periodic lattice of size \(L \times L\) has energy: \[E(\sigma) = -J \sum_{\langle i, j \rangle} \sigma_i \sigma_j\] where \(\langle i, j \rangle\) denotes nearest-neighbor pairs.

In 1944, Lars Onsager published an exact analytical solution for the infinite 2D Ising model, proving the existence of a continuous 2nd-order ferromagnetic phase transition at the critical temperature: \[\frac{k_B T_c}{J} = \frac{2}{\ln\left(1 + \sqrt{2}\right)} \approx 2.2691853\] Below \(T_c\), spontaneous symmetry breaking occurs: spins align into macroscopic domains with non-zero spontaneous magnetization: \[M(T) = \left(1 - \sinh^{-4}(2\beta J)\right)^{1/8} \quad (T < T_c)\]

        return p_curr, force_kepler(q_curr)

# 2. 4th-Order Symplectic Yoshida Integrator

w0 = 1.0 - 2.0 * w1

    p_next = p_half + 0.5 * tau * force_kepler(q_next)
    return q_next, p_next

    q, p = step_velocity_verlet(q, p, w0 * dt)
    q, p = step_velocity_verlet(q, p, w1 * dt)
    return q, p

## 2. Symplectic Geometry and Hamiltonian Phase Space

### 2.1 The Symplectic 2-Form and Phase Space Manifold
Let $\mathcal{Q}$ be an $n$-dimensional configuration manifold with generalized coordinates $\vec{q} = (q_1, \dots, q_n)$. The state space of Hamiltonian mechanics is the cotangent bundle:
$$\mathcal{M} = T^* \mathcal{Q}$$
known as **phase space**, parameterized by canonical coordinates $\vec{z} = (\vec{q}, \vec{p}) = (q_1, \dots, q_n, p_1, \dots, p_n) \in \mathbb{R}^{2n}$.

Phase space is endowed with a canonical, closed, non-degenerate differential 2-form, the **symplectic form**:
$$\omega = \sum_{i=1}^n dq_i \wedge dp_i$$

In matrix notation, for any two tangent vectors $\vec{\xi}, \vec{\eta} \in T_z \mathcal{M}$:
$$\omega(\vec{\xi}, \vec{\eta}) = \vec{\xi}^T \Omega \vec{\eta}, \quad \text{where } \Omega = \begin{pmatrix} \mathbf{0}_n & \mathbf{I}_n \\ -\mathbf{I}_n & \mathbf{0}_n \end{pmatrix}$$
The fundamental symplectic matrix $\Omega$ satisfies:
$$\Omega^T = -\Omega, \quad \Omega^2 = -\mathbf{I}_{2n}, \quad \Omega^{-1} = -\Omega$$

---

### 2.2 Symplectic Maps and Liouville's Theorem

::: {#def-symplectic-map}
#### Definition 2.1 (Symplectic Transformation)
A smooth transformation $\psi: \mathcal{M} \to \mathcal{M}$ with Jacobian matrix $J = \frac{\partial \psi}{\partial \vec{z}}$ is called **symplectic** (or canonical) if it preserves the symplectic form:
$$\psi^* \omega = \omega \iff J^T \Omega J = \Omega$$
:::

Taking the determinant of both sides:
$$\det(J^T \Omega J) = \det(\Omega) \implies (\det J)^2 \det(\Omega) = \det(\Omega) \implies (\det J)^2 = 1$$
In fact, every connected symplectic transformation has:
$$\det(J) = +1$$

#### Liouville's Theorem as an Exterior Derivative Consequence:
The $2n$-dimensional phase space volume element is given by the top exterior power of $\omega$:
$$d\mathcal{V} = \frac{(-1)^{n(n-1)/2}}{n!} \underbrace{\omega \wedge \omega \wedge \dots \wedge \omega}_{n \text{ times}} = dq_1 \wedge \dots \wedge dq_n \wedge dp_1 \wedge \dots \wedge dp_n$$
Because $\psi^* \omega = \omega$, it follows immediately that:
$$\psi^* d\mathcal{V} = d\mathcal{V}$$
**Liouville's Theorem:** *The volume of any arbitrary region in phase space is strictly conserved under the continuous time-evolution flow of a Hamiltonian system.*

### 2.3 Hamilton's Equations and Poisson Brackets
Given a smooth Hamiltonian function $H(\vec{q}, \vec{p}, t)$, Hamilton's equations of motion are:
$$\dot{q}_i = \frac{\partial H}{\partial p_i}, \quad \dot{p}_i = -\frac{\partial H}{\partial q_i}$$
In compact symplectic notation:
$$\dot{\vec{z}} = \Omega \nabla_{\vec{z}} H(\vec{z})$$

The **Poisson Bracket** of two observables $F, G: \mathcal{M} \to \mathbb{R}$ is defined as:
$$\{F, G\} = \sum_{i=1}^n \left(\frac{\partial F}{\partial q_i}\frac{\partial G}{\partial p_i} - \frac{\partial F}{\partial p_i}\frac{\partial G}{\partial q_i}\right) = (\nabla F)^T \Omega (\nabla G)$$
The time evolution of any observable $F$ is given by:
$$\frac{dF}{dt} = \{F, H\} + \frac{\partial F}{\partial t}$$
An observable $F$ is a **conserved first integral** if and only if $\{F, H\} = 0$.

## 3. Symplectic Integrators from First Principles

### 3.1 Operator Splitting and the Lie-Poisson Formalism
Consider a separable Hamiltonian describing kinetic energy $T(\vec{p})$ and potential energy $V(\vec{q})$:
$$H(\vec{q}, \vec{p}) = T(\vec{p}) + V(\vec{q}) = \frac{1}{2} \vec{p}^T M^{-1} \vec{p} + V(\vec{q})$$

The Hamiltonian vector field generates time evolution via the formal exponential Lie operator:
$$\vec{z}(t) = \exp\left(t \hat{D}_H\right) \vec{z}(0), \quad \text{where } \hat{D}_H f = \{f, H\}$$
Since $H = T + V$, the generator splits into:
$$\hat{D}_H = \hat{D}_T + \hat{D}_V$$
where:
* $\hat{D}_T \vec{z} = \{ \vec{z}, T \} = (M^{-1} \vec{p}, \mathbf{0})$ (Pure drift step in configuration space).
* $\hat{D}_V \vec{z} = \{ \vec{z}, V \} = (\mathbf{0}, -\nabla V(\vec{q}))$ (Pure kick step in momentum space).

Crucially, **each sub-Hamiltonian $T$ and $V$ can be integrated EXACTLY and analytically**:
* **The Drift Map $\Phi_T^\tau$:**
  $$q(t+\tau) = q(t) + \tau M^{-1} p(t), \quad p(t+\tau) = p(t)$$
* **The Kick Map $\Phi_V^\tau$:**
  $$q(t+\tau) = q(t), \quad p(t+\tau) = p(t) - \tau \nabla V(q(t))$$

Both $\Phi_T^\tau$ and $\Phi_V^\tau$ are **exact shears in phase space**, having unit Jacobian determinants:
$$J_T = \begin{pmatrix} I & \tau M^{-1} \\ 0 & I \end{pmatrix} \implies \det J_T = 1, \quad J_V = \begin{pmatrix} I & 0 \\ -\tau \nabla^2 V & I \end{pmatrix} \implies \det J_V = 1$$
Because the product of two symplectic matrices is symplectic, **any composition of exact drift and kick maps is unconditionally, exactly symplectic!**

### 3.2 The Verlet and Velocity-Verlet Algorithms
The 2nd-order symmetric composition (Strang splitting) gives the celebrated **Velocity-Verlet** integrator:
$$\Psi_2^\tau = \Phi_V^{\tau/2} \circ \Phi_T^\tau \circ \Phi_V^{\tau/2}$$

#### Algorithmic Execution Steps:
1. **Half-Step Kick:**
   $$\vec{p}_{n + 1/2} = \vec{p}_n - \frac{\tau}{2} \nabla V(\vec{q}_n)$$
2. **Full-Step Drift:**
   $$\vec{q}_{n+1} = \vec{q}_n + \tau M^{-1} \vec{p}_{n + 1/2}$$
3. **Half-Step Kick:**
   $$\vec{p}_{n+1} = \vec{p}_{n + 1/2} - \frac{\tau}{2} \nabla V(\vec{q}_{n+1})$$

#### Key Geometric Properties:
* **Symplectic:** Exactly satisfies $J^T \Omega J = \Omega$.
* **Time-Reversible:** Inverting $\tau \to -\tau$ and reversing velocities traces the exact identical trajectory backwards in time.
* **Global Order:** $\mathcal{O}(\tau^2)$ local error, $\mathcal{O}(\tau^2)$ global trajectory error.

### 3.3 High-Order Symplectic Splitting: The Yoshida 4th-Order Integrator
Can we construct an unconditionally symplectic integrator of order 4?  
In 1990, **Haruo Yoshida** proved that any 2nd-order symmetric integrator $\Psi_2^\tau$ can be combined into a 4th-order symmetric symplectic integrator $\Psi_4^\tau$ via fractal composition:
$$\Psi_4^\tau = \Psi_2^{w_1 \tau} \circ \Psi_2^{w_0 \tau} \circ \Psi_2^{w_1 \tau}$$

#### Derivation of the Yoshida Coefficients:
By the Baker-Campbell-Hausdorff (BCH) formula:
$$\Psi_2^\tau = \exp\left(\tau \hat{D}_H + \tau^3 \hat{D}_3 + \tau^5 \hat{D}_5 + \dots\right)$$
The composition of three symmetric steps of lengths $w_1 \tau, w_0 \tau, w_1 \tau$ yields:
$$\Psi_4^\tau = \exp\left( (2w_1 + w_0) \tau \hat{D}_H + (2w_1^3 + w_0^3) \tau^3 \hat{D}_3 + \mathcal{O}(\tau^5) \right)$$
To eliminate the $\tau^3$ error term while preserving consistency ($    au^1$ coefficient equals 1):
$$2w_1 + w_0 = 1$$
$$2w_1^3 + w_0^3 = 0$$

Solving this non-linear algebraic system:
$$w_0^3 = -2w_1^3 \implies w_0 = -2^{1/3} w_1$$
Substituting into the first equation:
$$2w_1 - 2^{1/3} w_1 = 1 \implies w_1 \left(2 - 2^{1/3}\right) = 1$$
$$w_1 = \frac{1}{2 - 2^{1/3}} \approx 1.351207191959657$$
$$w_0 = -\frac{2^{1/3}}{2 - 2^{1/3}} = 1 - 2w_1 \approx -1.702414383919315$$

*(Remarkable Fact: To achieve 4th-order accuracy, the intermediate step $w_0$ must step **backwards in time**!)*

Why do symplectic integrators conserve energy so extraordinarily well without secular drift?  
The answer is revealed by **Backward Error Analysis** (Moser, Benettin, Hairer).

When you run a symplectic integrator $\Psi^\tau$ on a Hamiltonian $H$, **the numerical points do NOT follow the exact trajectory of $H$**. Instead, they follow the **EXACT trajectory of a modified "Shadow Hamiltonian" $\tilde{H}$**:
$$\tilde{H}(\vec{q}, \vec{p}) = H(\vec{q}, \vec{p}) + \tau^2 H_2(\vec{q}, \vec{p}) + \tau^4 H_4(\vec{q}, \vec{p}) + \dots$$

Because $\Psi^\tau$ is the exact flow of $\tilde{H}$, the modified energy $\tilde{H}(\vec{q}_n, \vec{p}_n)$ is **strictly, exactly conserved**!
$$\tilde{H}(\vec{q}_n, \vec{p}_n) = \text{const}$$
Therefore, the true physical energy $H$ fluctuates within an extremely narrow bounded band:
$$|H(\vec{q}_n, \vec{p}_n) - H(\vec{q}_0, \vec{p}_0)| = \mathcal{O}(\tau^p)$$
**There is zero secular drift over exponentially long times $\sim e^{c/\tau}$!**  
In contrast, standard RK4 does not possess a shadow Hamiltonian; its energy drifts linearly or quadratically with time: $\Delta E_{\text{RK4}}(t) \sim t \tau^4$.

### 4.2 Chebyshev Differentiation Matrices
For non-periodic boundary value problems on $[-1, 1]$, equispaced grids cause catastrophic divergence near boundaries (**Runge's Phenomenon**).  
The cure is the **Chebyshev-Gauss-Lobatto (CGL) grid**:
$$x_j = \cos\left(\frac{\pi j}{N}\right), \quad j = 0, 1, \dots, N$$
These nodes are the horizontal projections of equally spaced points on the unit semicircle, clustering densely near the boundaries $x = \pm 1$ with density $\propto 1/\sqrt{1 - x^2}$.

The spectral derivative of an arbitrary vector of function values $\vec{u} = (u(x_0), \dots, u(x_N))^T$ is computed via a single dense matrix-vector product:
$$\vec{u}' = D_N \vec{u}$$
where $D_N$ is the **Chebyshev Differentiation Matrix**:
$$(D_N)_{jk} = \begin{cases} \frac{c_j}{c_k} \frac{(-1)^{j+k}}{x_j - x_k} & j \neq k \\ -\frac{x_j}{2(1 - x_j^2)} & 1 \le j = k \le N - 1 \\ \frac{2N^2 + 1}{6} & j = k = 0 \\ -\frac{2N^2 + 1}{6} & j = k = N \end{cases}$$
where $c_0 = c_N = 2$ and $c_j = 1$ otherwise.

Higher derivatives are obtained by matrix exponentiation: $\vec{u}'' = D_N^2 \vec{u}$.

Solving for energy eigenvalues and quantum eigenstates reduces to a standard **matrix eigenvalue problem**:
$$H_{\text{spec}} \vec{\psi}_k = E_k \vec{\psi}_k$$
This yields machine-precision quantum ground and excited states with as few as $N = 64$ grid points!

## 5. Quantum Dynamics: Split-Operator FFT for the TDSE

The Time-Dependent Schrödinger Equation (TDSE) describes non-relativistic wavepacket dynamics:
$$i\hbar \frac{\partial \psi(x, t)}{\partial t} = \left(-\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2} + V(x)\right)\psi(x, t) = (\hat{T} + \hat{V})\psi(x, t)$$

$$\psi(x, t + \Delta t) = \exp\left(-\frac{i}{\hbar}(\hat{T} + \hat{V})\Delta t\right)\psi(x, t)$$

### 5.1 The Strang Unitary Splitting
Because kinetic energy $\hat{T} = \frac{\hat{p}^2}{2m}$ and potential energy $\hat{V} = V(\hat{x})$ do not commute ($[\hat{x}, \hat{p}] = i\hbar$), their matrix exponential cannot be factored simply. Applying the symmetric Strang splitting:
$$\exp\left(-\frac{i}{\hbar}(\hat{T} + \hat{V})\Delta t\right) = \exp\left(-\frac{i}{2\hbar}\hat{V}\Delta t\right) \exp\left(-\frac{i}{\hbar}\hat{T}\Delta t\right) \exp\left(-\frac{i}{2\hbar}\hat{V}\Delta t\right) + \mathcal{O}(\Delta t^3)$$

#### The Spatial-Momentum Dual Trick:
* $\hat{V}$ is **strictly diagonal in position space $x$**: $\exp\left(-\frac{i}{2\hbar}V(x)\Delta t\right)$ is a simple pointwise complex multiplication!
* $\hat{T}$ is **strictly diagonal in momentum space $p$**: $\exp\left(-\frac{i}{\hbar}\frac{p^2}{2m}\Delta t\right)$ is a simple pointwise complex multiplication in Fourier space!


## 6. Statistical Mechanics and Markov Chain Monte Carlo (MCMC)

### 6.1 The Canonical Ensemble and the Combinatorial Explosion
In equilibrium statistical mechanics, the probability of finding a system in a microstate $\sigma$ with energy $E(\sigma)$ at temperature $T$ is given by the **Boltzmann distribution**:
$$P(\sigma) = \frac{1}{Z} e^{-\beta E(\sigma)}, \quad \beta = \frac{1}{k_B T}$$
where the normalizer is the **canonical partition function**:
$$Z = \sum_{\sigma \in \Omega} e^{-\beta E(\sigma)}$$

For a modest $20 \times 20$ lattice of magnetic spins $\sigma_i \in \{-1, +1\}$, the configuration space contains:
$$|\Omega| = 2^{400} \approx 2.58 \times 10^{120} \text{ states}$$
Evaluating $Z$ by exhaustive summation would require longer than the lifetime of the universe.

---

### 6.2 The Metropolis-Hastings Algorithm
Instead of evaluating the denominator $Z$, **Markov Chain Monte Carlo (MCMC)** constructs a random walk in configuration space whose stationary distribution is precisely the Boltzmann distribution.

To guarantee that the Markov chain converges to $P(\sigma)$, the transition probabilities $W(\sigma \to \sigma')$ must satisfy the **Detailed Balance Condition**:
$$P(\sigma) W(\sigma \to \sigma') = P(\sigma') W(\sigma' \to \sigma)$$
Rearranging:
$$\frac{W(\sigma \to \sigma')}{W(\sigma' \to \sigma)} = \frac{P(\sigma')}{P(\sigma)} = \frac{e^{-\beta E(\sigma')}}{e^{-\beta E(\sigma)}} = e^{-\beta \Delta E}$$
where $\Delta E = E(\sigma') - E(\sigma)$. Notice that the intractable partition function $Z$ **cancels completely!**

#### The Metropolis Acceptance Criterion:
Propose a trial move $\sigma \to \sigma'$ by selecting a single random spin $\sigma_i$ and flipping it ($\sigma_i \to -\sigma_i$).  
Accept the flip with probability:
$$\alpha(\sigma \to \sigma') = \min\left(1, e^{-\beta \Delta E}\right)$$
* If $\Delta E \le 0$ (the flip lowers or maintains energy), **accept unconditionally** (probability 1).
* If $\Delta E > 0$ (the flip raises energy), generate a uniform random number $r \sim U(0, 1)$ and accept if:
  $$r < e^{-\beta \Delta E}$$

### 6.3 The 2D Ising Model and Onsager's Phase Transition
The 2D ferromagnetic Ising model on a square periodic lattice of size $L \times L$ has energy:
$$E(\sigma) = -J \sum_{\langle i, j \rangle} \sigma_i \sigma_j$$
where $\langle i, j \rangle$ denotes nearest-neighbor pairs.

In 1944, **Lars Onsager** published an exact analytical solution for the infinite 2D Ising model, proving the existence of a continuous 2nd-order ferromagnetic phase transition at the critical temperature:
$$\frac{k_B T_c}{J} = \frac{2}{\ln\left(1 + \sqrt{2}\right)} \approx 2.2691853$$
Below $T_c$, spontaneous symmetry breaking occurs: spins align into macroscopic domains with non-zero spontaneous magnetization:
$$M(T) = \left(1 - \sinh^{-4}(2\beta J)\right)^{1/8} \quad (T < T_c)$$

## 7. Comprehensive Benchmarking Laboratory in Python

The following Python laboratory implements:
1. **Kepler Two-Body Problem:** Exact numerical comparison of RK4 vs. 4th-Order Symplectic Yoshida Integrator, demonstrating energy boundedness.
2. **Split-Operator FFT:** Quantum wavepacket tunneling through a potential barrier.
3. **2D Ising Model Metropolis MCMC:** Spontaneous magnetization curve near $T_c$.

```python
import numpy as np

print("=== LAB 1: KEPLER ORBIT — RK4 VS. 4TH-ORDER SYMPLECTIC YOSHIDA ===")

# Gravitational parameters (G*M = 1)
# Hamiltonian: H(q, p) = 0.5 * |p|^2 - 1 / |q|
def H_kepler(q, p):
    return 0.5 * np.dot(p, p) - 1.0 / np.linalg.norm(q)

def force_kepler(q):
    r = np.linalg.norm(q)
    return -q / (r**3)

# 1. Classical 4th-Order Runge-Kutta (RK4) Step
def step_rk4(q, p, dt):
    def deriv(q_curr, p_curr):
        return p_curr, force_kepler(q_curr)
    
    k1_q, k1_p = deriv(q, p)
    k2_q, k2_p = deriv(q + 0.5*dt*k1_q, p + 0.5*dt*k1_p)
    k3_q, k3_p = deriv(q + 0.5*dt*k2_q, p + 0.5*dt*k2_p)
    k4_q, k4_p = deriv(q + dt*k3_q, p + dt*k3_p)
    
    q_next = q + (dt / 6.0) * (k1_q + 2*k2_q + 2*k3_q + k4_q)
    p_next = p + (dt / 6.0) * (k1_p + 2*k2_p + 2*k3_p + k4_p)
    return q_next, p_next

# 2. 4th-Order Symplectic Yoshida Integrator
w1 = 1.0 / (2.0 - 2.0**(1.0/3.0))
w0 = 1.0 - 2.0 * w1

def step_velocity_verlet(q, p, tau):
    p_half = p + 0.5 * tau * force_kepler(q)
    q_next = q + tau * p_half
    p_next = p_half + 0.5 * tau * force_kepler(q_next)
    return q_next, p_next

def step_yoshida(q, p, dt):
    q, p = step_velocity_verlet(q, p, w1 * dt)
    q, p = step_velocity_verlet(q, p, w0 * dt)
    q, p = step_velocity_verlet(q, p, w1 * dt)
    return q, p

# Initial conditions: Elliptical Kepler orbit with eccentricity e = 0.6
q0 = np.array([1.0 - 0.6, 0.0]) # Perihelion at r = 0.4
v_y = np.sqrt((1.0 + 0.6) / 0.4) # Specific angular momentum
p0 = np.array([0.0, v_y])
E0 = H_kepler(q0, p0)

dt = 0.02
num_steps = 50000 # ~150 complete orbits

# Run RK4
q_rk, p_rk = np.copy(q0), np.copy(p0)
for _ in range(num_steps):
    q_rk, p_rk = step_rk4(q_rk, p_rk, dt)
E_rk_final = H_kepler(q_rk, p_rk)

# Run Yoshida Symplectic
q_yo, p_yo = np.copy(q0), np.copy(p0)
for _ in range(num_steps):
    q_yo, p_yo = step_yoshida(q_yo, p_yo, dt)
E_yo_final = H_kepler(q_yo, p_yo)

print(f"Initial Energy E0:           {E0:.8f}")
print(f"Final Energy RK4:            {E_rk_final:.8f} | Absolute Drift: {abs(E_rk_final - E0):.4e}")
print(f"Final Energy Yoshida (Symp): {E_yo_final:.8f} | Absolute Drift: {abs(E_yo_final - E0):.4e}")
print(f"Symplectic Integrator is {abs(E_rk_final - E0) / max(abs(E_yo_final - E0), 1e-16):.1f}x more energy-conserving!")


print("
=== LAB 2: QUANTUM TUNNELING VIA SPLIT-OPERATOR FFT ===")
# Discretize 1D space: x in [-20, 20], N = 512 grid points
Nx = 512
x = np.linspace(-20.0, 20.0, Nx, endpoint=False)
dx = x[1] - x[0]
dk = 2.0 * np.pi / (Nx * dx)
k = np.fft.fftfreq(Nx, d=dx) * 2.0 * np.pi # Momentum coordinates p = hbar * k

# Potential barrier: V(x) = V0 for 0 <= x <= 2, else 0
V0 = 5.0
V = np.where((x >= 0.0) & (x <= 2.0), V0, 0.0)

# Initial Gaussian wavepacket centered at x = -8 with momentum k0 = 3.0
x0, k0, sigma = -8.0, 3.0, 1.0
psi = np.exp(-0.5 * ((x - x0)/sigma)**2) * np.exp(1j * k0 * x)
psi /= np.sqrt(np.sum(np.abs(psi)**2) * dx) # Normalize

dt_q = 0.01
half_kick_phase = np.exp(-1j * 0.5 * V * dt_q)
drift_phase = np.exp(-1j * 0.5 * (k**2) * dt_q)

# Evolve for 400 time steps
for _ in range(400):
    psi = half_kick_phase * psi
    psi_k = np.fft.fft(psi)
    psi_k = drift_phase * psi_k
    psi = np.fft.ifft(psi_k)
    psi = half_kick_phase * psi

norm_final = np.sum(np.abs(psi)**2) * dx
tunneling_prob = np.sum(np.abs(psi[x > 2.0])**2) * dx
reflection_prob = np.sum(np.abs(psi[x < 0.0])**2) * dx

print(f"Norm after 400 steps:      {norm_final:.8f} (Exact Unitarity = 1.00000000)")
print(f"Tunneling Probability T:   {tunneling_prob:.4f}")
print(f"Reflection Probability R:  {reflection_prob:.4f}")
print(f"T + R Conservation Sum:    {tunneling_prob + reflection_prob:.4f}")

def run_ising_2d(L, temp, steps=10000):
    # Initialize random spin lattice (+1 or -1)
    spins = np.random.choice([-1, 1], size=(L, L))
    beta = 1.0 / temp
    
    for _ in range(steps):
        # Pick a random site (i, j)
        i, j = np.random.randint(0, L, size=2)
        s = spins[i, j]
        # Nearest neighbors with periodic boundary conditions
        neighbors = (spins[(i+1)%L, j] + spins[(i-1)%L, j] + 
                     spins[i, (j+1)%L] + spins[i, (j-1)%L])
        dE = 2 * s * neighbors
        if dE <= 0 or np.random.rand() < np.exp(-beta * dE):
            spins[i, j] = -s
            
    # Measure final absolute magnetization per spin
    return abs(np.mean(spins))

L = 16
temps = [1.5, 2.0, 2.27, 2.5, 3.5]
print("Lattice Size: 16x16 | Onsager Critical Temp Tc ≈ 2.269")
for T in temps:
    m = run_ising_2d(L, T, steps=50000)
    phase = "FERROMAGNETIC (Ordered)" if T < 2.27 else "PARAMAGNETIC (Disordered)"
    print(f"Temperature T = {T:4.2f} | Magnetization |M| = {m:.4f} | Phase: {phase}")
```
