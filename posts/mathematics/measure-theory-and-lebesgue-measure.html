Measure theory answers a deceptively simple question: how big is a set? Length, area, volume, and probability are all “measures,” and putting them on a rigorous footing required rebuilding integration from the ground up — replacing Riemann’s vertical strips with Lebesgue’s horizontal ones.

The payoff is enormous: limits can be exchanged with integrals, function spaces become complete, and probability becomes a branch of analysis.

1 Why the Riemann Integral Is Not Enough

The Riemann integral partitions the domain into small intervals and sums \(f(x_i^*)\Delta x_i\). It fails in two important ways:

  1. Too few functions are integrable. The Dirichlet function (1 on rationals, 0 on irrationals) is not Riemann integrable — upper and lower sums never agree — even though “almost all” points are irrational, so the natural answer is 0.
  2. Limits and integrals do not commute. A pointwise limit of Riemann-integrable functions need not be Riemann integrable, and \(\lim\int f_n \ne \int\lim f_n\) in general. This blocks the interchange operations that analysis and probability constantly need.

Lebesgue’s idea: partition the range instead of the domain, and measure the size of the level sets \(f^{-1}([a,b])\). This requires a theory of which sets have a size and how size behaves — measure theory.

2 Sigma-Algebras and Measures

2.1 Sigma-Algebras

A \(\sigma\)-algebra \(\mathcal{F}\) on a set \(\Omega\) is a collection of subsets containing \(\Omega\) and closed under complement and countable unions (hence countable intersections). The pair \((\Omega,\mathcal{F})\) is a measurable space.

  • Power set \(2^\Omega\) is always a \(\sigma\)-algebra.
  • The Borel \(\sigma\)-algebra \(\mathcal{B}(\mathbb{R})\) is generated by the open sets (equivalently by intervals).
  • A \(\sigma\)-algebra generated by a collection is the smallest one containing it.

\(\sigma\)-algebras are the “admissible” sets we are allowed to measure.

2.2 Measures

A measure \(\mu:\mathcal{F}\to[0,\infty]\) satisfies:

  1. Nonnegativity: \(\mu(A)\ge0\).
  2. Null empty set: \(\mu(\varnothing)=0\).
  3. Countable additivity: for pairwise disjoint \(A_n\), \(\mu\!\left(\bigcup_n A_n\right)=\sum_n\mu(A_n)\).

Consequences: monotonicity (\(A\subseteq B\Rightarrow\mu(A)\le\mu(B)\)), subadditivity, and continuity from below and (for finite measure) above.

2.3 Lebesgue Measure

Lebesgue measure \(\lambda\) on \(\mathbb{R}\) extends length: \(\lambda([a,b])=b-a\), is translation invariant (\(\lambda(A+x)=\lambda(A)\)), and is countably additive. It is constructed by outer measure, \[ \lambda^*(A)=\inf\left\{\sum_n (b_n-a_n): A\subseteq\bigcup_n(a_n,b_n)\right\}, \] restricted to the sets satisfying the Carathéodory criterion, which yields a \(\sigma\)-algebra on which \(\lambda^*\) is a genuine measure. It is the unique translation-invariant measure with \(\lambda([0,1])=1\).

The Cantor set is uncountable yet has measure zero: the removed intervals total \(1\), so the set that remains has length \(0\). Cardinality and measure are different notions of size.

3 Measurable Functions and the Lebesgue Integral

3.1 Measurable Functions

\(f:(\Omega,\mathcal{F})\to\mathbb{R}\) is measurable if \(f^{-1}(B)\in\mathcal{F}\) for every Borel set \(B\) (equivalently, \(\{f>a\}\in\mathcal{F}\) for every \(a\)). Sums, products, limits, and compositions of measurable functions are measurable. Properties that hold except on a null set hold almost everywhere (a.e.).

3.2 The Lebesgue Integral

Constructed in stages:

  1. Indicator functions: \(\int \mathbf{1}_A\,d\mu=\mu(A)\).
  2. Simple functions (finite linear combinations of indicators): integrate termwise.
  3. Nonnegative measurable functions: \(\int f=\sup\{\int s: 0\le s\le f,\ s\text{ simple}\}\).
  4. General \(f\): split \(f=f^+-f^-\) when \(\int|f|<\infty\).

If \(f\) is Riemann integrable, it is Lebesgue integrable with the same value; but the Lebesgue integral also handles the Dirichlet function (integral 0) and far wilder functions. The key improvement: the integral depends only on \(f\) up to a null set.

4 The Convergence Theorems

These are the reason measure theory exists. Let \(f_n, f\) be measurable.

  • Monotone Convergence Theorem (MCT): if \(0\le f_1\le f_2\le\cdots\) and \(f_n\uparrow f\) a.e., then \[ \int f_n \to \int f. \]
  • Fatou’s Lemma: \(\displaystyle\int \liminf_n f_n \le \liminf_n \int f_n\) for \(f_n\ge0\).
  • Dominated Convergence Theorem (DCT): if \(f_n\to f\) a.e. and \(|f_n|\le g\) with \(\int g<\infty\), then \[ \int f_n \to \int f. \]

These give conditions under which limits and integrals commute — the workhorse of probability (expectations of limits), PDE, and Fourier analysis.

4.1 \(L^p\) Spaces and Completeness

For \(1\le p<\infty\), \(L^p(\mu)\) is the space of measurable \(f\) with \(\int|f|^p<\infty\), modulo equality a.e., with norm \(\lVert f\rVert_p=(\int|f|^p)^{1/p}\). The Riesz–Fischer theorem says \(L^p\) is complete (a Banach space); \(L^2\) is a Hilbert space. This complements the completeness discussion in the Cauchy article and connects to infinite-dimensional analysis.

5 Probability as a Measure

A probability space is a measure space \((\Omega,\mathcal{F},P)\) with \(P(\Omega)=1\). Then:

  • A random variable is a measurable function \(X:\Omega\to\mathbb{R}\).
  • Expectation is the Lebesgue integral \(\mathbb{E}[X]=\int X\,dP\).
  • Distributions are pushforward measures, and densities are Radon–Nikodym derivatives.
  • Convergence theorems become statements about limits of expectations (dominated convergence underpins the law of large numbers and martingale theory).

This is exactly the measure-theoretic foundation of probability.

6 Non-Measurable Sets and Banach–Tarski

Not every set has a measure if we insist on translation invariance and countable additivity. The Vitali set (a choice set of cosets of \(\mathbb{Q}\)) is non-measurable, and the Banach–Tarski paradox shows a ball can be decomposed into finitely many pieces and reassembled into two balls of the same size — using non-measurable pieces. These results require the Axiom of Choice, and they explain why measure theory restricts to a \(\sigma\)-algebra rather than all subsets. Some set-theoretic models (Solovay) satisfy “all sets are Lebesgue measurable” by dropping full Choice.

7 Applications

Measure theory is the language of quantitative science:

  • Probability and statistics: distributions, expectation, conditional expectation, martingales, stochastic processes.
  • Physics: quantum mechanics uses \(L^2\) wavefunctions and integration over configuration/phase space; statistical mechanics integrates over measures.
  • Finance: pricing is integration over risk-neutral measures; risk measures and stochastic calculus rest on it.
  • Machine learning: expected risk \(\mathbb{E}_{(x,y)\sim P}[\ell]\) is a Lebesgue integral; generalization bounds use concentration of measure.
  • Signal processing: Fourier transforms, \(L^2\) theory, and spectral measures.
  • Monte Carlo and simulation: estimating integrals and expectations by sampling — the computational face of measure theory.

7.1 Readily Applicable Code

Measure theory is eminently computable:

  • Compute measures of unions/intersections of intervals and of the Cantor set.
  • Monte Carlo integration estimates \(\int f\) with error \(O(1/\sqrt{N})\), and is the practical method when dimensions are high (where Riemann-type grid integration dies).
  • Riemann vs Lebesgue: the Dirichlet function integrates to 0 in Lebesgue’s sense, demonstrated by sampling (rationals have measure zero).
  • Convergence theorems can be verified numerically by tracking \(\int f_n\).

8.1 Measuring Sets, Including the Cantor Set

Code 
print("=== LEBESGUE MEASURE ===")
def interval_union_measure(intervals):
    # measure of a union of intervals (merged)
    intervals = sorted(intervals)
    total, cur_l, cur_r = 0.0, *intervals[0]
    for l, r in intervals[1:]:
        if l <= cur_r:
            cur_r = max(cur_r, r)
        else:
            total += cur_r - cur_l; cur_l, cur_r = l, r
    total += cur_r - cur_l
    return total

intervals = [(0, 1), (0.5, 1.5), (2, 2.5), (2.4, 3)]
print(f"  union of {intervals} has measure {interval_union_measure(intervals)}")

# Cantor set: remove middle thirds; removed lengths sum to 1
removed = 0.0
length = 1.0
for stage in range(20):
    pieces = 2 ** stage
    piece_len = length / 3 ** stage
    removed += pieces * piece_len / 3
print(f"  Cantor set: total removed length after 20 stages = {removed:.12f}")
print(f"  remaining measure -> {1 - removed:.2e}  (the Cantor set has measure ZERO,")
print("   yet it is uncountable: cardinality and measure are different sizes.)")

8.2 Monte Carlo Integration (The Practical Face of Measure Theory)

Code 
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
fig, axes = plt.subplots(1, 2, figsize=(13, 4.8))

# pi estimation scatter
N = 5000
x, y = rng.random(N), rng.random(N)
inside = x**2 + y**2 <= 1
axes[0].scatter(x[inside], y[inside], s=3, color="#2980b9", label="inside")
axes[0].scatter(x[~inside], y[~inside], s=3, color="#e74c3c", label="outside")
t = np.linspace(0, np.pi/2, 100)
axes[0].plot(np.cos(t), np.sin(t), "k-", lw=1)
axes[0].set_title(f"Estimating π: 4·(inside/total) = {4*inside.mean():.4f}")
axes[0].set_aspect("equal"); axes[0].legend(); axes[0].grid(alpha=0.3)

# error scaling
Ns = np.logspace(2, 6, 25).astype(int)
errs = []
for n in Ns:
    xx, yy = rng.random(n), rng.random(n)
    est = 4 * np.mean(xx**2 + yy**2 <= 1)
    errs.append(abs(est - np.pi))
axes[1].loglog(Ns, errs, "o", color="#8e44ad", label="Monte Carlo error")
axes[1].loglog(Ns, errs[0]*np.sqrt(Ns[0])/np.sqrt(Ns), "k--", label=r"$O(1/\sqrt{N})$")
axes[1].set_title("Monte Carlo error decays like 1/√N")
axes[1].set_xlabel("samples N"); axes[1].set_ylabel("|estimate − π|"); axes[1].legend(); axes[1].grid(alpha=0.3, which="both")
plt.tight_layout(); plt.show()

## Why the Riemann Integral Is Not Enough

The Riemann integral partitions the **domain** into small intervals and sums $f(x_i^*)\Delta x_i$. It fails in two important ways:

1. **Too few functions are integrable.** The **Dirichlet function** (1 on rationals, 0 on irrationals) is not Riemann integrable — upper and lower sums never agree — even though "almost all" points are irrational, so the natural answer is 0.
2. **Limits and integrals do not commute.** A pointwise limit of Riemann-integrable functions need not be Riemann integrable, and $\lim\int f_n \ne \int\lim f_n$ in general. This blocks the interchange operations that analysis and probability constantly need.

Lebesgue's idea: partition the **range** instead of the domain, and measure the **size of the level sets** $f^{-1}([a,b])$. This requires a theory of which sets have a size and how size behaves — measure theory.

## Sigma-Algebras and Measures

### Sigma-Algebras

A **$\sigma$-algebra** $\mathcal{F}$ on a set $\Omega$ is a collection of subsets containing $\Omega$ and closed under complement and **countable** unions (hence countable intersections). The pair $(\Omega,\mathcal{F})$ is a **measurable space**.

- **Power set** $2^\Omega$ is always a $\sigma$-algebra.
- The **Borel $\sigma$-algebra** $\mathcal{B}(\mathbb{R})$ is generated by the open sets (equivalently by intervals).
- A $\sigma$-algebra generated by a collection is the smallest one containing it.

$\sigma$-algebras are the "admissible" sets we are allowed to measure.

### Measures

A **measure** $\mu:\mathcal{F}\to[0,\infty]$ satisfies:

1. **Nonnegativity:** $\mu(A)\ge0$.
2. **Null empty set:** $\mu(\varnothing)=0$.
3. **Countable additivity:** for pairwise disjoint $A_n$, $\mu\!\left(\bigcup_n A_n\right)=\sum_n\mu(A_n)$.

Consequences: **monotonicity** ($A\subseteq B\Rightarrow\mu(A)\le\mu(B)$), **subadditivity**, and **continuity** from below and (for finite measure) above.

### Lebesgue Measure

**Lebesgue measure** $\lambda$ on $\mathbb{R}$ extends length: $\lambda([a,b])=b-a$, is **translation invariant** ($\lambda(A+x)=\lambda(A)$), and is **countably additive**. It is constructed by **outer measure**,
$$
\lambda^*(A)=\inf\left\{\sum_n (b_n-a_n): A\subseteq\bigcup_n(a_n,b_n)\right\},
$$
restricted to the sets satisfying the **Carathéodory criterion**, which yields a $\sigma$-algebra on which $\lambda^*$ is a genuine measure. It is the unique translation-invariant measure with $\lambda([0,1])=1$.

**The Cantor set** is uncountable yet has **measure zero**: the removed intervals total $1$, so the set that remains has length $0$. Cardinality and measure are different notions of size.

$f:(\Omega,\mathcal{F})\to\mathbb{R}$ is **measurable** if $f^{-1}(B)\in\mathcal{F}$ for every Borel set $B$ (equivalently, $\{f>a\}\in\mathcal{F}$ for every $a$). Sums, products, limits, and compositions of measurable functions are measurable. Properties that hold except on a null set hold **almost everywhere (a.e.)**.

Constructed in stages:

1. **Indicator functions:** $\int \mathbf{1}_A\,d\mu=\mu(A)$.

3. **Nonnegative measurable functions:** $\int f=\sup\{\int s: 0\le s\le f,\ s\text{ simple}\}$.

## The Convergence Theorems

These are the reason measure theory exists. Let $f_n, f$ be measurable.

- **Monotone Convergence Theorem (MCT):** if $0\le f_1\le f_2\le\cdots$ and $f_n\uparrow f$ a.e., then
$$
\int f_n \to \int f.
$$
- **Fatou's Lemma:** $\displaystyle\int \liminf_n f_n \le \liminf_n \int f_n$ for $f_n\ge0$.
- **Dominated Convergence Theorem (DCT):** if $f_n\to f$ a.e. and $|f_n|\le g$ with $\int g<\infty$, then
$$
\int f_n \to \int f.
$$

These give conditions under which **limits and integrals commute** — the workhorse of probability (expectations of limits), PDE, and Fourier analysis.

### $L^p$ Spaces and Completeness

For $1\le p<\infty$, $L^p(\mu)$ is the space of measurable $f$ with $\int|f|^p<\infty$, modulo equality a.e., with norm $\lVert f\rVert_p=(\int|f|^p)^{1/p}$. The **Riesz–Fischer theorem** says $L^p$ is **complete** (a Banach space); $L^2$ is a Hilbert space. This complements the completeness discussion in [the Cauchy article](cauchy-completeness-weierstrass-and-series-convergence.qmd) and connects to [infinite-dimensional analysis](infinite-dimensional-algebra-sequence-and-function-spaces.qmd).

---

## Probability as a Measure

A **probability space** is a measure space $(\Omega,\mathcal{F},P)$ with $P(\Omega)=1$. Then:

- A **random variable** is a measurable function $X:\Omega\to\mathbb{R}$.
- **Expectation** is the Lebesgue integral $\mathbb{E}[X]=\int X\,dP$.
- Distributions are **pushforward measures**, and densities are Radon–Nikodym derivatives.
- Convergence theorems become statements about limits of expectations (**dominated convergence** underpins the law of large numbers and martingale theory).

This is exactly the measure-theoretic foundation of [probability](probability-theory-and-mathematical-probability.qmd).

---

## Non-Measurable Sets and Banach–Tarski

Not every set has a measure if we insist on translation invariance and countable additivity. The **Vitali set** (a choice set of cosets of $\mathbb{Q}$) is non-measurable, and the **Banach–Tarski paradox** shows a ball can be decomposed into finitely many pieces and reassembled into two balls of the same size — using non-measurable pieces. These results require the **Axiom of Choice**, and they explain why measure theory restricts to a $\sigma$-algebra rather than all subsets. Some set-theoretic models (Solovay) satisfy "all sets are Lebesgue measurable" by dropping full Choice.

---

## Applications

Measure theory is the language of quantitative science:

- **Probability and statistics:** distributions, expectation, conditional expectation, martingales, stochastic processes.
- **Physics:** quantum mechanics uses $L^2$ wavefunctions and integration over configuration/phase space; statistical mechanics integrates over measures.
- **Finance:** pricing is integration over risk-neutral measures; risk measures and stochastic calculus rest on it.
- **Machine learning:** expected risk $\mathbb{E}_{(x,y)\sim P}[\ell]$ is a Lebesgue integral; generalization bounds use concentration of measure.
- **Signal processing:** Fourier transforms, $L^2$ theory, and spectral measures.
- **Monte Carlo and simulation:** estimating integrals and expectations by sampling — the computational face of measure theory.

### Readily Applicable Code

Measure theory is eminently computable:

- **Compute measures** of unions/intersections of intervals and of the Cantor set.
- **Monte Carlo integration** estimates $\int f$ with error $O(1/\sqrt{N})$, and is the practical method when dimensions are high (where Riemann-type grid integration dies).
- **Riemann vs Lebesgue:** the Dirichlet function integrates to 0 in Lebesgue's sense, demonstrated by sampling (rationals have measure zero).
- **Convergence theorems** can be verified numerically by tracking $\int f_n$.

## Laboratory: Measure, Integration, and Convergence

### Measuring Sets, Including the Cantor Set

```{python}
print("=== LEBESGUE MEASURE ===")
def interval_union_measure(intervals):
    # measure of a union of intervals (merged)
    intervals = sorted(intervals)
    total, cur_l, cur_r = 0.0, *intervals[0]
    for l, r in intervals[1:]:
        if l <= cur_r:
            cur_r = max(cur_r, r)
        else:
            total += cur_r - cur_l; cur_l, cur_r = l, r
    total += cur_r - cur_l
    return total

intervals = [(0, 1), (0.5, 1.5), (2, 2.5), (2.4, 3)]
print(f"  union of {intervals} has measure {interval_union_measure(intervals)}")

# Cantor set: remove middle thirds; removed lengths sum to 1
removed = 0.0
length = 1.0
for stage in range(20):
    pieces = 2 ** stage
    piece_len = length / 3 ** stage
    removed += pieces * piece_len / 3
print(f"  Cantor set: total removed length after 20 stages = {removed:.12f}")
print(f"  remaining measure -> {1 - removed:.2e}  (the Cantor set has measure ZERO,")
print("   yet it is uncountable: cardinality and measure are different sizes.)")

print("\n=== DIRICHLET FUNCTION: RIEMANN FAILS, LEBESGUE GIVES 0 ===")
import numpy as np
rng = np.random.default_rng(0)
N = 1_000_000
samples = rng.random(N)
# rationals have measure zero; a random sample is irrational with probability 1
is_rational = np.isclose(samples, np.round(samples * 1000) / 1000, atol=1e-12) & (rng.random(N) < 1e-6)
print(f"  fraction of sampled points that are (numerically) rational: {is_rational.mean():.2e}")
print("  Lebesgue integral of the Dirichlet function = 0, since Q has measure zero.")
```

### Monte Carlo Integration (The Practical Face of Measure Theory)

```{python}
#| label: fig-monte-carlo
#| fig-cap: "Monte Carlo integration. Left: estimating π by sampling random points in the unit square and counting those inside the quarter circle. Right: the error of the estimate falls like 1/√N on a log-log plot (the straight line has slope −1/2) — the defining rate of Monte Carlo, the reason it beats grid-based quadrature in high dimensions."

import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(1)
fig, axes = plt.subplots(1, 2, figsize=(13, 4.8))

# pi estimation scatter
N = 5000
x, y = rng.random(N), rng.random(N)
inside = x**2 + y**2 <= 1
axes[0].scatter(x[inside], y[inside], s=3, color="#2980b9", label="inside")
axes[0].scatter(x[~inside], y[~inside], s=3, color="#e74c3c", label="outside")
t = np.linspace(0, np.pi/2, 100)
axes[0].plot(np.cos(t), np.sin(t), "k-", lw=1)
axes[0].set_title(f"Estimating π: 4·(inside/total) = {4*inside.mean():.4f}")
axes[0].set_aspect("equal"); axes[0].legend(); axes[0].grid(alpha=0.3)

# error scaling
Ns = np.logspace(2, 6, 25).astype(int)
errs = []
for n in Ns:
    xx, yy = rng.random(n), rng.random(n)
    est = 4 * np.mean(xx**2 + yy**2 <= 1)
    errs.append(abs(est - np.pi))
axes[1].loglog(Ns, errs, "o", color="#8e44ad", label="Monte Carlo error")
axes[1].loglog(Ns, errs[0]*np.sqrt(Ns[0])/np.sqrt(Ns), "k--", label=r"$O(1/\sqrt{N})$")
axes[1].set_title("Monte Carlo error decays like 1/√N")
axes[1].set_xlabel("samples N"); axes[1].set_ylabel("|estimate − π|"); axes[1].legend(); axes[1].grid(alpha=0.3, which="both")
plt.tight_layout(); plt.show()

print("=== MONTE CARLO INTEGRATION ===")
for f, name, exact in [(lambda t: t**2, "x^2 on [0,1]", 1/3),
                       (lambda t: np.exp(-t**2), "exp(-x^2) on [0,1]", 0.7468241328124271)]:
    n = 2_000_000
    u = rng.random(n)
    est = np.mean(f(u))
    print(f"  integral of {name}: MC = {est:.8f}, exact = {exact:.8f}, error = {abs(est-exact):.2e}")
print("  high-dimensional integrals (finance, physics, ML) are done this way.")
```

### The Convergence Theorems, Numerically

```{python}
import numpy as np

print("=== MONOTONE CONVERGENCE: f_n = (1 - x/n)^n -> e^{-x} ===")
x = np.linspace(0, 5, 200000)
for n in [1, 2, 5, 10, 100, 1000]:
    f_n = (1 - x/n) ** n * (x <= n)
    integral = np.trapz(f_n, x)
    print(f"  n={n:>4}: integral = {integral:.6f}  (-> 1 - e^(-5) = {1-np.exp(-5):.6f})")

print("\n=== DOMINATED CONVERGENCE: f_n = sin(nx)/n -> 0 ===")
xx = np.linspace(0, np.pi, 100000)
for n in [1, 10, 100, 1000]:
    f_n = np.sin(n * xx) / n
    print(f"  n={n:>4}: integral = {np.trapz(f_n, xx): .3e}  (-> 0, dominated by 1/n)")
print("  the dominated convergence theorem guarantees the interchange of limit and integral.")
```

The laboratory shows measure theory in action: sets are measured (including the measure-zero Cantor set), the Dirichlet function integrates to 0, Monte Carlo integration converges at the theoretical $1/\sqrt{N}$ rate, and the convergence theorems hold numerically.

## Summary

$$
\begin{aligned}
&\textbf{Why: } && \text{Riemann integral misses functions and fails to commute with limits.} \\[3pt]
&\textbf{Sigma-algebra: } && \text{collection closed under complement and countable unions; Borel sets.} \\[3pt]
&\textbf{Measure: } && \text{nonnegative, } \mu(\varnothing)=0,\ \text{countably additive; Lebesgue measure is translation invariant.} \\[3pt]
&\textbf{Lebesgue integral: } && \text{simple} \to \text{nonnegative} \to \text{general; depends on } f \text{ only a.e.} \\[3pt]
&\textbf{Convergence: } && \text{MCT, Fatou, DCT — conditions for } \lim\!\int=\int\!\lim. \\[3pt]
&\textbf{Lp: } && \text{complete (Riesz–Fischer); } L^2 \text{ is a Hilbert space.} \\[3pt]
&\textbf{Probability: } && \text{normalized measure; expectation} = \text{Lebesgue integral.} \\[3pt]
&\textbf{Pathologies: } && \text{Vitali non-measurable sets, Banach–Tarski (need Choice).} \\[3pt]
&\textbf{Practice: } && \text{Monte Carlo integration, expectation estimation, convergence checks.}
\end{aligned}
$$

Measure theory supplies the foundation beneath probability, $L^p$ analysis, and the Lebesgue integral — the last of the great abstractions that make modern analysis and its applications rigorous.
