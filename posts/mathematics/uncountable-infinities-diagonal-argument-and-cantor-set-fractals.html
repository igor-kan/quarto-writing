“I see it, but I don’t believe it.”

Infinity is not one thing. There is a countable infinity, \(\aleph_0\); a first uncountable infinity, \(\aleph_1\); the continuum, \(2^{\aleph_0}\); and an endless ascent of ever-larger cardinals whose behavior is partly undecidable. The diagonal argument proves that this ascent never stops. The Cantor set is the uncountable object that occupies no length — a microscope’s summary of the strange geometry of the infinite. This essay tours all of it, and then confronts the deep objection that the whole edifice rests on a philosophical choice about infinity.

1 1. Introduction: The Climb Beyond Countability

A set is countable if it can be listed as \(a_0, a_1, a_2, \dots\); otherwise it is uncountable. We have seen that \(\mathbb{N}\), \(\mathbb{Z}\), and even \(\mathbb{Q}\) are countable, while \(\mathbb{R}\) is not. This essay answers four questions:

  1. What kinds of uncountable infinity are there? (Section 2.)
  2. How does the diagonal argument prove uncountability, and how general is it? (Section 3.)
  3. Is the argument legitimate? What do intuitionists and other critics say? (Section 4.)
  4. What is the Cantor set, why does it matter, and what are its fractal relatives? (Sections 5–6.)

The companion article on Gödel’s theorems continues the story from the diagonal to the limits of provability.

2 2. The Cardinal Hierarchy of Uncountable Infinities

2.1 2.1 Alephs: The Well-Ordered Sequence of Infinite Cardinals

The infinite cardinal numbers are the alephs, indexed by the ordinals: \[ \aleph_0 < \aleph_1 < \aleph_2 < \cdots < \aleph_\omega < \aleph_{\omega+1} < \cdots \] - \(\aleph_0 = |\mathbb{N}|\) is the smallest infinite cardinal. - \(\aleph_1\) is the least uncountable cardinal: there is no set \(S\) with \(\aleph_0<|S|<\aleph_1\). - \(\aleph_{\alpha+1}\) is the least cardinal strictly greater than \(\aleph_\alpha\).

That \(\aleph_{\alpha+1}\) exists for every \(\alpha\) uses the well-ordering theorem (equivalent to the Axiom of Choice); constructing \(\aleph_{\alpha+1}\) explicitly is impossible without it.

2.2 2.2 The Continuum and the Beth Hierarchy

The continuum is \[ \mathfrak{c} = |\mathbb{R}| = |\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}. \] The beth numbers are defined by \(\beth_0=\aleph_0\) and \(\beth_{\alpha+1}=2^{\beth_\alpha}\), with \(\beth_\lambda=\sup_{\beta<\lambda}\beth_\beta\) at limits. The first few: \[ \beth_0 = \aleph_0,\qquad \beth_1 = 2^{\aleph_0} = \mathfrak{c},\qquad \beth_2 = 2^{\mathfrak{c}},\qquad \beth_3 = 2^{2^{\mathfrak{c}}}. \]

Definition 1 (CH and GCH) \[ \text{(CH)}\quad 2^{\aleph_0}=\aleph_1 \qquad\qquad \text{(GCH)}\quad 2^{\aleph_\alpha}=\aleph_{\alpha+1}\ \forall\alpha. \] CH holds in Gödel’s constructible universe \(L\) and fails in Cohen’s forcing extensions; it is independent of ZFC.

2.3 2.3 Cantor’s Theorem: Why the Ascent Never Stops

Theorem 1 (Theorem 2.1 (Cantor, 1891)) For every set \(A\), \[ |A| < |\mathcal{P}(A)| = 2^{|A|}. \]

Proof. The map \(a\mapsto\{a\}\) is an injection, so \(|A|\le|\mathcal{P}(A)|\). Suppose \(f:A\to\mathcal{P}(A)\) were surjective. Form the diagonal set \[ D=\{\,a\in A : a\notin f(a)\,\}. \] Since \(D\subseteq A\), if \(f\) were onto there is \(a_0\) with \(f(a_0)=D\). Then \(a_0\in D\iff a_0\notin f(a_0)=D\), a contradiction. So no surjection exists, and \(|A|<|\mathcal{P}(A)|\). \(\blacksquare\)

Iterating on \(\mathbb{N}\): \[ \aleph_0 < \mathfrak{c}=2^{\aleph_0} < 2^{\mathfrak{c}} < 2^{2^{\mathfrak{c}}} < \cdots \] No largest infinity exists: the class of cardinals is unbounded.

2.5 2.5 Regular and Singular Cardinals, Cofinality

A cardinal \(\kappa\) has cofinality \(\operatorname{cf}(\kappa)\): the least length of an unbounded (cofinal) sequence in \(\kappa\). \(\kappa\) is regular if \(\operatorname{cf}(\kappa)=\kappa\) and singular otherwise. \[ \operatorname{cf}(\aleph_0)=\aleph_0\ (\text{regular}),\qquad \operatorname{cf}(\aleph_\omega)=\aleph_0\ (\text{singular}). \] König’s theorem: \(\operatorname{cf}(2^{\aleph_0})>\aleph_0\), so \(2^{\aleph_0}\neq\aleph_\omega\). This already proves some cardinals are impossible continua. Every successor cardinal \(\aleph_{\alpha+1}\) is regular (in ZFC), so \(\aleph_1,\aleph_2,\dots\) are regular. Easton’s theorem shows the function \(\kappa\mapsto 2^\kappa\) on regular cardinals can be almost arbitrary, constrained only by König.

2.6 2.6 Large Cardinals: A Hierarchy of “Strengths” of Infinity

Beyond the alephs and beths lies a different kind of classification: large cardinals, defined by combinatorial properties not provable from ZFC. Each level implies the consistency of all lower levels, forming a consistency-strength hierarchy: \[ \text{inaccessible} \;<\; \text{Mahlo} \;<\; \text{measurable} \;<\; \text{strong} \;<\; \text{supercompact} \;<\; \text{Woodin} \;<\; \cdots \] These are the modern “types of uncountable infinity”: not merely bigger, but stronger, in that assuming their existence proves more sentences. Whether they exist is not decidable from ZFC.

2.7 2.7 Skolem’s Paradox

If ZFC has a model, the downward Löwenheim–Skolem theorem gives a countable model \(M\). Yet ZFC proves “uncountable sets exist.” So \(M\) contains a set \(x\) that \(M\) believes is uncountable — while from outside, \(x\) is countable (there is a bijection, but it is not in \(M\)). Countability is not absolute; it depends on which functions exist. This is not a contradiction but a warning that set-theoretic notions are relative to a model.

3 3. The Diagonal Argument

3.1 3.1 The Argument for \(\mathbb{R}\)

Theorem 2 (Theorem 3.1 (Cantor)) \(\mathbb{R}\) is uncountable.

Proof (diagonal, 1891). It suffices to show \(2^{\mathbb{N}}\), the set of infinite binary sequences, is uncountable (and \(2^{\mathbb{N}}\) injects into \(\mathbb{R}\) via \(0.b_1b_2b_3\ldots\)). Suppose \((s_n)\) lists every binary sequence, and write \(s_n = (s_{n1}, s_{n2}, s_{n3},\dots)\). Define the diagonal sequence \(d\) by \[ d_n = 1 - s_{nn}\quad(\text{flip the }n\text{-th digit of the }n\text{-th sequence}). \] Then for every \(n\), \(d\) differs from \(s_n\) at position \(n\), so \(d\neq s_n\). Hence \(d\) is a binary sequence not on the list — contradiction. Therefore no list exists. \(\blacksquare\)

Note

The decimal-ambiguity caveat. Using decimal digits, one must avoid \(0.4999\ldots=0.5000\ldots\). The cleanest fix is to work in Cantor space \(2^{\mathbb{N}}\) (binary sequences), where no such ambiguity exists, or to use digits \(\{1,2\}\) when constructing \(d\). This is the constructive-friendly formulation.

3.2 3.2 Cantor’s 1874 Proof

The 1891 proof was preceded by Cantor’s 1874 proof by nested intervals: given a sequence of reals, build a shrinking nested interval sequence avoiding the listed points, yielding a real not in the list. The diagonal proof is simpler and more general, which is why it is the one remembered.

3.3 3.3 The Abstract Diagonal Theorem

The same move — “make an object that differs from every member of a purported list at its own index” — is a universal engine:

Theorem Purported list Diagonal object
Cantor all binary sequences \(d_n = 1-s_{nn}\)
Cantor’s theorem all subsets via \(f\) \(D=\{a: a\notin f(a)\}\)
Russell all sets via \(R\) \(R=\{x:x\notin x\}\)
Gödel (I) all provable sentences \(G\): “I am unprovable”
Turing all halting deciders \(D\): “halt iff \(H\) says I loop”
Chaitin all short descriptions the least incompressible string
Grelling–Nelson all adjectives “heterological”

Formally, these are all instances of a fixed-point lemma: for suitable \(f\) there exists \(x\) with \(x \leftrightarrow f(x)\) (or \(x = f(x)\)), obtained by diagonalization. The Gödel article makes this precise.

4 4. Objections and Constructive Criticisms

4.1 4.1 Hilbert’s Hotel and Popular Objections

Hilbert’s hotel (an infinite hotel whose rooms are all full yet can accommodate new guests by shifting everyone to the next room) is an intuition pump for the completed infinite. It is not a paradox; it is a consequence of the definition of equipotence. Objections in this family:

  • “A proper subset can’t have the same size.” Definition-dependent. Equipotence is defined by bijection; “same size” for infinite sets is not the same intuition as for finite ones.
  • “The diagonal number isn’t really written down.” True but irrelevant: the argument is a proof by contradiction from a hypothetical surjection. Given a total enumeration function, the diagonal sequence is a computable construction; the conclusion is no such function exists.
  • “The proof assumes the completeness of the list, so it is circular.” No — it refutes the existence of a complete list; that is the standard form of a non-surjectivity proof.
  • “There are only countably many definable reals, so the diagonal one isn’t definable.” Correct, and important: the diagonal real is defined relative to the list. This leads to Richard’s paradox and the non-definability of truth, not to a refutation of Cantor.

4.2 4.2 Intuitionism and Constructivism

Intuitionism (Brouwer, Heyting) rejects: - the law of excluded middle (\(P\vee\neg P\)) as a general principle; - the completed (actual) infinite in favor of the potential infinite; - non-constructive existence proofs (to prove \(\exists x\,P(x)\) one must exhibit \(x\)).

Constructive analysis (Bishop) rebuilds much of analysis without excluded middle.

Important

Crucial nuance. Cantor’s diagonal argument is constructively valid. The statement “there is no surjection \(\mathbb{N}\to 2^{\mathbb{N}}\)” (equivalently, “there exist uncountable sets”) is a theorem of intuitionistic logic: given a function \(f\) and a proof that it is total, the diagonal \(d_n=1-f(n)_n\) is computable and provably outside the range. Decidable equality on \(\{0,1\}\) is all that is needed. What intuitionists reject is not the diagonal but: 1. the identification of the reals with arbitrary completed decimal expansions; 2. classical trichotomy and non-constructive existence; 3. the powerset of an arbitrary infinite set as a completed totality.

So the popular claim that “intuitionists deny Cantor’s theorem” is misleading. They deny certain classical corollaries and foundations, not the diagonal core.

4.4 4.4 What Survives

The diagonal theorem survives essentially all of these critiques because it is finitary and computational. What is contested is: - the ontology of completed infinite totalities (realism vs constructivism); - the truth value of statements like CH (model-relative); - the meaning of “there exists” (constructive vs classical).

Modern mathematics is overwhelmingly classical and ZFC-based, but constructive mathematics is a live, well-developed alternative (dependent type theory, homotopy type theory), and the diagonal argument appears there in fully constructive form.

5 5. The Cantor Set

5.1 5.1 Construction

Definition 2 (Definition 5.1 (Middle-thirds Cantor set)) Start with \(C_0=[0,1]\). At stage \(n+1\), remove the open middle third of every interval of \(C_n\). Then \[ C = \bigcap_{n=0}^{\infty} C_n. \] At stage \(n\), \(C_n\) consists of \(2^n\) closed intervals each of length \(3^{-n}\).

   C1  ██████████████████           ██████████████████
   C2  ███████     ███████           ███████     ███████
   C3  ██  ██      ██  ██            ██  ██      ██  ██
   ...
   C   = the limiting "dust": uncountably many points, no interval.

5.2 5.2 The Ternary Characterization

Every \(x\in[0,1]\) has a base-3 expansion. Then \[ x\in C \iff x \text{ has a ternary expansion using only the digits } 0 \text{ and } 2. \] The first removal kills numbers whose first ternary digit is \(1\); the next removal kills those whose second digit is \(1\), and so on. Endpoint ambiguities (\(0.1000\ldots_3=0.0222\ldots_3\)) are handled by choosing the expansion without a \(1\) when one exists.

The central paradox: \(C\) is as numerous as \(\mathbb{R}\) yet occupies no length. Cardinality and measure are independent notions.

5.4 5.4 The Cantor Function

The Cantor function (devil’s staircase) \(C(x)\) is the unique non-decreasing continuous map \([0,1]\to[0,1]\) that is constant on each removed middle third, with \(C(0)=0\), \(C(1)=1\). In ternary digits: replace each \(0\) by a binary \(0\) and each \(2\) by a binary \(1\); on hitting the first \(1\), terminate. It is: - continuous and non-decreasing; - constant on every interval of \([0,1]\setminus C\), hence differentiable with derivative \(0\) almost everywhere; - not constant, and not the integral of its derivative (it is singular); - the distribution function of the Cantor measure, a probability measure with no density, supported on a set of measure zero.

Theorem 3 (Theorem 5.1 (Brouwer’s characterization)) Every nonempty compact, perfect, totally disconnected metrizable space is homeomorphic to the Cantor set.

Thus the Cantor set is not one example among many; it is the universal model of its topological type.

6 6. Fractals

6.1 6.1 What Makes a Fractal

A fractal typically exhibits: 1. self-similarity (pieces resemble the whole, exactly or statistically); 2. fine structure at all scales; 3. non-integer dimension (Hausdorff, box, or similarity dimension); 4. often a simple iterated function system (IFS) generating rule.

Hausdorff/similarity dimension. If a set is made of \(N\) copies of itself scaled by factor \(r\), its similarity dimension is \[ D = \frac{\log N}{\log(1/r)}. \] For the Cantor set \(N=2\), \(r=1/3\), so \(D=\log2/\log3\approx0.6309\).

The box-counting dimension is \[ D_{\mathrm{box}}=\lim_{\varepsilon\to0}\frac{\log N(\varepsilon)}{\log(1/\varepsilon)}, \] where \(N(\varepsilon)\) is the number of \(\varepsilon\)-boxes meeting the set. For self-similar fractals it agrees with the similarity dimension.

All of these have a common engine: an iterated function system of contractions. By the Banach fixed-point theorem (see the rational/topology article), a set of contractions has a unique compact attractor, which is the fractal.

6.3 6.3 The Weierstrass Function

The Weierstrass function \[ W(x)=\sum_{n=0}^{\infty} a^{n}\cos(b^{n}\pi x),\qquad 0<a<1,\ b\ \text{odd},\ ab>1, \] is continuous everywhere but differentiable nowhere — the first explicit counterexample to the belief that continuity implies “mostly” differentiability. Its graph is a fractal with box dimension \(2+\log a/\log b\).

# ---- Cantor function (devil's staircase) ----
def cantor(x, n=80):
    if x <= 0: return 0.0
    if x >= 1: return 1.0
    y = 0.0
    for i in range(1, n + 1):
        x *= 3
        d = int(x); x -= d
        if d == 2:
            y += 1.0 / 2**i
        elif d == 1:
            y += 1.0 / 2**i
            break
        elif d not in (0, 1, 2):
            break
    return y

def koch(points, n):
    for _ in range(n):
        new = []
        for i in range(len(points) - 1):
            a, b = points[i], points[i + 1]
            d = (b - a) / 3
            ang = -np.pi / 3
            R = np.array([[np.cos(ang), -np.sin(ang)], [np.sin(ang), np.cos(ang)]])
            apex = a + d + R.dot(d)
            new += [a, a + d, apex, a + 2 * d]
        new.append(points[-1])
        points = np.array(new)
    return points

## 1. Introduction: The Climb Beyond Countability

A set is **countable** if it can be listed as $a_0, a_1, a_2, \dots$; otherwise it is **uncountable**. We have seen that $\mathbb{N}$, $\mathbb{Z}$, and even $\mathbb{Q}$ are countable, while $\mathbb{R}$ is not. This essay answers four questions:

1. **What kinds of uncountable infinity are there?** (Section 2.)
2. **How does the diagonal argument prove uncountability, and how general is it?** (Section 3.)
3. **Is the argument legitimate? What do intuitionists and other critics say?** (Section 4.)
4. **What is the Cantor set, why does it matter, and what are its fractal relatives?** (Sections 5–6.)

The companion article on [Gödel's theorems](godel-completeness-and-incompleteness-theorems.qmd) continues the story from the diagonal to the limits of provability.

## 2. The Cardinal Hierarchy of Uncountable Infinities

### 2.1 Alephs: The Well-Ordered Sequence of Infinite Cardinals

The infinite cardinal numbers are the **alephs**, indexed by the ordinals:
$$
\aleph_0 < \aleph_1 < \aleph_2 < \cdots < \aleph_\omega < \aleph_{\omega+1} < \cdots
$$
- $\aleph_0 = |\mathbb{N}|$ is the smallest infinite cardinal.
- $\aleph_1$ is the **least uncountable** cardinal: there is no set $S$ with $\aleph_0<|S|<\aleph_1$.
- $\aleph_{\alpha+1}$ is the least cardinal strictly greater than $\aleph_\alpha$.

That $\aleph_{\alpha+1}$ exists for every $\alpha$ uses the **well-ordering theorem** (equivalent to the Axiom of Choice); constructing $\aleph_{\alpha+1}$ explicitly is impossible without it.

### 2.2 The Continuum and the Beth Hierarchy

The **continuum** is
$$
\mathfrak{c} = |\mathbb{R}| = |\mathcal{P}(\mathbb{N})| = 2^{\aleph_0}.
$$
The **beth numbers** are defined by $\beth_0=\aleph_0$ and $\beth_{\alpha+1}=2^{\beth_\alpha}$, with $\beth_\lambda=\sup_{\beta<\lambda}\beth_\beta$ at limits. The first few:
$$
\beth_0 = \aleph_0,\qquad \beth_1 = 2^{\aleph_0} = \mathfrak{c},\qquad \beth_2 = 2^{\mathfrak{c}},\qquad \beth_3 = 2^{2^{\mathfrak{c}}}.
$$

::: {#def-ch-gch}
#### CH and GCH
$$
\text{(CH)}\quad 2^{\aleph_0}=\aleph_1 \qquad\qquad \text{(GCH)}\quad 2^{\aleph_\alpha}=\aleph_{\alpha+1}\ \forall\alpha.
$$
CH holds in Gödel's constructible universe $L$ and fails in Cohen's forcing extensions; it is **independent of ZFC**.
:::

### 2.3 Cantor's Theorem: Why the Ascent Never Stops

::: {#thm-cantor-power}
#### Theorem 2.1 (Cantor, 1891)
For every set $A$,
$$
|A| < |\mathcal{P}(A)| = 2^{|A|}.
$$
:::

*Proof.* The map $a\mapsto\{a\}$ is an injection, so $|A|\le|\mathcal{P}(A)|$. Suppose $f:A\to\mathcal{P}(A)$ were surjective. Form the **diagonal** set
$$
D=\{\,a\in A : a\notin f(a)\,\}.
$$
Since $D\subseteq A$, if $f$ were onto there is $a_0$ with $f(a_0)=D$. Then $a_0\in D\iff a_0\notin f(a_0)=D$, a contradiction. So no surjection exists, and $|A|<|\mathcal{P}(A)|$. $\blacksquare$

Iterating on $\mathbb{N}$:
$$
\aleph_0 < \mathfrak{c}=2^{\aleph_0} < 2^{\mathfrak{c}} < 2^{2^{\mathfrak{c}}} < \cdots
$$
**No largest infinity exists**: the class of cardinals is unbounded.

### 2.4 A Catalogue of Uncountable Cardinals

| Set | Cardinality | Notes |
| :--- | :--- | :--- |
| $\mathbb{R}$, any interval, the Cantor set | $\mathfrak{c}=2^{\aleph_0}$ | all equipotent to $\mathbb{R}$ |
| $\mathbb{R}^n$, $\mathbb{C}$, $\mathbb{R}^{\mathbb{N}}$ | $\mathfrak{c}$ | finite products and countable powers add nothing |
| Baire space $\mathbb{N}^{\mathbb{N}}$ | $\mathfrak{c}$ | homeomorphic to the irrationals |
| Cantor space $2^{\mathbb{N}}$ | $\mathfrak{c}$ | the "cleanest" presentation of the reals' cardinality |
| $\mathcal{P}(\mathbb{N})$ | $\mathfrak{c}$ | powerset of the countable |
| set of continuous $f:\mathbb{R}\to\mathbb{R}$, $C(\mathbb{R})$ | $\mathfrak{c}$ | determined by values on $\mathbb{Q}$ |
| set of Borel sets | $\mathfrak{c}$ | generated by countably many operations |
| set of Lebesgue-measurable sets | $2^{\mathfrak{c}}$ | there are more measurable sets than reals |
| $\mathbb{R}^{\mathbb{R}}$, $\mathcal{P}(\mathbb{R})$ | $2^{\mathfrak{c}}$ | all functions / all subsets of the line |
| Stone–Čech compactification $\beta\mathbb{N}$ | $2^{2^{\aleph_0}}=2^{\mathfrak{c}}$ | enormous |
| set of all topologies on $\mathbb{R}$ | $2^{\mathfrak{c}}$ | — |

So "uncountable" spans an unbounded tower. The continuum is not the top; it is barely the second rung.

### 2.5 Regular and Singular Cardinals, Cofinality

A cardinal $\kappa$ has **cofinality** $\operatorname{cf}(\kappa)$: the least length of an unbounded (cofinal) sequence in $\kappa$. $\kappa$ is **regular** if $\operatorname{cf}(\kappa)=\kappa$ and **singular** otherwise.
$$
\operatorname{cf}(\aleph_0)=\aleph_0\ (\text{regular}),\qquad \operatorname{cf}(\aleph_\omega)=\aleph_0\ (\text{singular}).
$$
**König's theorem**: $\operatorname{cf}(2^{\aleph_0})>\aleph_0$, so $2^{\aleph_0}\neq\aleph_\omega$. This already proves some cardinals are impossible continua. Every successor cardinal $\aleph_{\alpha+1}$ is regular (in ZFC), so $\aleph_1,\aleph_2,\dots$ are regular. Easton's theorem shows the function $\kappa\mapsto 2^\kappa$ on regular cardinals can be almost arbitrary, constrained only by König.

### 2.6 Large Cardinals: A Hierarchy of "Strengths" of Infinity

Beyond the alephs and beths lies a different kind of classification: **large cardinals**, defined by combinatorial properties not provable from ZFC. Each level implies the consistency of all lower levels, forming a **consistency-strength hierarchy**:
$$
\text{inaccessible} \;<\; \text{Mahlo} \;<\; \text{measurable} \;<\; \text{strong} \;<\; \text{supercompact} \;<\; \text{Woodin} \;<\; \cdots
$$
These are the modern "types of uncountable infinity": not merely bigger, but **stronger**, in that assuming their existence proves more sentences. Whether they exist is not decidable from ZFC.

### 2.7 Skolem's Paradox

If ZFC has a model, the downward Löwenheim–Skolem theorem gives a **countable** model $M$. Yet ZFC proves "uncountable sets exist." So $M$ contains a set $x$ that $M$ believes is uncountable — while from outside, $x$ is countable (there is a bijection, but it is not *in* $M$). **Countability is not absolute**; it depends on which functions exist. This is not a contradiction but a warning that set-theoretic notions are relative to a model.

## 3. The Diagonal Argument

### 3.1 The Argument for $\mathbb{R}$

::: {#thm-reals-uncountable}
#### Theorem 3.1 (Cantor)
$\mathbb{R}$ is uncountable.
:::

*Proof (diagonal, 1891).* It suffices to show $2^{\mathbb{N}}$, the set of infinite binary sequences, is uncountable (and $2^{\mathbb{N}}$ injects into $\mathbb{R}$ via $0.b_1b_2b_3\ldots$). Suppose $(s_n)$ lists every binary sequence, and write $s_n = (s_{n1}, s_{n2}, s_{n3},\dots)$. Define the diagonal sequence $d$ by
$$
d_n = 1 - s_{nn}\quad(\text{flip the }n\text{-th digit of the }n\text{-th sequence}).
$$
Then for every $n$, $d$ differs from $s_n$ at position $n$, so $d\neq s_n$. Hence $d$ is a binary sequence not on the list — contradiction. Therefore no list exists. $\blacksquare$

::: {.callout-note}
**The decimal-ambiguity caveat.** Using decimal digits, one must avoid $0.4999\ldots=0.5000\ldots$. The cleanest fix is to work in **Cantor space** $2^{\mathbb{N}}$ (binary sequences), where no such ambiguity exists, or to use digits $\{1,2\}$ when constructing $d$. This is the constructive-friendly formulation.
:::

### 3.2 Cantor's 1874 Proof

The 1891 proof was preceded by Cantor's **1874** proof by nested intervals: given a sequence of reals, build a shrinking nested interval sequence avoiding the listed points, yielding a real not in the list. The diagonal proof is simpler and more general, which is why it is the one remembered.

### 3.3 The Abstract Diagonal Theorem

The same move — "make an object that differs from every member of a purported list at its own index" — is a universal engine:

| Theorem | Purported list | Diagonal object |
| :--- | :--- | :--- |
| **Cantor** | all binary sequences | $d_n = 1-s_{nn}$ |
| **Cantor's theorem** | all subsets via $f$ | $D=\{a: a\notin f(a)\}$ |
| **Russell** | all sets via $R$ | $R=\{x:x\notin x\}$ |
| **Gödel (I)** | all provable sentences | $G$: "I am unprovable" |
| **Turing** | all halting deciders | $D$: "halt iff $H$ says I loop" |
| **Chaitin** | all short descriptions | the least incompressible string |
| **Grelling–Nelson** | all adjectives | "heterological" |

Formally, these are all instances of a **fixed-point lemma**: for suitable $f$ there exists $x$ with $x \leftrightarrow f(x)$ (or $x = f(x)$), obtained by diagonalization. The [Gödel article](godel-completeness-and-incompleteness-theorems.qmd) makes this precise.

## 4. Objections and Constructive Criticisms

### 4.1 Hilbert's Hotel and Popular Objections

**Hilbert's hotel** (an infinite hotel whose rooms are all full yet can accommodate new guests by shifting everyone to the next room) is an intuition pump for the **completed infinite**. It is not a paradox; it is a *consequence* of the definition of equipotence. Objections in this family:

- **"A proper subset can't have the same size."** Definition-dependent. Equipotence is *defined by bijection*; "same size" for infinite sets is not the same intuition as for finite ones.
- **"The diagonal number isn't really written down."** True but irrelevant: the argument is a **proof by contradiction from a hypothetical surjection**. Given a total enumeration function, the diagonal sequence is a **computable construction**; the conclusion is *no such function exists*.
- **"The proof assumes the completeness of the list, so it is circular."** No — it *refutes* the existence of a complete list; that is the standard form of a non-surjectivity proof.
- **"There are only countably many definable reals, so the diagonal one isn't definable."** Correct, and important: the diagonal real is defined *relative to the list*. This leads to **Richard's paradox** and the non-definability of truth, not to a refutation of Cantor.

### 4.2 Intuitionism and Constructivism

**Intuitionism** (Brouwer, Heyting) rejects:
- the **law of excluded middle** ($P\vee\neg P$) as a general principle;
- the **completed (actual) infinite** in favor of the **potential infinite**;
- non-constructive existence proofs (to prove $\exists x\,P(x)$ one must exhibit $x$).

**Constructive analysis** (Bishop) rebuilds much of analysis without excluded middle.

::: {.callout-important}
**Crucial nuance.** Cantor's diagonal argument is **constructively valid**. The statement "there is no surjection $\mathbb{N}\to 2^{\mathbb{N}}$" (equivalently, "there exist uncountable sets") is a theorem of **intuitionistic** logic: given a function $f$ and a proof that it is total, the diagonal $d_n=1-f(n)_n$ is computable and provably outside the range. Decidable equality on $\{0,1\}$ is all that is needed.
What intuitionists reject is not the diagonal but:
1. the identification of the reals with arbitrary completed decimal expansions;
2. classical trichotomy and non-constructive existence;
3. the powerset of an arbitrary infinite set as a completed totality.
:::

So the popular claim that "intuitionists deny Cantor's theorem" is misleading. They deny certain **classical corollaries and foundations**, not the diagonal core.

### 4.3 Other Critical Currents

| Position | Rejects | On Cantor |
| :--- | :--- | :--- |
| **Finitism** (Hilbert's finitism) | completed infinite; only finitary objects are real | diagonal is a finitary metatheorem about formal systems |
| **Ultrafinitism** (Nelson, Zeilberger) | very large naturals as concrete | questions the existence of $2^{2^{100}}$ |
| **Predicativism** (Poincaré, Weyl, Feferman) | impredicative comprehension | restricts powersets; accepts countable diagonal |
| **Paraconsistent / dialetheist** | explosion from contradiction | liars can be "both true and false"; Cantor re-examined |
| **Formalist** | a single intended "true" $\mathbb{R}$ | CH-independence is expected, not paradoxical |

### 4.4 What Survives

The **diagonal theorem** survives essentially all of these critiques because it is finitary and computational. What is contested is:
- the **ontology** of completed infinite totalities (realism vs constructivism);
- the **truth value** of statements like CH (model-relative);
- the **meaning** of "there exists" (constructive vs classical).

Modern mathematics is overwhelmingly **classical** and ZFC-based, but constructive mathematics is a live, well-developed alternative (dependent type theory, homotopy type theory), and the diagonal argument appears there in fully constructive form.

## 5. The Cantor Set

### 5.1 Construction

::: {#def-cantor-set}
#### Definition 5.1 (Middle-thirds Cantor set)
Start with $C_0=[0,1]$. At stage $n+1$, remove the open middle third of every interval of $C_n$. Then
$$
C = \bigcap_{n=0}^{\infty} C_n.
$$
At stage $n$, $C_n$ consists of $2^n$ closed intervals each of length $3^{-n}$.
:::

```text
   C0  ██████████████████████████████████████████████████
   C1  ██████████████████           ██████████████████
   C2  ███████     ███████           ███████     ███████
   C3  ██  ██      ██  ██            ██  ██      ██  ██
   ...
   C   = the limiting "dust": uncountably many points, no interval.
```

### 5.2 The Ternary Characterization

Every $x\in[0,1]$ has a base-3 expansion. Then
$$
x\in C \iff x \text{ has a ternary expansion using only the digits } 0 \text{ and } 2.
$$
The first removal kills numbers whose first ternary digit is $1$; the next removal kills those whose second digit is $1$, and so on. Endpoint ambiguities ($0.1000\ldots_3=0.0222\ldots_3$) are handled by choosing the expansion without a $1$ when one exists.

### 5.3 Properties

| Property | Statement | Reason |
| :--- | :--- | :--- |
| **Compact** | closed and bounded | intersection of closed bounded sets |
| **Uncountable** | $\lvert C\rvert=\mathfrak{c}$ | $x\mapsto(\text{ternary digits }2\to1)$ gives a bijection onto $2^{\mathbb{N}}$ |
| **Perfect** | closed, no isolated points | every neighborhood of $x\in C$ meets $C\setminus\{x\}$ |
| **Totally disconnected** | components are points | between any two points lies a removed gap |
| **Nowhere dense** | closure has empty interior | $C$ contains no interval |
| **Measure zero** | $\lambda(C)=0$ | removed length $\sum_{n\ge0}2^n/3^{n+1}=1$ |
| **Self-similar** | $C=\frac{C}{3}\cup\bigl(\frac{C}{3}+\frac23\bigr)$ | two half-size copies |
| **Hausdorff dimension** | $\log 2/\log 3\approx0.6309$ | two copies at scale $1/3$ |

The central paradox: $C$ is **as numerous as $\mathbb{R}$** yet occupies **no length**. Cardinality and measure are independent notions.

### 5.4 The Cantor Function

The **Cantor function** (devil's staircase) $C(x)$ is the unique non-decreasing continuous map $[0,1]\to[0,1]$ that is constant on each removed middle third, with $C(0)=0$, $C(1)=1$. In ternary digits: replace each $0$ by a binary $0$ and each $2$ by a binary $1$; on hitting the first $1$, terminate. It is:
- continuous and non-decreasing;
- constant on every interval of $[0,1]\setminus C$, hence differentiable with derivative $0$ almost everywhere;
- not constant, and not the integral of its derivative (it is **singular**);
- the distribution function of the **Cantor measure**, a probability measure with no density, supported on a set of measure zero.

### 5.5 Variants

| Variant | Description | Distinguishing property |
| :--- | :--- | :--- |
| **Smith–Volterra–Cantor** | remove $2^{n-1}$ intervals of length $4^{-n}$ | **positive measure**, still nowhere dense |
| **Fat Cantor sets** | remove decreasing lengths with total $<1$ | positive measure, homeomorphic to $C$ |
| **Generalized Cantor set** | remove fraction $\alpha$ | dimension $\log 2/\log(2/\alpha)$ |
| **Cantor dust** | $C\times C\subseteq\mathbb{R}^2$ | dimension $2\log2/\log3\approx1.26$ |
| **Cantor space** $2^{\mathbb{N}}$ | all binary sequences | homeomorphic to $C$; the abstract Cantor set |
| **Cantor measure** | uniform on $C$ | singular w.r.t. Lebesgue |
| **Random Cantor set** | keep each third with probability $p$ | random fractal, almost-sure dimension |
| **Cantor–Bendixson** | general decomposition | every closed set $=$ perfect $+$ countable |

::: {#thm-brouwer-cantor}
#### Theorem 5.1 (Brouwer's characterization)
Every nonempty compact, perfect, totally disconnected metrizable space is homeomorphic to the Cantor set.
:::

Thus the Cantor set is not one example among many; it is *the* universal model of its topological type.

## 6. Fractals

### 6.1 What Makes a Fractal

A **fractal** typically exhibits:
1. **self-similarity** (pieces resemble the whole, exactly or statistically);
2. **fine structure at all scales**;
3. **non-integer dimension** (Hausdorff, box, or similarity dimension);
4. often a simple **iterated function system (IFS)** generating rule.

**Hausdorff/similarity dimension.** If a set is made of $N$ copies of itself scaled by factor $r$, its similarity dimension is
$$
D = \frac{\log N}{\log(1/r)}.
$$
For the Cantor set $N=2$, $r=1/3$, so $D=\log2/\log3\approx0.6309$.

The **box-counting dimension** is
$$
D_{\mathrm{box}}=\lim_{\varepsilon\to0}\frac{\log N(\varepsilon)}{\log(1/\varepsilon)},
$$
where $N(\varepsilon)$ is the number of $\varepsilon$-boxes meeting the set. For self-similar fractals it agrees with the similarity dimension.

### 6.2 A Gallery

| Fractal | Construction | Dimension |
| :--- | :--- | :--- |
| **Cantor set** | remove middle thirds | $\log2/\log3\approx0.6309$ |
| **Sierpinski triangle** | remove central inverted triangles | $\log3/\log2\approx1.5850$ |
| **Sierpinski carpet** | remove central ninths (squares) | $\log8/\log3\approx1.8928$ |
| **Menger sponge** | 3D carpet | $\log20/\log3\approx2.7268$ |
| **Koch curve** | replace each segment by 4 at $1/3$ scale | $\log4/\log3\approx1.2619$ |
| **Koch snowflake** | 3 Koch curves | same as Koch, $1.2619$ |
| **Weierstrass function** | $\sum a^{-n}\cos(b^n x)$ | graph dimension $2-\log a/\log b$ |
| **Julia set** | filled-in points with bounded orbit of $z\mapsto z^2+c$ | usually $1$–$2$ |
| **Mandelbrot set** | connectedness locus of $z\mapsto z^2+c$ | boundary dimension $2$ |
| **Lorenz / Hénon attractors** | chaotic dynamical systems | non-integer (e.g. $\approx2.06$) |
| **Barnsley fern** | IFS with four affine maps | $D\approx1.45$ |
| **Coastlines** | Richardson–Mandelbrot | empirical $1.2$–$1.5$ |

All of these have a common engine: an **iterated function system** of contractions. By the **Banach fixed-point theorem** (see the [rational/topology article](rationals-density-enumeration-metric-spaces-and-topology.qmd)), a set of contractions has a unique compact **attractor**, which is the fractal.

### 6.3 The Weierstrass Function

The Weierstrass function
$$
W(x)=\sum_{n=0}^{\infty} a^{n}\cos(b^{n}\pi x),\qquad 0<a<1,\ b\ \text{odd},\ ab>1,
$$
is **continuous everywhere but differentiable nowhere** — the first explicit counterexample to the belief that continuity implies "mostly" differentiability. Its graph is a fractal with box dimension $2+\log a/\log b$.

def koch(points, n):
    for _ in range(n):
        new = []
        for i in range(len(points) - 1):
            a, b = points[i], points[i + 1]
            d = (b - a) / 3
            ang = -np.pi / 3
            R = np.array([[np.cos(ang), -np.sin(ang)], [np.sin(ang), np.cos(ang)]])
            apex = a + d + R.dot(d)
            new += [a, a + d, apex, a + 2 * d]
        new.append(points[-1])
        points = np.array(new)
    return points

\begin{aligned}
