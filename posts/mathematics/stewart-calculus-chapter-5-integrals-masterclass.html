1. Introduction: The Philosophy and Geometry of Accumulation

In elementary calculus curricula, differentiation is introduced as a local, instantaneous operation: measuring the instantaneous rate of change of a dynamic variable (\(dy/dx\)). In contrast, integration is a global, cumulative operation: synthesizing an infinite continuum of infinitesimal contributions into a finite macroscopic quantity.

While introductory students often reduce integration to “finding anti-derivatives,” James Stewart’s Calculus: Early Transcendentals (Chapter 5) structures the definite integral upon its true geometric foundation: the limit of approximating Riemann sums.

\[\int_a^b f(x) \, dx = \lim_{\|P\| \to 0} \sum_{i=1}^n f(x_i^*) \, \Delta x_i\]

This masterclass deconstructs the entirety of Stewart Chapter 5—from the geometry of partitions, convexity error bounds, and the Fundamental Theorem of Calculus to real-world continuous accumulation in virology, aerospace, radiation physics, and high-performance numerical algorithms.

2. Sections 5.1 & 5.2: Areas, Distances, and the Definite Integral

2.1 The Geometry of Partitions and Sample Points

Let \([a, b] \subset \mathbb{R}\) be a closed interval. A partition \(P\) is an ordered set of points: \[P = \{a = x_0 < x_1 < x_2 < \dots < x_n = b\}\] The subinterval widths are \(\Delta x_i = x_i - x_{i-1}\), and the mesh (or norm) is \(\|P\| = \max \Delta x_i\).

For each subinterval \([x_{i-1}, x_i]\), we select an arbitrary sample point (or tag) \(x_i^* \in [x_{i-1}, x_i]\). The primary tag selection strategies include: 1. Left Endpoint Sum (\(L_n\)): \(x_i^* = x_{i-1}\) 2. Right Endpoint Sum (\(R_n\)): \(x_i^* = x_i\) 3. Midpoint Sum (\(M_n\)): \(x_i^* = \bar{x}_i = \frac{x_{i-1} + x_i}{2}\) 4. Trapezoidal Approximation (\(T_n\)): \(\frac{L_n + R_n}{2} = \sum_{i=1}^n \frac{f(x_{i-1}) + f(x_i)}{2} \Delta x_i\)

2.2 Convexity, Monotonicity, and Error Geometry

The curvature (second derivative) and slope (first derivative) of \(f(x)\) dictate strict geometric inequalities between these approximations and the exact integral \(I = \int_a^b f(x) dx\):

A. Monotonicity Invariants

  • Strictly Increasing (\(f'(x) > 0\)): \[L_n < \int_a^b f(x) \, dx < R_n\] The exact integral is strictly sandwiched between the left and right sums.
  • Strictly Decreasing (\(f'(x) < 0\)): \[R_n < \int_a^b f(x) \, dx < L_n\]

B. Curvature & Convexity Invariants

  • Concave Upward (\(f''(x) > 0\)): The tangent line lies below the curve, while secant lines lie above the curve. Consequently: \[M_n < \int_a^b f(x) \, dx < T_n\] The midpoint rule systematically underestimates, while the trapezoidal rule systematically overestimates.
  • Asymptotic Error Relationship: For sufficiently smooth functions, Taylor expansions demonstrate that: \[E_T \approx -2 E_M\] The error of the trapezoid rule is approximately twice the magnitude of the midpoint rule and has the opposite sign. This crucial insight directly yields Simpson’s Rule: \[S_{2n} = \frac{2 M_n + T_n}{3} = \frac{1}{3} T_n + \frac{2}{3} M_n\]

2.3 What Happens When Left and Right Sum Limits Disagree?

In elementary calculus, student intuition takes for granted that \(\lim_{n \to \infty} L_n = \lim_{n \to \infty} R_n = \int_a^b f(x) \, dx\). But what does it mathematically signify if these limits fail to coincide or if different tagging schemes diverge?

A. The Monotonic Case and Telescoping Error

For any bounded, monotonically increasing function \(f\) on \([a, b]\) partitioned into \(n\) uniform subintervals of width \(\Delta x = \frac{b-a}{n}\): \[R_n - L_n = \sum_{i=1}^n f(x_i) \Delta x - \sum_{i=1}^n f(x_{i-1}) \Delta x = \Delta x \sum_{i=1}^n \left( f(x_i) - f(x_{i-1}) \right)\]

The sum telescopes completely: \[R_n - L_n = \frac{b - a}{n} \left[ f(b) - f(a) \right]\]

Because \(f(b) - f(a)\) is finite, \(\lim_{n \to \infty} (R_n - L_n) = 0\) unconditionally. Hence, every bounded monotonic function is automatically Riemann integrable, even if it has countably infinitely many jump discontinuities!

B. Discontinuities and Lebesgue’s Criterion

If \(\lim_{n \to \infty} L_n \ne \lim_{n \to \infty} R_n\), the function violates Riemann integrability. Henri Lebesgue proved the definitive criterion: > Lebesgue’s Criterion for Riemann Integrability: A bounded function \(f: [a, b] \to \mathbb{R}\) is Riemann integrable if and only if its set of discontinuities \(D \subset [a, b]\) has Lebesgue measure zero (\(\mu(D) = 0\)).

  1. Isolated Jump Discontinuities: If \(f\) has a finite (or countable) number of step jumps (e.g. Heaviside step \(\Theta(x)\)), the set of jump points has measure zero (\(\mu(D) = 0\)). Although on any single coarse subinterval containing a jump, the left and right sample values differ by the jump height \(\Delta y\), the subinterval width shrinks as \(\mathcal{O}(1/n)\). The total contribution of all jump intervals to the difference \(|R_n - L_n|\) scales as \(\sum (\text{jump}_k) \cdot \frac{b-a}{n} \to 0\). Thus, piecewise continuous functions remain Riemann integrable.
  2. Dense Non-Removable Discontinuities (The Dirichlet Function): \[\mathbf{1}_\mathbb{Q}(x) = \begin{cases} 1, & x \in \mathbb{Q} \\ 0, & x \notin \mathbb{Q} \end{cases}\] Between any two real numbers, there exist both infinitely many rationals and infinitely many irrationals. If tags are chosen at rational sample points (\(x_i^* \in \mathbb{Q}\)), the Riemann sum is \(\sum_{i=1}^n 1 \cdot \Delta x = 1\). If tags are chosen at irrational sample points (\(x_i^* \notin \mathbb{Q}\)), the Riemann sum is \(\sum_{i=1}^n 0 \cdot \Delta x = 0\). The limit does not exist, and the lower and upper Darboux integrals remain locked at \(L(f) = 0\) and \(U(f) = 1\).
  3. Physical and Numerical Implication: In numerical computing and physical sensors, when left and right approximations disagree significantly, it implies the presence of a shock wave (in compressible gas dynamics), a phase change boundary (in thermodynamics), or an undersampled high-frequency transient violating the Nyquist-Shannon sampling theorem.

2.4 Worked Example: High-Degree Monomial Riemann Limit (Stewart Ch 5, Problem 78)

Evaluate the following limit from Stewart Calculus Chapter 5: \[\mathcal{L} = \lim_{n \to \infty} \sum_{i=1}^n \frac{i^9}{n^{10}}\]

Step-by-Step Analytical Deconstruction:

  1. Factor out \(1/n\) to isolate the subinterval width: \[\frac{i^9}{n^{10}} = \frac{i^9}{n^9 \cdot n} = \left(\frac{i}{n}\right)^9 \frac{1}{n}\]
  2. Identify Partition and Tagging: Let the interval be \([0, 1]\). The uniform partition has \(\Delta x = \frac{1 - 0}{n} = \frac{1}{n}\), and the right endpoints are \(x_i = 0 + i \Delta x = \frac{i}{n}\).
  3. Recognize the Riemann Sum: \[\sum_{i=1}^n \frac{i^9}{n^{10}} = \sum_{i=1}^n \left(x_i\right)^9 \Delta x = R_n\]
  4. Pass to the Definite Integral: Since \(f(x) = x^9\) is continuous on \([0, 1]\), the limit of the Riemann sum equals the definite integral: \[\lim_{n \to \infty} \sum_{i=1}^n \frac{i^9}{n^{10}} = \int_0^1 x^9 \, dx = \left[ \frac{x^{10}}{10} \right]_0^1 = \frac{1}{10}\]

3. Section 5.3: The Fundamental Theorem of Calculus (FTC)

The Fundamental Theorem of Calculus is the intellectual crown of analysis, proving that differentiation and integration are inverse operations.

3.1 FTC Part 1: The Area Accumulator Function

Let \(f\) be continuous on \([a, b]\). Define the accumulator function: \[g(x) = \int_a^x f(t) \, dt \quad \text{for } x \in [a, b]\]

Theorem (FTC 1): The function \(g(x)\) is continuous on \([a, b]\), differentiable on \((a, b)\), and its derivative is precisely the integrand: \[g'(x) = \frac{d}{dx} \left[ \int_a^x f(t) \, dt \right] = f(x)\]

Rigorous Proof:

By the limit definition of the derivative: \[g'(x) = \lim_{h \to 0} \frac{g(x + h) - g(x)}{h} = \lim_{h \to 0} \frac{1}{h} \left[ \int_a^{x+h} f(t) \, dt - \int_a^x f(t) \, dt \right] = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t) \, dt\] By the Mean Value Theorem for Integrals, because \(f\) is continuous on \([x, x+h]\), there exists a number \(c_h\) between \(x\) and \(x + h\) such that: \[\int_x^{x+h} f(t) \, dt = f(c_h) \cdot h \implies \frac{1}{h} \int_x^{x+h} f(t) \, dt = f(c_h)\] As \(h \to 0\), \(x \le c_h \le x + h\) forces \(c_h \to x\) by the Squeeze Theorem. By continuity of \(f\): \[\lim_{h \to 0} f(c_h) = f(x) \implies g'(x) = f(x) \quad \blacksquare\]

3.2 Leibniz Integral Rule (Chain Rule Generalization)

When both boundaries of integration depend dynamically on \(x\): \[\frac{d}{dx} \left[ \int_{u(x)}^{v(x)} f(t) \, dt \right] = f(v(x)) \cdot v'(x) - f(u(x)) \cdot u'(x)\]

4. Section 5.4: Indefinite Integrals & The Net Change Theorem

4.1 The Net Change Theorem

Theorem: The integral of a rate of change represents the net change of the original quantity: \[\int_{t_1}^{t_2} F'(t) \, dt = F(t_2) - F(t_1)\]

Displacement vs. Total Distance Traveled:

For an object with velocity \(v(t)\): * Net Displacement: \(\Delta s = \int_{t_1}^{t_2} v(t) \, dt = s(t_2) - s(t_1)\) (vector net change). * Total Distance Traveled: \(D = \int_{t_1}^{t_2} |v(t)| \, dt\) (scalar accumulation of path length).

5.3 The Center of Mass: Discrete vs. Continuous Integrals and Momentum Dynamics

In physics, the transition from discrete summations to definite integrals is perfectly embodied by the Center of Mass (CM) and linear momentum conservation.

A. The Discrete System

For an ensemble of \(N\) discrete point particles with masses \(m_i\) located at position vectors \(\mathbf{r}_i\): \[\mathbf{r}_{\text{CM}} = \frac{\sum_{i=1}^N m_i \mathbf{r}_i}{\sum_{i=1}^N m_i} = \frac{1}{M_{\text{total}}} \sum_{i=1}^N m_i \mathbf{r}_i\]

Differentiating with respect to time yields the velocity of the center of mass: \[\mathbf{v}_{\text{CM}} = \frac{d\mathbf{r}_{\text{CM}}}{dt} = \frac{\sum_{i=1}^N m_i \mathbf{v}_i}{M_{\text{total}}} = \frac{\mathbf{P}_{\text{total}}}{M_{\text{total}}}\]

By Newton’s third law, all internal action-reaction force pairs cancel (\(\sum \mathbf{F}_{\text{internal}} = 0\)), meaning the center of mass moves as if the entire system mass were concentrated at \(\mathbf{r}_{\text{CM}}\) driven solely by net external forces: \[\frac{d\mathbf{P}_{\text{total}}}{dt} = M_{\text{total}} \frac{d\mathbf{v}_{\text{CM}}}{dt} = \sum \mathbf{F}_{\text{external}}\]

Integrating both sides over time yields the Impulse-Momentum Theorem: \[\Delta \mathbf{P}_{\text{total}} = \int_{t_1}^{t_2} \mathbf{F}_{\text{net,ext}}(t) \, dt\]

B. The Continuous Limit

For a macroscopic rigid body with continuous mass density \(\rho(\mathbf{r})\), we partition the body into \(n\) volume elements \(\Delta V_i\) of mass \(\Delta m_i = \rho(\mathbf{r}_i^*) \Delta V_i\). Taking the Riemann limit as \(\Delta V_i \to 0\) (\(n \to \infty\)): \[\mathbf{r}_{\text{CM}} = \lim_{n \to \infty} \frac{\sum_{i=1}^n \mathbf{r}_i^* \rho(\mathbf{r}_i^*) \Delta V_i}{\sum_{i=1}^n \rho(\mathbf{r}_i^*) \Delta V_i} = \frac{\iiint_V \mathbf{r} \, \rho(\mathbf{r}) \, dV}{\iiint_V \rho(\mathbf{r}) \, dV} = \frac{1}{M} \iiint_V \mathbf{r} \, dm\]

For a planar plate of uniform density \(\rho\) bounded by \(y = f(x)\), \(y = 0\), \(a \le x \le b\): \[\bar{x} = \frac{1}{A} \int_a^b x f(x) \, dx, \quad \bar{y} = \frac{1}{A} \int_a^b \frac{1}{2} [f(x)]^2 \, dx\]

1. Philosophy and Logic: The Sorites Paradox and Degree-Theoretic Semantics

The ancient Megarian philosopher Eubulides of Miletus formulated the Sorites Paradox (Paradox of the Heap): 1. \(1,000,000\) grains of sand form a heap. 2. Removing a single grain from a heap does not turn it into a non-heap. 3. By induction, \(1\) grain of sand must form a heap (a manifest absurdity).

Classical bivalent logic (\(\{0, 1\}\)) fails because natural language predicates (“bald”, “tall”, “heap”, “rich”) lack crisp boundaries. Modern philosophical logic resolves the Sorites paradox by treating truth values as a continuous Riemann spectrum \([0, 1]\). The predicate’s truth value \(\mu_{\text{Heap}}(n)\) is defined as the limit of an infinitesimal approximation: \[\mu_{\text{Heap}}(n) = \int_0^n w(x) \, dx\] where \(w(x)\) is a kernel density representing human linguistic consensus. The concept of a “heap” is not an arbitrary discrete cutoff, but the continuous limit of accumulated microscopic grains!

2. Moral Philosophy: Bentham’s Felicific Calculus and Continuous Utility

In An Introduction to the Principles of Morals and Legislation (1789), Jeremy Bentham proposed that moral decisions can be quantified via the Felicific Calculus: \[\text{Total Utility} = \sum (\text{Pleasure}) - \sum (\text{Pain})\] Bentham explicitly parameterized pleasure along seven dimensions: Intensity (\(I\)), Duration (\(D\)), Certainty (\(C\)), Propinquity (\(P\)), Fecundity (\(F\)), Purity (\(U\)), and Extent (\(E\)).

In modern mathematical ethics, Bentham’s discrete sum is formalized as a definite integral of instantaneous hedonic intensity over time: \[U_{\text{total}} = \int_0^T I(t) \cdot e^{-\delta t} \, dt\] where \(e^{-\delta t}\) represents the continuous discount rate (propinquity). John Stuart Mill further refined this by introducing qualitative weights, mirroring Lebesgue integration where pleasures are partitioned by quality (intensity range) rather than temporal duration.

3. Jurisprudence: The “Reasonable Person” as an Asymptotic Limit

In tort law and common law jurisprudence, the standard of care in negligence is defined by the actions of the “Reasonable Person” (bonus paterfamilias). Legal scholars have long debated: does this person exist? Is it the mathematical median of citizens?

In legal philosophy, the Reasonable Person is defined as the asymptotic limit of deliberative rationality: \[\text{Standard of Care} = \lim_{\text{bias} \to 0, \, \text{recklessness} \to 0} \mathbb{E}[\text{Action} \mid \text{Information}]\] No single living human behaves rationally in every instant. The legal standard is an idealized limiting surface—a normative asymptote towards which real-world human behavior is compared, identical to how an idealized friction-free mathematical surface serves as the limiting reference frame in Newtonian mechanics.

4. Historical Linguistics: Continuous Phonetic Drift vs. Discrete Phonemic Shifts

How do languages evolve? In historical phonology (e.g. Grimm’s Law, the Great Vowel Shift), a language transitions from Old English to Middle English to Early Modern English.

Linguists model speech sounds as coordinates in a continuous acoustic space defined by vowel formant frequencies (\(F_1, F_2\) in Hertz). Each generation of speakers produces acoustic tokens with microscopic variance \(\Delta F\). Across centuries, these infinitesimal phonetic shifts accumulate via a continuous drift integral: \[F_{\text{vowel}}(t) = F_{\text{vowel}}(0) + \int_0^t v_{\text{drift}}(\tau) \, d\tau\]

When the continuous integral crosses a perceptual acoustic threshold (the boundary of a phonemic perceptual magnet), the language community experiences a discrete bifurcation: a sound that was formerly an allophonic variation crystallizes into an entirely distinct phoneme. The discrete phonemic inventory of human language is the topological limit of continuous phonetic accumulation!

5. Historiography: Braudel’s Longue Durée as an Integral of Micro-Events

Fernand Braudel and the French Annales School revolutionized historical methodology by decomposing historical time into three tiers: 1. Le temps individuel (l’histoire événementielle): Fast, high-frequency, surface fluctuations—daily politics, battles, treaties, and political speeches (\(f_{\text{high}}(t)\)). 2. Le temps social (conjunctural cycles): Medium-term economic, demographic, and trade cycles (10–50 years). 3. Le temps géographique (la longue durée): Deep, slow, centuries-long civilizational structures, agrarian trade routes, and environmental geography (\(S(t)\)).

Braudel argued that chroniclers who focus exclusively on discrete headlines confuse superficial turbulence with true historical movement. Mathematically: \[\text{Civilizational Reality } S(T) = \int_0^T \left[ f_{\text{structural}}(t) + \xi_{\text{noise}}(t) \right] dt = \int_0^T f_{\text{structural}}(t) \, dt + \underbrace{\int_0^T \xi_{\text{noise}}(t) \, dt}_{\to 0 \text{ as } T \to \infty}\]

By the Mean Value Theorem and the Law of Large Numbers, the high-frequency event noise \(\xi(t)\) averages to zero over centuries, revealing the smooth, profound current of the longue durée. def integrate_uniform(func, a: float, b: float, n: int):

    assert n % 2 == 0, "n must be even for Simpson's rule"
    x = np.linspace(a, b, n + 1)
    dx = (b - a) / n
    y = func(x)

    left_sum = np.sum(y[:-1]) * dx
    right_sum = np.sum(y[1:]) * dx

7. Advanced Numerical Engines: Romberg Integration & Adaptive Quadrature

While uniform composite rules (trapezoidal and Simpson’s) are foundational, production scientific computing relies on adaptive and extrapolated quadrature to eliminate wasted function evaluations and guarantee error convergence.

7.1 Romberg Integration via Richardson Extrapolation

The composite trapezoid rule \(T(h)\) on subintervals of width \(h\) admits an asymptotic expansion governed by the Euler-Maclaurin Summation Formula: \[T(h) = I + c_1 h^2 + c_2 h^4 + c_3 h^6 + \dots\] Notice that only even powers of \(h\) appear in the truncation error.

By halving the step size (\(h o h/2\)), we can cancel the leading \(h^2\) error term: \[T(h/2) = I + c_1 rac{h^2}{4} + c_2 rac{h^4}{16} + \dots\] Multiplying by \(4\) and subtracting \(T(h)\): \[4 T(h/2) - T(h) = 3I + c_2' h^4 + \dots \implies R(1, 1) = rac{4 T(h/2) - T(h)}{3} = I + O(h^4)\] This cancellation is precisely Simpson’s Rule!

The General Romberg Tableau:

Iterating this extrapolation hierarchically generates the Romberg Tableau: \[R(k, m) = rac{4^m R(k, m-1) - R(k-1, m-1)}{4^m - 1}\] where \(k\) denotes the refinement level (\(n = 2^k\) intervals) and \(m\) denotes the extrapolation column (canceling \(O(h^{2m})\) error).

R(0, 0)  [Trapezoid O(h^2)]
R(1, 0)  ->  R(1, 1)  [Simpson O(h^4)]
R(2, 0)  ->  R(2, 1)  ->  R(2, 2)  [Boole O(h^6)]
R(3, 0)  ->  R(3, 1)  ->  R(3, 2)  ->  R(3, 3)  [O(h^8)]

7.2 Adaptive Simpson’s Quadrature

In functions with localized high curvature or steep boundary layers, a uniform mesh is profoundly inefficient. Adaptive Simpson’s Quadrature dynamically bisects intervals \([a, b]\) only where the local curvature demands it:

  1. Compute Simpson’s estimate over the whole interval: \(S(a, b) = rac{b - a}{6} [f(a) + 4f(c) + f(b)]\) where \(c = rac{a+b}{2}\).
  2. Compute Simpson’s estimate over the two halves: \(S(a, c) + S(c, b)\).
  3. The local truncation error satisfies: \[ ext{Error} pprox rac{|S(a, b) - [S(a, c) + S(c, b)]|}{15}\]
  4. If $ ext{Error} < arepsilon$, accept \([S(a, c) + S(c, b)] + rac{S(a, c) + S(c, b) - S(a, b)}{15}\) (local Richardson correction).
  5. If $ ext{Error} arepsilon$, recursively subdivide \([a, c]\) and \([c, b]\) each with tolerance $ arepsilon / 2$.

def romberg(func, a: float, b: float, max_steps: int = 5, tol: float = 1e-12):
    """Romberg integration via Richardson extrapolation."""
    R = [[0.0] * (max_steps + 1) for _ in range(max_steps + 1)]
    h = b - a
    R[0][0] = 0.5 * h * (func(a) + func(b))

    for k in range(1, max_steps + 1):
        h /= 2.0
        # Trapezoid midpoint evaluation
        sum_pts = sum(func(a + (2 * i - 1) * h) for i in range(1, 2**(k - 1) + 1))
        R[k][0] = 0.5 * R[k-1][0] + h * sum_pts

        # Richardson extrapolation columns
        for m in range(1, k + 1):
            factor = 4**m
            R[k][m] = (factor * R[k][m-1] - R[k-1][m-1]) / (factor - 1)

        if abs(R[k][k] - R[k-1][k-1]) < tol:
            return R[k][k], k

    return R[max_steps][max_steps], max_steps

## 1. Introduction: The Philosophy and Geometry of Accumulation

In elementary calculus curricula, differentiation is introduced as a local, instantaneous operation: measuring the instantaneous rate of change of a dynamic variable ($dy/dx$). In contrast, **integration** is a global, cumulative operation: synthesizing an infinite continuum of infinitesimal contributions into a finite macroscopic quantity.

While introductory students often reduce integration to "finding anti-derivatives," James Stewart's *Calculus: Early Transcendentals* (Chapter 5) structures the definite integral upon its true geometric foundation: **the limit of approximating Riemann sums**.

$$\int_a^b f(x) \, dx = \lim_{\|P\| \to 0} \sum_{i=1}^n f(x_i^*) \, \Delta x_i$$

This masterclass deconstructs the entirety of Stewart Chapter 5—from the geometry of partitions, convexity error bounds, and the Fundamental Theorem of Calculus to real-world continuous accumulation in virology, aerospace, radiation physics, and high-performance numerical algorithms.

### 2.1 The Geometry of Partitions and Sample Points

Let $[a, b] \subset \mathbb{R}$ be a closed interval. A **partition** $P$ is an ordered set of points:
$$P = \{a = x_0 < x_1 < x_2 < \dots < x_n = b\}$$
The subinterval widths are $\Delta x_i = x_i - x_{i-1}$, and the **mesh** (or norm) is $\|P\| = \max \Delta x_i$.

For each subinterval $[x_{i-1}, x_i]$, we select an arbitrary **sample point** (or tag) $x_i^* \in [x_{i-1}, x_i]$. The primary tag selection strategies include:
1. **Left Endpoint Sum ($L_n$)**: $x_i^* = x_{i-1}$
2. **Right Endpoint Sum ($R_n$)**: $x_i^* = x_i$
3. **Midpoint Sum ($M_n$)**: $x_i^* = \bar{x}_i = \frac{x_{i-1} + x_i}{2}$
4. **Trapezoidal Approximation ($T_n$)**: $\frac{L_n + R_n}{2} = \sum_{i=1}^n \frac{f(x_{i-1}) + f(x_i)}{2} \Delta x_i$

```
[ Left Sum L_n ]         [ Right Sum R_n ]        [ Midpoint Sum M_n ]
  |===|                    |   |===|                |  |===|  |
  |   |   |===|            |   |   |   |===|        |  |   |  |
  |   |   |   |            |   |   |   |   |        |  |   |  |
──┴───┴───┴───┴──        ──┴───┴───┴───┴───┴──    ──┴──┴───┴──┴───┴──
  x0  x1  x2               x0  x1  x2               x0  x1*  x1
```

### 2.2 Convexity, Monotonicity, and Error Geometry

The curvature (second derivative) and slope (first derivative) of $f(x)$ dictate strict geometric inequalities between these approximations and the exact integral $I = \int_a^b f(x) dx$:

#### A. Monotonicity Invariants
* **Strictly Increasing ($f'(x) > 0$)**:
  $$L_n < \int_a^b f(x) \, dx < R_n$$
  The exact integral is strictly sandwiched between the left and right sums.
* **Strictly Decreasing ($f'(x) < 0$)**:
  $$R_n < \int_a^b f(x) \, dx < L_n$$

#### B. Curvature & Convexity Invariants
* **Concave Upward ($f''(x) > 0$)**:
  The tangent line lies *below* the curve, while secant lines lie *above* the curve. Consequently:
  $$M_n < \int_a^b f(x) \, dx < T_n$$
  The midpoint rule systematically **underestimates**, while the trapezoidal rule systematically **overestimates**.
* **Asymptotic Error Relationship**:
  For sufficiently smooth functions, Taylor expansions demonstrate that:
  $$E_T \approx -2 E_M$$
  The error of the trapezoid rule is approximately twice the magnitude of the midpoint rule and has the opposite sign. This crucial insight directly yields **Simpson's Rule**:
  $$S_{2n} = \frac{2 M_n + T_n}{3} = \frac{1}{3} T_n + \frac{2}{3} M_n$$

### 2.3 What Happens When Left and Right Sum Limits Disagree?

In elementary calculus, student intuition takes for granted that $\lim_{n \to \infty} L_n = \lim_{n \to \infty} R_n = \int_a^b f(x) \, dx$. But what does it mathematically signify if these limits **fail to coincide** or if different tagging schemes diverge?

#### A. The Monotonic Case and Telescoping Error
For any bounded, monotonically increasing function $f$ on $[a, b]$ partitioned into $n$ uniform subintervals of width $\Delta x = \frac{b-a}{n}$:
$$R_n - L_n = \sum_{i=1}^n f(x_i) \Delta x - \sum_{i=1}^n f(x_{i-1}) \Delta x = \Delta x \sum_{i=1}^n \left( f(x_i) - f(x_{i-1}) \right)$$

The sum telescopes completely:
$$R_n - L_n = \frac{b - a}{n} \left[ f(b) - f(a) \right]$$

Because $f(b) - f(a)$ is finite, $\lim_{n \to \infty} (R_n - L_n) = 0$ unconditionally. Hence, **every bounded monotonic function is automatically Riemann integrable**, even if it has countably infinitely many jump discontinuities!

#### B. Discontinuities and Lebesgue's Criterion
If $\lim_{n \to \infty} L_n \ne \lim_{n \to \infty} R_n$, the function **violates Riemann integrability**. Henri Lebesgue proved the definitive criterion:
> **Lebesgue's Criterion for Riemann Integrability**: A bounded function $f: [a, b] \to \mathbb{R}$ is Riemann integrable if and only if its set of discontinuities $D \subset [a, b]$ has **Lebesgue measure zero** ($\mu(D) = 0$).

1. **Isolated Jump Discontinuities**: If $f$ has a finite (or countable) number of step jumps (e.g. Heaviside step $\Theta(x)$), the set of jump points has measure zero ($\mu(D) = 0$). Although on any single coarse subinterval containing a jump, the left and right sample values differ by the jump height $\Delta y$, the subinterval width shrinks as $\mathcal{O}(1/n)$. The total contribution of all jump intervals to the difference $|R_n - L_n|$ scales as $\sum (\text{jump}_k) \cdot \frac{b-a}{n} \to 0$. Thus, **piecewise continuous functions remain Riemann integrable**.
2. **Dense Non-Removable Discontinuities (The Dirichlet Function)**:
   $$\mathbf{1}_\mathbb{Q}(x) = \begin{cases} 1, & x \in \mathbb{Q} \\ 0, & x \notin \mathbb{Q} \end{cases}$$
   Between any two real numbers, there exist both infinitely many rationals and infinitely many irrationals. If tags are chosen at rational sample points ($x_i^* \in \mathbb{Q}$), the Riemann sum is $\sum_{i=1}^n 1 \cdot \Delta x = 1$. If tags are chosen at irrational sample points ($x_i^* \notin \mathbb{Q}$), the Riemann sum is $\sum_{i=1}^n 0 \cdot \Delta x = 0$. The limit does not exist, and the lower and upper Darboux integrals remain locked at $L(f) = 0$ and $U(f) = 1$.
3. **Physical and Numerical Implication**: In numerical computing and physical sensors, when left and right approximations disagree significantly, it implies the presence of a **shock wave** (in compressible gas dynamics), a **phase change boundary** (in thermodynamics), or an **undersampled high-frequency transient** violating the Nyquist-Shannon sampling theorem.

### 2.4 Worked Example: High-Degree Monomial Riemann Limit (Stewart Ch 5, Problem 78)

Evaluate the following limit from Stewart Calculus Chapter 5:
$$\mathcal{L} = \lim_{n \to \infty} \sum_{i=1}^n \frac{i^9}{n^{10}}$$

#### Step-by-Step Analytical Deconstruction:
1. **Factor out $1/n$ to isolate the subinterval width**:
   $$\frac{i^9}{n^{10}} = \frac{i^9}{n^9 \cdot n} = \left(\frac{i}{n}\right)^9 \frac{1}{n}$$
2. **Identify Partition and Tagging**:
   Let the interval be $[0, 1]$. The uniform partition has $\Delta x = \frac{1 - 0}{n} = \frac{1}{n}$, and the right endpoints are $x_i = 0 + i \Delta x = \frac{i}{n}$.
3. **Recognize the Riemann Sum**:
   $$\sum_{i=1}^n \frac{i^9}{n^{10}} = \sum_{i=1}^n \left(x_i\right)^9 \Delta x = R_n$$
4. **Pass to the Definite Integral**:
   Since $f(x) = x^9$ is continuous on $[0, 1]$, the limit of the Riemann sum equals the definite integral:
   $$\lim_{n \to \infty} \sum_{i=1}^n \frac{i^9}{n^{10}} = \int_0^1 x^9 \, dx = \left[ \frac{x^{10}}{10} \right]_0^1 = \frac{1}{10}$$

## 3. Section 5.3: The Fundamental Theorem of Calculus (FTC)

The Fundamental Theorem of Calculus is the intellectual crown of analysis, proving that differentiation and integration are inverse operations.

### 3.1 FTC Part 1: The Area Accumulator Function

Let $f$ be continuous on $[a, b]$. Define the **accumulator function**:
$$g(x) = \int_a^x f(t) \, dt \quad \text{for } x \in [a, b]$$

> **Theorem (FTC 1)**: The function $g(x)$ is continuous on $[a, b]$, differentiable on $(a, b)$, and its derivative is precisely the integrand:
> $$g'(x) = \frac{d}{dx} \left[ \int_a^x f(t) \, dt \right] = f(x)$$

#### Rigorous Proof:
By the limit definition of the derivative:
$$g'(x) = \lim_{h \to 0} \frac{g(x + h) - g(x)}{h} = \lim_{h \to 0} \frac{1}{h} \left[ \int_a^{x+h} f(t) \, dt - \int_a^x f(t) \, dt \right] = \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(t) \, dt$$
By the **Mean Value Theorem for Integrals**, because $f$ is continuous on $[x, x+h]$, there exists a number $c_h$ between $x$ and $x + h$ such that:
$$\int_x^{x+h} f(t) \, dt = f(c_h) \cdot h \implies \frac{1}{h} \int_x^{x+h} f(t) \, dt = f(c_h)$$
As $h \to 0$, $x \le c_h \le x + h$ forces $c_h \to x$ by the Squeeze Theorem. By continuity of $f$:
$$\lim_{h \to 0} f(c_h) = f(x) \implies g'(x) = f(x) \quad \blacksquare$$

### 3.2 Leibniz Integral Rule (Chain Rule Generalization)

When both boundaries of integration depend dynamically on $x$:
$$\frac{d}{dx} \left[ \int_{u(x)}^{v(x)} f(t) \, dt \right] = f(v(x)) \cdot v'(x) - f(u(x)) \cdot u'(x)$$

## 4. Section 5.4: Indefinite Integrals & The Net Change Theorem

### 4.1 The Net Change Theorem

> **Theorem**: The integral of a rate of change represents the **net change** of the original quantity:
> $$\int_{t_1}^{t_2} F'(t) \, dt = F(t_2) - F(t_1)$$

#### Displacement vs. Total Distance Traveled:
For an object with velocity $v(t)$:
* **Net Displacement**: $\Delta s = \int_{t_1}^{t_2} v(t) \, dt = s(t_2) - s(t_1)$ (vector net change).
* **Total Distance Traveled**: $D = \int_{t_1}^{t_2} |v(t)| \, dt$ (scalar accumulation of path length).

### 5.3 The Center of Mass: Discrete vs. Continuous Integrals and Momentum Dynamics

In physics, the transition from discrete summations to definite integrals is perfectly embodied by the **Center of Mass (CM)** and linear momentum conservation.

#### A. The Discrete System
For an ensemble of $N$ discrete point particles with masses $m_i$ located at position vectors $\mathbf{r}_i$:
$$\mathbf{r}_{\text{CM}} = \frac{\sum_{i=1}^N m_i \mathbf{r}_i}{\sum_{i=1}^N m_i} = \frac{1}{M_{\text{total}}} \sum_{i=1}^N m_i \mathbf{r}_i$$

Differentiating with respect to time yields the velocity of the center of mass:
$$\mathbf{v}_{\text{CM}} = \frac{d\mathbf{r}_{\text{CM}}}{dt} = \frac{\sum_{i=1}^N m_i \mathbf{v}_i}{M_{\text{total}}} = \frac{\mathbf{P}_{\text{total}}}{M_{\text{total}}}$$

By Newton's third law, all internal action-reaction force pairs cancel ($\sum \mathbf{F}_{\text{internal}} = 0$), meaning the center of mass moves as if the entire system mass were concentrated at $\mathbf{r}_{\text{CM}}$ driven solely by net external forces:
$$\frac{d\mathbf{P}_{\text{total}}}{dt} = M_{\text{total}} \frac{d\mathbf{v}_{\text{CM}}}{dt} = \sum \mathbf{F}_{\text{external}}$$

Integrating both sides over time yields the **Impulse-Momentum Theorem**:
$$\Delta \mathbf{P}_{\text{total}} = \int_{t_1}^{t_2} \mathbf{F}_{\text{net,ext}}(t) \, dt$$

#### B. The Continuous Limit
For a macroscopic rigid body with continuous mass density $\rho(\mathbf{r})$, we partition the body into $n$ volume elements $\Delta V_i$ of mass $\Delta m_i = \rho(\mathbf{r}_i^*) \Delta V_i$. Taking the Riemann limit as $\Delta V_i \to 0$ ($n \to \infty$):
$$\mathbf{r}_{\text{CM}} = \lim_{n \to \infty} \frac{\sum_{i=1}^n \mathbf{r}_i^* \rho(\mathbf{r}_i^*) \Delta V_i}{\sum_{i=1}^n \rho(\mathbf{r}_i^*) \Delta V_i} = \frac{\iiint_V \mathbf{r} \, \rho(\mathbf{r}) \, dV}{\iiint_V \rho(\mathbf{r}) \, dV} = \frac{1}{M} \iiint_V \mathbf{r} \, dm$$

For a planar plate of uniform density $\rho$ bounded by $y = f(x)$, $y = 0$, $a \le x \le b$:
$$\bar{x} = \frac{1}{A} \int_a^b x f(x) \, dx, \quad \bar{y} = \frac{1}{A} \int_a^b \frac{1}{2} [f(x)]^2 \, dx$$

#### 1. Philosophy and Logic: The Sorites Paradox and Degree-Theoretic Semantics
The ancient Megarian philosopher Eubulides of Miletus formulated the **Sorites Paradox (Paradox of the Heap)**:
1. $1,000,000$ grains of sand form a heap.
2. Removing a single grain from a heap does not turn it into a non-heap.
3. By induction, $1$ grain of sand must form a heap (a manifest absurdity).

Classical bivalent logic ($\{0, 1\}$) fails because natural language predicates ("bald", "tall", "heap", "rich") lack crisp boundaries. Modern philosophical logic resolves the Sorites paradox by treating truth values as a **continuous Riemann spectrum** $[0, 1]$. The predicate's truth value $\mu_{\text{Heap}}(n)$ is defined as the limit of an infinitesimal approximation:
$$\mu_{\text{Heap}}(n) = \int_0^n w(x) \, dx$$
where $w(x)$ is a kernel density representing human linguistic consensus. The concept of a "heap" is not an arbitrary discrete cutoff, but the continuous limit of accumulated microscopic grains!

#### 2. Moral Philosophy: Bentham's Felicific Calculus and Continuous Utility
In *An Introduction to the Principles of Morals and Legislation* (1789), Jeremy Bentham proposed that moral decisions can be quantified via the **Felicific Calculus**:
$$\text{Total Utility} = \sum (\text{Pleasure}) - \sum (\text{Pain})$$
Bentham explicitly parameterized pleasure along seven dimensions: *Intensity* ($I$), *Duration* ($D$), *Certainty* ($C$), *Propinquity* ($P$), *Fecundity* ($F$), *Purity* ($U$), and *Extent* ($E$). 

In modern mathematical ethics, Bentham's discrete sum is formalized as a definite integral of instantaneous hedonic intensity over time:
$$U_{\text{total}} = \int_0^T I(t) \cdot e^{-\delta t} \, dt$$
where $e^{-\delta t}$ represents the continuous discount rate (propinquity). John Stuart Mill further refined this by introducing qualitative weights, mirroring Lebesgue integration where pleasures are partitioned by quality (intensity range) rather than temporal duration.

#### 3. Jurisprudence: The "Reasonable Person" as an Asymptotic Limit
In tort law and common law jurisprudence, the standard of care in negligence is defined by the actions of the **"Reasonable Person"** (*bonus paterfamilias*). Legal scholars have long debated: does this person exist? Is it the mathematical median of citizens?

In legal philosophy, the Reasonable Person is defined as the **asymptotic limit of deliberative rationality**:
$$\text{Standard of Care} = \lim_{\text{bias} \to 0, \, \text{recklessness} \to 0} \mathbb{E}[\text{Action} \mid \text{Information}]$$
No single living human behaves rationally in every instant. The legal standard is an idealized limiting surface—a normative asymptote towards which real-world human behavior is compared, identical to how an idealized friction-free mathematical surface serves as the limiting reference frame in Newtonian mechanics.

#### 4. Historical Linguistics: Continuous Phonetic Drift vs. Discrete Phonemic Shifts
How do languages evolve? In historical phonology (e.g. Grimm's Law, the Great Vowel Shift), a language transitions from Old English to Middle English to Early Modern English. 

Linguists model speech sounds as coordinates in a continuous acoustic space defined by vowel formant frequencies ($F_1, F_2$ in Hertz). Each generation of speakers produces acoustic tokens with microscopic variance $\Delta F$. Across centuries, these infinitesimal phonetic shifts accumulate via a continuous drift integral:
$$F_{\text{vowel}}(t) = F_{\text{vowel}}(0) + \int_0^t v_{\text{drift}}(\tau) \, d\tau$$

When the continuous integral crosses a perceptual acoustic threshold (the boundary of a phonemic perceptual magnet), the language community experiences a **discrete bifurcation**: a sound that was formerly an allophonic variation crystallizes into an entirely distinct phoneme. The discrete phonemic inventory of human language is the topological limit of continuous phonetic accumulation!

#### 5. Historiography: Braudel's *Longue Durée* as an Integral of Micro-Events
Fernand Braudel and the French *Annales* School revolutionized historical methodology by decomposing historical time into three tiers:
1. *Le temps individuel* (l'histoire événementielle): Fast, high-frequency, surface fluctuations—daily politics, battles, treaties, and political speeches ($f_{\text{high}}(t)$).
2. *Le temps social* (conjunctural cycles): Medium-term economic, demographic, and trade cycles (10–50 years).
3. *Le temps géographique* (la longue durée): Deep, slow, centuries-long civilizational structures, agrarian trade routes, and environmental geography ($S(t)$).

Braudel argued that chroniclers who focus exclusively on discrete headlines confuse superficial turbulence with true historical movement. Mathematically:
$$\text{Civilizational Reality } S(T) = \int_0^T \left[ f_{\text{structural}}(t) + \xi_{\text{noise}}(t) \right] dt = \int_0^T f_{\text{structural}}(t) \, dt + \underbrace{\int_0^T \xi_{\text{noise}}(t) \, dt}_{\to 0 \text{ as } T \to \infty}$$

By the Mean Value Theorem and the Law of Large Numbers, the high-frequency event noise $\xi(t)$ averages to zero over centuries, revealing the smooth, profound current of the *longue durée*. Macro-history is the definite integral of human existence.

```python
import numpy as np

def integrate_uniform(func, a: float, b: float, n: int):
    """Uniform grid composite quadrature rules."""
    assert n % 2 == 0, "n must be even for Simpson's rule"
    x = np.linspace(a, b, n + 1)
    dx = (b - a) / n
    y = func(x)

    # 1. Left & Right Riemann Sums
    left_sum = np.sum(y[:-1]) * dx
    right_sum = np.sum(y[1:]) * dx

    # 2. Midpoint Rule
    mids = (x[:-1] + x[1:]) / 2.0
    mid_sum = np.sum(func(mids)) * dx

    # 3. Trapezoidal Rule
    trap_sum = (0.5 * y[0] + np.sum(y[1:-1]) + 0.5 * y[-1]) * dx

    # 4. Simpson's 1/3 Rule
    simpson_sum = (y[0] + 4.0 * np.sum(y[1:-1:2]) + 2.0 * np.sum(y[2:-1:2]) + y[-1]) * (dx / 3.0)

    return {"Left": left_sum, "Right": right_sum, "Midpoint": mid_sum, 
            "Trapezoid": trap_sum, "Simpson": simpson_sum}

def integrate_nonuniform(x, y):
    """Composite trapezoidal rule on non-equally spaced partitions."""
    dx = np.diff(x)
    return np.sum(0.5 * (y[:-1] + y[1:]) * dx)

# Demonstration: Measles in-host acute infection integral on [0, 12]
```

```cpp
#include <iostream>
#include <vector>
#include <iomanip>
#include <cmath>
#include <functional>

struct QuadratureResults {
    double left, right, midpoint, trapezoid, simpson;
};

QuadratureResults integrate_uniform(std::function<double(double)> f, double a, double b, int n) {
    double dx = (b - a) / n;
    double left = 0.0, right = 0.0, mid = 0.0, trap = 0.0;
    
    std::vector<double> y(n + 1);
    for (int i = 0; i <= n; ++i) {
        y[i] = f(a + i * dx);
    }
    
    for (int i = 0; i < n; ++i) {
        left += y[i] * dx;
        right += y[i+1] * dx;
        mid += f(a + (i + 0.5) * dx) * dx;
    }
    
    trap = 0.5 * (left + right);
    
    // Simpson 1/3 Rule
    double simpson = y[0] + y[n];
    for (int i = 1; i < n; ++i) {
        simpson += (i % 2 == 1) ? 4.0 * y[i] : 2.0 * y[i];
    }
    simpson *= (dx / 3.0);
    
    return {left, right, mid, trap, simpson};
}

double integrate_nonuniform(const std::vector<double>& x, const std::vector<double>& y) {
    double total = 0.0;
    for (size_t i = 0; i < x.size() - 1; ++i) {
        total += 0.5 * (y[i] + y[i+1]) * (x[i+1] - x[i]);
    }
    return total;
}
```

```rust
fn integrate_uniform<F>(f: F, a: f64, b: f64, n: usize) -> (f64, f64, f64, f64, f64) 
where F: Fn(f64) -> f64 {
    assert!(n % 2 == 0);
    let dx = (b - a) / (n as f64);
    let y: Vec<f64> = (0..=n).map(|i| f(a + (i as f64) * dx)).collect();

    let left = y[..n].iter().sum::<f64>() * dx;
    let right = y[1..].iter().sum::<f64>() * dx;
    let mid: f64 = (0..n).map(|i| f(a + (i as f64 + 0.5) * dx)).sum::<f64>() * dx;
    let trap = 0.5 * (left + right);

    let mut simp = y[0] + y[n];

        simp += if i % 2 == 1 { 4.0 * y[i] } else { 2.0 * y[i] };
    }
    let simpson = simp * (dx / 3.0);

    (left, right, mid, trap, simpson)
}
```

## 7. Advanced Numerical Engines: Romberg Integration & Adaptive Quadrature

While uniform composite rules (trapezoidal and Simpson's) are foundational, production scientific computing relies on **adaptive and extrapolated quadrature** to eliminate wasted function evaluations and guarantee error convergence.

### 7.1 Romberg Integration via Richardson Extrapolation

The composite trapezoid rule $T(h)$ on subintervals of width $h$ admits an asymptotic expansion governed by the **Euler-Maclaurin Summation Formula**:
$$T(h) = I + c_1 h^2 + c_2 h^4 + c_3 h^6 + \dots$$
Notice that only *even* powers of $h$ appear in the truncation error.

By halving the step size ($h    o h/2$), we can cancel the leading $h^2$ error term:
$$T(h/2) = I + c_1 rac{h^2}{4} + c_2 rac{h^4}{16} + \dots$$
Multiplying by $4$ and subtracting $T(h)$:
$$4 T(h/2) - T(h) = 3I + c_2' h^4 + \dots \implies R(1, 1) = rac{4 T(h/2) - T(h)}{3} = I + O(h^4)$$
This cancellation is precisely **Simpson's Rule**!

#### The General Romberg Tableau:
Iterating this extrapolation hierarchically generates the **Romberg Tableau**:
$$R(k, m) = rac{4^m R(k, m-1) - R(k-1, m-1)}{4^m - 1}$$
where $k$ denotes the refinement level ($n = 2^k$ intervals) and $m$ denotes the extrapolation column (canceling $O(h^{2m})$ error).

```
R(0, 0)  [Trapezoid O(h^2)]
R(1, 0)  ->  R(1, 1)  [Simpson O(h^4)]
R(2, 0)  ->  R(2, 1)  ->  R(2, 2)  [Boole O(h^6)]
R(3, 0)  ->  R(3, 1)  ->  R(3, 2)  ->  R(3, 3)  [O(h^8)]
```

### 7.2 Adaptive Simpson's Quadrature

In functions with localized high curvature or steep boundary layers, a uniform mesh is profoundly inefficient. **Adaptive Simpson's Quadrature** dynamically bisects intervals $[a, b]$ only where the local curvature demands it:

1. Compute Simpson's estimate over the whole interval: $S(a, b) = rac{b - a}{6} [f(a) + 4f(c) + f(b)]$ where $c = rac{a+b}{2}$.
2. Compute Simpson's estimate over the two halves: $S(a, c) + S(c, b)$.
3. The local truncation error satisfies:
   $$   ext{Error} pprox rac{|S(a, b) - [S(a, c) + S(c, b)]|}{15}$$
4. If $ ext{Error} < arepsilon$, accept $[S(a, c) + S(c, b)] + rac{S(a, c) + S(c, b) - S(a, b)}{15}$ (local Richardson correction).
5. If $ ext{Error} \ge arepsilon$, recursively subdivide $[a, c]$ and $[c, b]$ each with tolerance $arepsilon / 2$.

```python
def romberg(func, a: float, b: float, max_steps: int = 5, tol: float = 1e-12):
    """Romberg integration via Richardson extrapolation."""
    R = [[0.0] * (max_steps + 1) for _ in range(max_steps + 1)]
    h = b - a
    R[0][0] = 0.5 * h * (func(a) + func(b))

    for k in range(1, max_steps + 1):
        h /= 2.0
        # Trapezoid midpoint evaluation
        sum_pts = sum(func(a + (2 * i - 1) * h) for i in range(1, 2**(k - 1) + 1))
        R[k][0] = 0.5 * R[k-1][0] + h * sum_pts

        # Richardson extrapolation columns
        for m in range(1, k + 1):
            factor = 4**m
            R[k][m] = (factor * R[k][m-1] - R[k-1][m-1]) / (factor - 1)

        if abs(R[k][k] - R[k-1][k-1]) < tol:
            return R[k][k], k

    return R[max_steps][max_steps], max_steps
```
